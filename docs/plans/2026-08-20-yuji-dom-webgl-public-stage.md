## 问题本质

现有公共站已经具备完整内容路由、Three.js 与 GSAP，但液态雨膜、固定二次元品牌图和暖纸编辑式页面没有形成 owner 认可的第一印象。继续调整旧 shader 或叠加更多特效会保留错误的视觉主语。新方向要重建的不是一个 3D 背景，而是“真实 DOM 内容与统一 WebGL 舞台共享滚动、指针、对象位置和路由状态”的公共体验。

## 已确认结果

- 移除液态雨膜、四张固定二次元品牌图、三屏固定叙事及其生产引用。
- 第一阶段完整重做公共壳、首页、文章列表和文章详情；图库与关于只继承新 token 与共享转场。
- 首页为约一屏 3D“雨迹”字标舞台，之后依次为简短宣言、最新 8 篇文章索引、少量图库与关于入口。
- 文章索引使用真实 DOM / CSS Grid 与 WebGL 镜像封面，提供负片显影、滚动速度形变、点阵悬停和全屏点阵路由转场。
- 文章详情默认近黑安静阅读，保留完整浅色模式；长文章显示目录，删除固定装饰侧注，不让持续 WebGL 进入正文。
- 中文承担真实内容，英文只承担品牌遥测；第一阶段不做声音。
- 第五轮按机制层接近参考站，但继续使用雨迹自有字标呈现、贴纸、配色和内容：桌面指针移动驱动流体光场，贴纸与 3D 信号物首次入场时依次降落并停稳，随后只缓慢漂浮。第六轮进一步依据公开部署证据，把局部加法光平面纠偏为按视口比例求解、轻度折射整幅 WebGL 内容并在透明区域输出连续主题流光的全画布流体。
- 第七轮把左侧中文宣言调整为较轻且行框不重叠的中文字体层级；3D `yuji` 改为使用 Three.js 已附带、许可允许再分发的 Optimer Bold 轮廓生成圆角倒角 GLB，并随资产保留 MgOpen 许可；DOM SVG 贴纸复用 PointerBus 提供流光靠近时的边缘亮起与轻微避让，首屏与下一内容段之间不再出现独立黑色分隔线。
- 第八轮把 WebGL 前景信号物从高饱和三角、方块、折面体和立体箭头收敛为圆环、胶囊、光珠与绳结等连续曲面，并以冰青、淡紫和受限淡粉虹彩材质融入全画布流光；保持原有七个落点、落物顺序与滚动退场不变。
- 品牌首屏通过统一公共舞台退场进入内容：点阵溶解、相机后退与 3D 轻度柔化共享同一进度，反向滚动可恢复，不让光场、字标、贴纸或信号物单独硬隐藏。
- 首页 WebGL 舞台、首页文章封面与 `/articles` 可见封面共享速度型弯曲和停滚回正，真实 DOM 网格、文字和链接保持平面；文章详情、图库和关于不扩大持续 WebGL 范围。
- 桌面使用完整效果；移动端关闭流体模拟、点击爆发与滚动弯曲并减少落物，系统减少动画时直接显示稳定终态。
- 深浅主题共享同一动力学，只切换主题化流光与点阵对比度；第一版以参考站约 `70%–80%` 的视觉强度为基线，再通过真实 Chrome 并排观察微调。

## 技术架构

### 统一帧与输入

- 新增 `@react-three/fiber@9` 与 `lenis`，不新增 Drei、Motion 或通用后处理框架。
- R3F 持有唯一舞台帧循环；每帧先调用关闭自动 RAF 的 `lenis.raf(time)`，再把 scroll、limit、progress、velocity、direction 与 viewportHeight 写入 ScrollBus，最后由 WebGL 消费同一快照。
- WebGL 在帧循环中直接读取 mutable snapshot，不触发 React render；只有真实 DOM 输出需要滚动状态时才通过 `useSyncExternalStore` 订阅。
- PointerBus 统一维护位置、离开状态和供流体消费的同帧位移，不新增第二套全局监听；同时提供 mutable UV 与 immutable React snapshot，离开窗口、失焦或页面隐藏时回到中心。
- 第五、六轮只在现有 R3F 主循环内增加定向 FBO 与自定义 shader pass，不引入通用 Composer/postprocessing 框架、物理引擎或第二套 RAF。流体、舞台退场和速度弯曲复用现有 renderer、性能档位与可见性停算边界；流体使用八个按视口比例调整、短边基准为 `160` 的 HalfFloat target 执行压力投影。

### DOM / WebGL 镜像

- DOM 与 CSS Grid 决定文章标题、链接、封面占位、列数、间距和无障碍结构。
- 单一封面注册表持有需要增强的 DOM 封面；近视口对象按当前 DOM 矩形对齐，离开近视口后停止绘制，并对已离开视口对象降低测量频率。
- 每张近视口封面使用屏幕空间矩形 uniform 对齐 WebGL 图像；纹理未准备、矩形无效或远离视口时停止绘制和更新。
- 单封面通过原色、负片或双色处理形成状态变化；不修改文章接口或数据模型。

### 视觉系统

- 3D `yuji` 字标由仓库脚本使用 Three.js 示例字体中的 Optimer Bold 轮廓生成圆角倒角 GLB，字体许可随资产保留；浏览器继续使用雨迹自有 Fresnel、薄膜色散、指针响应和颗粒 shader，不加载第三方模型、纹理或参考站资产，DOM 同步提供可访问的静态降级字标。
- 3D 字标使用透射、色散和体积衰减物理材质，并与动态光束、指针光迹和实时坐标 HUD 共享同一 PointerBus；不复制参考站的 `hello` 几何、贴纸或品牌素材。
- 六枚原创 SVG 信号贴纸和 3D 信号物承担前景节奏；加载门打开后先稳定光场与字标，再显现导航与宣言，随后让 3D 信号物由后向前降落，最后落下 DOM 贴纸，整体约 `1.4s`。桌面端每次完整页面加载只播放一次，使用确定性固定落点、弹簧式轨迹和一次轻微回弹，不增加碰撞物理；进入文章再返回首页时不重播，也不提供点击爆发。DOM 贴纸在流光靠近时使用同一 PointerBus 增加受限的青色边缘光、亮度和不超过约 `10px` 的避让位移，使其与 WebGL 信号物共享“被触碰”反馈。移动端只保留 3 枚贴纸的短距离降落并裁切到安全区域。它们不是可点击的假功能。
- 指针流体通过 curl、位移注入、散度、四次压力求解、压力梯度与平流得到速度场，再在最终全画布 pass 中轻度位移和色散 WebGL 光场、玻璃字与 3D 信号物；透明背景区域额外输出低透明度主题流光，让连续移动路径覆盖整个视口而不是停留在单一径向光斑。真实 DOM 文字与公共导航不变形；指针静止后约 `600ms` 停止求解并恢复直通，离开舞台或公共舞台退场完成后同样停算。
- 公共舞台退场在首次滚动时立即开始并在约 `0.75` 个视口内完成，不 pin 首屏；点阵承担主要溶解，相机后退约 `15%`，WebGL 最大柔化约 `6px`，DOM 最大柔化约 `4px` 并轻微上移淡出。WebGL 字标、信号物、光场、指针轨迹与 DOM 宣言、贴纸、遥测共享可逆进度，公共导航保持清晰固定。
- 首页 WebGL 舞台、首页文章封面与 `/articles` 可见封面只按滚动速度绝对值弯曲，采用约 `25ms` 进入、`175ms` 释放和最大约 `6%` 的统一响应，DOM 网格、文字和链接不变形。
- 文章入口把真实封面、反相切片和 DOM 标题组合为横向作品条目，悬停、键盘焦点和路由转场仍复用同一套点阵规则。
- 近黑、电光钴蓝或靛蓝、冰青高光与单一酸性激活色构成公共 token；浅色模式使用冷白表面与同一信号色关系。
- 点阵反馈作为卡片、移动菜单和路由转场的共同视觉规则；交互只在舞台路由和可见文档中运行。

### 路由连续性

- 点击文章时记录来源封面 ID、文章索引 URL、滚动位置和转场阶段，点阵关闭后切换路由，再打开文章详情。
- 浏览器返回执行反向转场并恢复索引 URL 与滚动位置；直接打开文章 URL 不依赖来源状态。
- 交互状态机与滚动恢复决策保持纯函数，路由、动画、DOM 测量和浏览器历史作为外部副作用装配。

## 实施阶段

### 0. 基线与失败用例

1. 记录现有首页、文章列表和详情在 390、900、1366、1440、1920px 的 DOM、路由、主题、loading 与降级行为。
2. 先为新公共舞台语义、8 篇文章、转场状态、返回恢复、直接访问、减少动画和 WebGL 失败补失败用例。
3. 确认旧液态模块、四张品牌图及相关测试的全部引用，再建立删除清单。

### 1. 依赖、资产与舞台底座

1. 添加已授权的 R3F 9 与 Lenis，建立唯一 Canvas、ScrollBus、PointerBus、性能档位 resolver 和生命周期清理。
2. 建立原创程序化字标路径、圆角端帽和 DOM 静态降级，先完成独立技术样片。
3. 验证字标物理材质、主题色、指针倾斜、resize、DPR、context lost、离屏暂停和静态降级；样片未通过时不扩展文章索引。

### 2. 公共壳与首页舞台

1. 重建公共 token、字体层级、近黑/冷白主题、导航、英文品牌遥测、移动菜单和共享点阵表面。
2. 用约一屏公共舞台替换 300svh 液态首页，再接入宣言、最新 8 篇文章、图库与关于入口。
3. 首次进入首页时用浅纸色品牌加载门承接真实 GLB 下载进度，至少保持一个可辨识的起拍节奏；模型成功或失败后都必须 fail-open，随后同步释放导航、宣言、贴纸和舞台入场。DOM 降级内容始终存在，文章与图库请求不得阻塞这道加载门。

### 3. 舞台文章索引

1. 建立共享 DOM 矩形采样器、纹理缓存、近视口剔除和封面镜像层。
2. 接入负片显影、单封面点阵悬停、受控滚动速度形变和键盘焦点等价反馈。
3. 首页 8 篇索引与 `/articles` 完整列表复用同一规则和参数真源，不复制 effect。

### 4. 点阵路由与文章详情

1. 实现可测试的转场状态机、双向路由连续性、滚动位置恢复、直接访问和减少动画分支。
2. 重构文章首屏、条件式目录、约 800px 正文、代码与媒体样式、文末标签和相关文章。
3. 删除固定 `NOTE` 侧注；正文卸载或路由离开后不保留 Canvas、订阅或滚动锁。

### 5. 继承页面与旧实现移除

1. 图库和关于页只接入新 token、导航与共享点阵转场，不重做其内容模型和核心布局。
2. 删除 `YujiLiquidRainStage`、液态专用 feature/hook/style/test 和四张 `apps/web/src/assets/yuji-brand/*.webp`，前提是全仓引用检查为空。
3. 更新产品规格、ADR、领域术语与计划状态；新体验通过 owner 验收后归档旧液态计划。

### 6. 第五轮动效精修

1. 在不复制参考站品牌资产的前提下，为 PointerBus、ScrollBus 和公共舞台建立统一的流体光场、落物入场、舞台退场与速度弯曲契约。
2. 保持首页与 `/articles` 的 DOM / WebGL 职责边界、唯一帧循环和可见对象剔除；使用定向 FBO 与自定义 shader pass，不增加通用后处理框架、物理引擎或第二套 RAF。
3. 深浅主题复用同一动力学并只替换颜色与对比度；完成桌面完整档、移动平衡档、减少动画终态，以及 GLB/WebGL 失败时 DOM 贴纸轻量入场、CSS 淡出与点阵近似退场的降级。
4. 以参考站约 `70%–80%` 的视觉强度完成首版，再补真实浏览器正反滚动、快速滚动、指针移动/静止、入场、停滚回正和并排观察证据。

### 7. 第六轮全画布流体纠偏

1. 以 Haoqi 公开生产 chunk 的 `FluidPushPass` 为机制证据，先记录参考站的压力投影、全屏 `tDiffuse` 位移、600ms 停算和移动端降级边界；不从视觉猜测未公开源码。
2. 删除仅形变三条程序光线的独立加法光平面，改为按视口比例分配八个 HalfFloat target，在唯一 R3F 帧循环内执行 curl、指针注入、散度、四次压力 Jacobi、压力梯度和平流。
3. 最终合成 pass 对现有 WebGL 内容施加受控位移与色散，并为透明背景区域输出低透明度主题流光，使轨迹可跨越整屏空白 DOM 区域；保持真实 DOM、导航、链接和可访问结构不变形。
4. 增加画幅与启停纯逻辑覆盖，并在真实 Chrome 中核对整屏连续路径、浅色与深色主题、停止回稳、滚动退场、移动档停算和控制台错误。

### 8. 第七轮首屏排版与交互一致性

1. 保留中文宣言的品牌职责，减轻字重、缩小桌面尺度并增加行高与行内留白，避免文本选区跨行覆盖；不把真实中文内容替换成装饰性英文。
2. 用项目现有 Three.js 示例字体中许可允许再分发的 Optimer Bold 轮廓重建圆角倒角 GLB，控制生成资产体积并随资产保留许可，不增加运行时字体解析或新依赖。
3. 让六枚 DOM SVG 贴纸通过 PointerBus 计算指针邻近度，在不改变真实 DOM 像素和可访问结构的前提下增加边缘流光、亮度与轻微避让；静态档不启用该反馈。
4. 移除首页首屏到内容声明之间的独立边框，并在 1512、900、390px 的当前 Chrome 中核对首屏排版、贴纸反馈、移动降级与无缝滚动边界。

### 9. 第八轮 WebGL 信号物视觉收敛

1. 删除高饱和三角、方块、折面体和立体箭头，避免硬边原色几何抢走 `yuji` 字标与流光的视觉主语。
2. 在不增加依赖或外部模型的前提下，以细圆环、圆角胶囊、椭圆光珠、绳结和小光珠重建七枚程序化信号物，保留确定性落点与既有入场引用关系。
3. 统一使用低金属度、低粗糙度、带清漆和薄膜虹彩的冰青—淡紫材质，只保留一枚受限淡粉暖色光体；浅色与深色主题保持相同材质层级。
4. 在真实 Chrome 中核对 1512、900、390px 浅色构图、桌面深色主题、慢速跨屏指针流光与横向溢出；不扩大 Canvas 范围或流体求解成本。

## 验证矩阵

### 自动验证

- 纯逻辑：ScrollBus、PointerBus、性能档位、矩形刷新调度、转场 reducer、滚动恢复与主题参数。
- 组件：真实 DOM 链接、8 篇文章、键盘焦点、WebGL/GLB 失败、减少动画、短文无目录、直接访问和浏览器返回。
- 命令：`pnpm --filter @valley/web check`、`pnpm --filter @valley/web exec tsc --noEmit`、受影响 Vitest、Web 全量测试、覆盖率与生产构建。
- 文档：encoding guard、`pnpm check:docs-links`、`pnpm check:plans-index`。

### 真实浏览器

- 视口：390、900、1366、1440、1920px；桌面 Chrome/Edge，Safari 与 iOS Safari 或等价真实设备环境。
- 路径：首页滚动与指针、文章显影与悬停、点击进入、浏览器返回、直接详情 URL、主题切换、移动菜单、快速滚动、resize、离开与返回。
- 第五、六轮专项：首页约 `1.4s` 首次入场落物、固定落点与回弹、指针连续跨屏移动及静止约 `600ms` 后的流体启停、全画布 WebGL 位移与透明区流光、首屏正向退场与反向恢复、慢速与快速滚动弯曲、停滚回正、深浅主题同动力学、GLB/WebGL 失败、移动端与减少动画降级。
- 状态：访客/站主、慢网、文章失败、无封面、纹理失败、GLB 失败、WebGL 禁用、context lost、减少动画。
- 证据：真实 DOM 与 WebGL 封面无可见错位；桌面常用设备稳定接近 60 FPS，中端手机降质后不低于 30 FPS；控制台无错误、无离屏持续渲染、无导航或滚动锁死。

## 非目标

- 不修改服务端接口、文章数据模型、专栏与标签语义，不新增人工精选或第二封面字段。
- 不在第一阶段重做图库、单图、关于或搜索的内容架构，不改创作室样式。
- 不复制 Haoqi 的 `hello` 模型、贴纸、字体、文案、声音或作品资产。
