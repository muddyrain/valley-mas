## 完成边界

- Webhook 与内部事件只接受不超过 256 KiB 的 JSON 对象，不支持文件输入和子工作流；投递输入按 Start 节点声明在运行时校验。
- 同一触发器下相同 `X-Valley-Delivery` 只创建一个任务。worker 发现任务已有运行记录时不会重放整图；中断运行进入可诊断失败，避免重复写操作。
- 死信队列、运行告警、租约续期、跨进程取消和外部事件连接器仍不在本批次完成范围。

- 计划勾选只代表真实代码和验证完成。
- 不新增只有图标和配置表单、但没有服务端执行器的节点。
- 每个新增节点都要说明输入、输出、副作用、权限、成本、失败语义与可重复验证路径。
