# 账号安全加固

> 状态：实现与自动化验证完成，生产迁移及真实 SMTP 回归待部署环境执行。

## 目标

- 密码重置或主动修改密码后，已签发的 JWT 立即失效。
- 邮箱验证码可在多实例间共享、仅可使用一次，并限制暴力尝试与发送频率。
- 找回密码不泄露邮箱是否已注册。
- 新密码改用 bcrypt 保存，既有 MD5 密码在一次成功登录后平滑升级。

## 实施边界

- `users.token_version` 作为会话版本；认证中间件校验 JWT 声明与当前版本一致。
- 验证码和发送频率持久化到 PostgreSQL/MySQL；请求方 IP 仅以 SHA-256 摘要保存。
- 保留旧 MD5 校验兼容，禁止在日志、接口或数据库中暴露明文验证码与密码。

## 验收

- 重置密码、修改密码后，旧 token 请求受保护接口返回 401。
- 验证码可跨进程验证，错误五次或成功一次后不能重放。
- 重置未注册或已禁用邮箱返回相同成功语义，且不发送验证码。
- 执行版本化迁移后，PostgreSQL 和 MySQL 迁移序列一致。

## 部署注意

- 上线前先执行 `go run ./cmd/migrate up`，再滚动发布服务实例。
- 在真实 SMTP 与反向代理环境复测重置邮件、来源 IP 识别与频率限制。
