# AI 图片创作工作台实施计划

> 日期：2026-07-23
> 设计：`docs/specs/2026-07-23-ai-image-studio-design.md`

- [x] 新增模板、创建、列表、详情和保存资源接口。
- [x] 增加输入边界、owner 隔离、异步状态与失败测试。

## Task 2：Web 图片创作页面

- [x] 新增 API 类型与请求封装。
- [x] 新增 Canvas 画布，支持绘制、擦除、撤销、素材摆放与导出。
- [x] 新增模板、可见的受控提示词、比例、模型感知的目标分辨率和模型设置；尺寸能力按模型而非中转 Provider 判断，支持参考图的 Seedream 4.0 与 GPT Image 2 4K 模型优先作为默认选择。
- [x] 对生成结果执行目标像素校验；尺寸不符时失败且不转存。
- [x] 复用提示词助手，根据当前画面描述生成可预览、确认回填的图片提示词。
- [x] 新增阶段生成动效、失败态、结果历史、下载和保存资源。
- [x] 接入路由、标题和侧栏入口。

- [x] 按 `.code-review/README.md` 加载适用规则并复核改动。

## Task 4：多模型协议适配与能力验证

- [x] 抽取统一图片生成接口和 SiliconFlow、Amux、ARK Provider Adapter。
- [x] 统一解析临时 URL 与 Base64 图片结果，修复上游成功但本地误判失败。
- [x] 将 `image_edit` 兼容迁移为 `reference_image`，用户侧统一显示“图片模型”。
- [x] 为模型目录增加能力验证状态、已验证能力和最近验证时间。
- [x] 增加 Provider 请求、响应、参考图与验证状态回归测试。
- [x] 完成 Web/Admin 运行时验收并同步长期文档。

## Task 5：画布体验与参考图遵循

- [x] 修复画布卡片被设置栏拉伸、共享选中按钮 hover 丢失背景的问题。
- [x] 修复 Slider 宽度为零导致画笔粗细和素材大小无法调整。
- [x] 素材按长边等比缩放，切换画布比例时不再拉伸变形。
- [x] 参考画布作为构图真源，模板与文字不得覆盖主体数量、轮廓、姿态和空间布局。
- [x] 生成设置和历史记录明确展示参考画布是否启用、是否随任务提交。

## Task 6：历史资产独立性与回放

- [x] 保存到资源库时复制生成文件；删除资源不会再删除创作历史的图片，旧的共用对象也会被保护。
- [x] 为使用参考画布的任务保存扁平画布快照，并固化当时的模板名称与中文提示词；历史卡片可预览结果与快照，并在再次创作时还原模板、描述、模型、尺寸和画布。
- [x] 目标像素不再作为失败门槛；所有有效图片都会保存，并记录实际返回尺寸。

## Task 7：智能体生图能力

- [x] 将 `image.generate` 作为受控智能体工具，复用既有图片生成计划、模型目录、存储和审计。
- [x] 为智能体版本增加默认图片模型、比例和清晰度，并在会话中支持临时参考图。
- [x] 将内置视觉风格与已安装技能收敛到同一个风格选择器，避免 `/` 技能与视觉风格形成重复入口；会话内持续展示当前选中的风格。
- [x] 图片工作台与智能体会话复用输入组件，统一参考图附件、发送/停止和生图 loading；图片工作台通过统一风格选择器使用内置风格或已安装技能，智能体保留 `/` 技能并按工具开关启用生图。
- [x] 补齐服务端与 Web 验证，同步长期项目说明。

## Task 8：生图多样性与博客封面收敛

- [x] 将题材上下文、用户画面要求与视觉风格拆分，避免文章正文或固定默认词覆盖真实创作意图。
- [x] 为无参考图生成增加精确、均衡、探索三档请求级变化策略，并保存不可变变体快照。
- [x] 工作流图片节点开放画面变化选项，相同固定提示词再次运行时由统一计划器生成新的构图方案。
- [x] 工作流图片节点开放创作用途与题材上下文；选择文章封面后复用博客封面助手的 `cover + subjectContext` 规划契约，不再把所有工作流生图固定为自由创作；存量 `image.generateCover` 也已从固定 ARK 提示词迁入同一计划器。
- [x] 博客封面助手移除二游角色固定提示词，改为标题、摘要和正文要点驱动，用户提示词仅作为可选补充要求。
- [x] 增加计划器、工作流透传、博客题材上下文和封面弹窗回归测试。

## Task 9：AI 创作画布重构

- [x] 抽离版本化 `CanvasDocument`、元素命令和统一撤销/重做历史，现有自由笔迹与素材改用同一文档状态。
- [x] 增加本地闭合填色，将封闭手绘转换为独立图形，支持选中、移动、改色、铅笔纹理、层级调整和删除。
- [x] 抽离 AI Canvas Adapter，统一导出整图参考与当前对象蒙版；整图参考继续复用现有图片生成请求。
- [x] 增加画布内的局部 AI 修改入口，将对象蒙版、用户指令和可追溯父生成记录接入现有 edits 接口。
- [x] 按 owner 持久化可编辑画布文档和素材图层，使用 revision 冲突保护与自动保存支持刷新和跨设备恢复。
- [x] 当前不引入对象分割、矢量化或 AI 结果图层重建：用户绘制的闭合图形和图片素材已可独立选择并生成蒙版，普通生成结果继续作为扁平位图图层；只有真实验收证明需要拆分 AI 位图内部对象时再扩展。

## Task 10：AI 画布独立页面

- [x] 新增受登录保护的 `/workbench/canvas` 页面，并同步侧栏入口与页面标题。
- [x] 从 `/workbench/images` 移除画布 Tab、画布参考开关和画布专属提交链路；AI 图片页收敛为对话生图。
- [x] 独立画布页保留画布比例、自由绘制、闭合填色、素材与对象编辑、撤销重做，并支持导出 PNG。
- [x] 旧图片历史中的画布快照在再次创作时按普通参考图附件恢复，不再恢复已移除的画布模式。

## Task 11：独立画布 AI 协作闭环

- [x] 在画布下方增加紧凑 AI 协作栏，只保留创作意图和支持参考图的模型选择，不恢复 AI 图片页的完整设置栏。
- [x] 将整张画布以 `free + precise + 1K` 固定策略提交到现有图片生成任务，并轮询展示真实生成阶段与失败结果。
- [x] 成功结果继续进入 owner 私有图片历史，并可读取为新图层加入当前画布。
- [x] 基于可追溯父生成记录接入对象蒙版的局部 AI 修改；本地任意素材不会被伪装成可编辑的父版本。
- [x] 使用当前 Chrome 登录态验证独立页面、AI 图片页拆分、绘制、比例切换、自动保存、刷新恢复和清空回写；未触发可能计费的真实模型生成。
