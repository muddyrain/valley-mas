# 标准智能体技能

> 状态：进行中

## 目标

将资源库中的技能收敛为可供智能体和工作流复用的标准技能包：导入 `SKILL.md` 与参考资料、按标签组织、在明确绑定后按 owner 解析为运行指令。

## 本期范围

- 兼容公开 GitHub 链接和 `npx skills add owner/repository --skill skill-name` 的来源语法；服务端只解析来源，不执行 `npx`。
- 保存并编辑技能标签，资源页支持标签筛选。
- 智能体版本配置和工作流 LLM 节点可选择最多 8 个 owner 私有技能。
- 运行时仅加载 `SKILL.md` 与 `references/`；`scripts/` 继续只读保存、展示，绝不执行或注入模型。

## 非目标与后续

- 不在本期实现脚本在线执行、容器隔离、依赖安装、网络策略或执行审计。
- 不实现第三方技能注册表搜索；短来源仅支持可确定的 GitHub `owner/repository`。
- 后续如开放脚本能力，必须先定义一次性执行授权、隔离运行环境、资源上限、网络白名单、审计和结果脱敏。
