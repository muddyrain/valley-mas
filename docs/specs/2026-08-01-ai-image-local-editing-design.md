# AI 图片局部编辑设计

> 状态：已实现，待真实模型验收
> 日期：2026-08-01

## 目标

为图片工作台中当前用户已成功生成的历史图提供局部重绘、擦除替换与扩图。三种交互统一为一次带蒙版的图片编辑请求，并生成新的不可变子版本。

## 契约

- `POST /ai/image-generations/:generationId/edits` 接收模型、创作类型、风格、画面描述、编辑模式、PNG 编辑画布和同尺寸 PNG 蒙版。
- `inpaint` 与 `erase_replace` 使用用户涂抹区域作为模型重绘范围；`outpaint` 使用浏览器扩展出的透明画布区域作为重绘范围。
- 服务端校验源图 owner、完成状态、蒙版格式和尺寸；额外参考图在局部编辑中被拒绝。
- 模型必须声明并已验证 `masked_edit`；`outpaint` 额外需要声明并已验证 `outpainting`。未验证模型不能由前端绕过调用。

## Provider 与数据边界

- OpenAI 兼容适配器以 multipart 向 `/images/edits` 发送 `image`、`mask`、`prompt` 和 `size`，其中 mask 明确为 `image/png`。
- ARK 与 SiliconFlow 当前适配器不接受蒙版，未通过专用协议验证前保持不可用。
- 编辑画布与掩码是请求态数据，不写入数据库、对象存储或 AI 审计；历史只保存 `edit_mode` 和现有的 `parent_generation_id`。

## 验收

1. 已验证编辑模型可以从历史图片打开编辑器并创建子任务。
2. 普通局部模式没有涂抹选区时不可提交；扩图模式生成透明扩展区域。
3. 删除子版本不影响父图；跨用户或未完成图片不能作为编辑源。
4. 不支持或未验证编辑能力的模型在 UI 和服务端均被拒绝。
