# 创作者智能体工具卡设计

> 状态：设计确认，分阶段实施中
> 日期：2026-08-08
> 范围：`apps/web` 智能体会话、`server` AI App 任务与内部工具运行时

## 目标

内容创作者在智能体会话中提交文字或私有附件。智能体通过结构化工具调用生成图片、创建文件或转换文件；参数不足，或普通对话必须由用户补充信息、确认偏好后才能继续时，先发起可视化澄清。生成和转换无需确认，保存文档、覆盖内容与发布博客必须由 owner 确认。

第一入口只放在智能体会话。底层工具契约独立于页面和模型，可被工作流与未来 MCP Adapter 复用；本期不建设对外 MCP Server。

## 用户流程

1. 用户输入需求并可上传文件。
2. 智能体根据工具 Schema 判断参数是否完整。
3. 缺少参数或需要用户选择方向时创建结构化澄清请求；用户可点击建议或直接回复。
4. 参数完整后创建后台任务，页面显示工具进度。
5. 成功结果以图片卡或文件卡展示，owner 可预览和下载。
6. 临时产物默认私有保存 72 小时；转为长期文档、覆盖内容或发布博客前必须确认。

## 工具与协议边界

内部工具继续注册在 `server/internal/ai/tools`。在现有 `Tool` 接口之外，通过可选元数据接口声明输入、输出、风险、确认策略和卡片类型，避免破坏 Life Trace 等既有工具。

第一批能力：

| 工具 | 输入 | 输出 | 确认 |
| --- | --- | --- | --- |
| `image.generate` | 文本、可选参考图 | 图片产物 | 否 |
| `image.convert` | owner 私有图片附件、目标格式 | JPG、PNG 或 WebP 文件 | 否 |
| `document.convert` | owner 私有 PDF 附件 | DOCX 文件与转换摘要 | 否 |
| `file.create` | 文件名、格式、文本 | Markdown、JSON 或 CSV 文件 | 否 |
| `document.export` | 文本、目标格式 | Markdown、PDF 或 DOCX 文件 | 否 |
| `document.save` | 临时产物、保存目标 | 长期文档 | 是 |
| `document.overwrite` | 临时产物、目标文档 | 更新后的文档 | 是 |
| `blog.publish` | 文档或草稿、发布参数 | 已发布博客 | 是 |

转换是确定性领域服务。模型只负责选择工具和补齐参数，不负责用自然语言伪造文件转换结果。

## 结构化卡片

工具与任务结果使用稳定类型，而不是让页面解析自由文本：

- `clarification`：问题、原因、建议答案及可选说明、是否阻塞、轮次上限、回答和解决状态。
- `tool_progress`：工具名、阶段、进度和可取消状态。
- `image_result`：图片预览、尺寸、格式和结果操作。
- `file_artifact`：文件名、类型、大小、过期时间和下载入口。
- `conversion_result`：源格式、目标格式、转换摘要和产物。
- `confirmation`：写操作目标、影响摘要和 owner 决定。
- `tool_error`：稳定错误码、用户可读说明和可重试状态。

任务阶段为 `needs_input / queued / validating / running / waiting_confirmation / succeeded / failed / cancelled`。页面不得仅凭中文状态文案推导业务状态。

## 澄清协议

基础澄清属于运行时协议，不依赖特定 Skill。创作采访 Skill 可以复用该协议形成更深入的逐轮访谈。

- `clarification.ask` 是每个智能体都具备的内部运行时工具，不依赖是否另外绑定了转换、生成或发布工具。
- 模型未调用工具而在普通回复中输出明确的邀请式追问时，服务端保守地将该追问转成同一结构化协议；若追问前已经给出连续编号的候选方案，则将方案标题和说明保存为可选择项。Web 只消费持久化结构，不解析 Markdown 猜测卡片。
- 用户补充作为同一运行的正式用户消息进入恢复上下文。澄清卡是持久时间线事件，回答后仍保留在发起它的用户消息之后，并切换为显示所选答案的只读状态；恢复中的活动任务与最终结果只挂在同一运行最后一条用户消息之后。

- 简单任务最多 1 轮，普通任务最多 3 轮，复杂任务最多 5 轮；服务端绝对上限 5 轮。
- 跳过非阻塞问题时使用安全默认值，并在结果中公开假设。
- 阻塞问题被跳过或拒绝后不得执行工具，也不得换一种说法重复追问。
- 达到上限仍缺少阻塞字段时，智能体说明缺失内容，用户通过普通对话继续补充。
- 图片转换的源文件和目标格式、写入目标和发布确认属于阻塞字段。

## 转换边界

图片第一版仅支持 WebP、JPG、PNG 互转。透明图片转 JPG 时必须使用明确的背景策略；动态 WebP、损坏文件和超限文件返回稳定失败，不覆盖源文件。

PDF 转 DOCX 的第一版目标是“尽力保留可编辑内容”，保留主要文字、段落、分页和可识别的图片/表格，不承诺像素级还原。加密、损坏、空白或超限 PDF 明确失败。扫描件 OCR 后置，不把空结果误报为成功。

## 临时产物与权限

- 所有产物按 owner、智能体、会话和任务隔离。
- 默认有效期为 72 小时，由服务端配置并返回 `expiresAt`。
- 下载必须经过认证和 owner 校验，不把永久公开 URL 当作权限边界。
- 保存为长期资产后取消临时过期语义。
- 清理任务删除过期数据库记录和对象存储文件；失败可重试并记录审计。

## 非目标

- 对外 MCP Server、外部客户端认证和工具市场。
- 任意格式互转、视频或音频转码、扫描 PDF OCR。
- Skill 脚本在线执行。
- 无确认覆盖、自动发布和公开临时文件。

## 验收标准

1. “把这张 WebP 转为 PNG”会调用正确工具并生成 owner 私有文件卡。
2. “帮我转换一下”不会猜目标格式，而是创建澄清问题卡。
3. 关闭并重新进入会话后，未过期的任务和产物仍可恢复、预览和下载。
4. PDF 转 DOCX 对正常文本 PDF 生成可打开的 DOCX；不支持输入返回明确错误。
5. 生成与转换不要求确认；保存、覆盖和发布无法绕过 owner 确认。
6. Web 定向测试、类型检查、静态检查，Server 定向与全量测试通过；真实浏览器覆盖澄清、进度、失败、下载、刷新恢复和确认。
7. 连续编号的多个方案能显示为带说明的选择项；选择后卡片保留且只读，同一运行同时最多显示一个活动响应状态。
