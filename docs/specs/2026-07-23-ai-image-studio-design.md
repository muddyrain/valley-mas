# AI 图片创作工作台设计

> 状态：V2 协议适配、能力验证、工作台视觉重构与生成计划分层已完成
> 日期：2026-07-27

## 产品目标

在 Web AI 工作台中新增独立的图片创作入口。用户可以绘制简笔画、摆放本地参考素材，或通过对话描述与修改图片，分别选择创作类型、视觉风格与输出比例，通过已启用的图片模型生成图片，并查看生成状态、历史结果、下载或保存到私有资源库。

完整创作体验落在独立页面；智能体后续只作为发起生成与跳转继续编辑的入口，不在首期把画布、素材和尺寸控制塞进聊天消息。

## 页面与交互

- 新增 `/workbench/images`，侧栏“创作”分组增加“AI 图片”。
- 桌面端以“画布 / 对话”双 Tab 组织核心创作区，右侧使用可滚动的粘性设置面板，并在面板头部汇总当前模型、清晰度、比例与目标尺寸；窄屏按创作区、设置区、历史区纵向排列。
- 画布首期支持选择、画笔、橡皮、撤销、清空、素材上传、素材移动、缩放和删除。
- 画笔粗细与素材大小使用共享 Slider；素材以长边为缩放基准并保持原始宽高比，切换画布比例时重新计算尺寸但不拉伸内容。
- 画布按选定比例导出为单张 PNG 参考图；原始参考图 data URL 只用于当前生成请求，不写入生成历史或审计日志。使用画布或对话引用上一张图片时额外尝试保存一张扁平快照，供历史预览与再次创作恢复；快照上传失败不阻断图片生成，且不保存逐笔轨迹或独立图层。
- 对话创作首条消息直接生成图片；后续消息默认跟随本次对话最近一张成功图片，也可锁定自己的任一成功历史图片，或切换为不使用参考图。使用历史图片生成时，结果保存单一父版本 ID，历史卡片可查看来源；删除父版本时只断开子版本的来源关系，不删除子版本结果。对话消息按当前用户持久化到服务端会话，图片结果继续进入 owner 私有历史。
- 任一成功历史图片可通过“基于此图”进入变体创作：用户必须填写新的修改要求，系统以当前右侧模型、比例和清晰度将该图作为受控参考图提交，并继续记录单一父版本。该入口只在已选模型支持 `reference_image` 时允许发起。
- 启用参考画布时，画布是主体数量、轮廓、姿态、取景、空间布局和相对比例的结构真源；创作类型、视觉风格和文字不能覆盖该结构。
- 画面描述支持调用已有提示词助手：以当前输入为视觉需求，选择文本模型生成扩写结果，预览并确认后才替换当前内容；空输入不触发生成。
- 创作类型由服务端白名单控制，只声明输出用途与结构约束，提供自由创作、壁纸、草图成图、文章封面、产品展示和角色头像；自由创作不注入隐藏用途提示。视觉风格独立控制色彩、材质、光线与渲染语言，提供内置风格，并把 owner 私有已安装技能约束为风格适配器。用户也可从 AI 资源中的 owner 私有提示词选择正文，填入当前对话或画布模式的画面描述；该选择不改变创作类型或视觉风格，也不自动提交生成。
- 创作类型侧栏提供可展开的快速示例和“换一些”操作。首次展示与后续轮换均来自服务端按创作类型维护的受控候选池；“换一些”即时返回三条不同于当前项的画面描述，不调用外部模型，也不产生 AI 用量记录。
- 输出比例支持 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`；目标分辨率由所选模型和输入类型共同决定。`doubao-seedream-4-0-*` 提供 `1K`、`2K`、`3K`、`4K`；`gpt-image-2` 包括参考图编辑在内均提供 `1K`、`2K`、`4K`，其 `16:9` 4K 目标尺寸为 `3840×2160`；其他当前模型只提供 `1K`、`2K`。目标尺寸是发送给 Provider 的请求意图，不是返回像素必须精确相等的合同。4K 请求返回的有效图片只要达到该目标对应的 1K 宽高基线，就按实际像素入库并显示为完成；低于最低可用尺寸的明显异常结果才标记为失败。模型目录同时返回纯文字和参考图两套可选分辨率。
- 生成结果按 owner 私有展示，可下载并保存为私有资源；方形结果默认保存为头像，其他比例默认保存为壁纸。
- 创作历史卡片不展示用户提示词，改为图片优先的信息结构；卡片只呈现清晰度、实际分辨率、画面比例、模型、Provider、创作类型、参考图与资源保存状态，并提供下载、预览、保存、基于此图、再次创作、画布快照、详情和删除操作。详情抽屉补充视觉风格；状态、模型、仅看收藏和分页保持在 URL query，仍不展示提示词。

## 生成状态与动效

服务端生成任务使用 `queued`、`running`、`succeeded`、`failed` 状态，并提供 `preparing`、`generating`、`storing`、`completed` 阶段。前端轮询任务状态，在画布上展示与当前阶段对应的骨架占位和短状态文案，不伪造百分比进度；页面初次加载与创作历史加载也使用与最终布局同构的骨架屏，避免内容跳变。

提交前在设置栏显示本次请求摘要：模型、目标尺寸、参考图来源和费用边界。选择 4K 时，摘要必须与实际接口尺寸一致；请求提交后，服务商可能已按一次调用计费。失败任务只允许用户恢复原参数后主动再次提交，系统不得自动重试。

画布与对话 Tab 的选中指示器使用短时 FLIP 布局过渡，图片卡片只保留轻量的预览缩放和边框、阴影反馈。表现动效只表达真实状态或空间关系，不声称展示模型扩散中间帧，不使用持续漂浮、颗粒噪点或装饰性扫描线。所有持续动画必须响应 `prefers-reduced-motion`；任务失败后停止动画并提供可重试信息。

## 服务端契约

- `GET /ai/image-options`：返回受控创作类型、内置与 owner 私有视觉风格、比例和尺寸选项；旧 `/ai/image-presets` 暂时保留兼容。
- `POST /ai/image-recipes/:recipeId/sample-prompts`：从对应创作类型的受控候选池轮换三条快速示例；请求可携带当前展示项以避免立即重复，响应中的 `model` 固定为 `local-curated`；旧模板路径暂时保留兼容。
- `GET /ai/image-generations`：返回当前用户最近的生成记录。
- `POST /ai/image-generations`：创建异步生成任务，输入模型目录 ID、`recipeId`、可选 `styleProfileId`、`brief`、比例、清晰度、最多三张 data URL 参考图，或传入一条当前用户已有的 `referenceGenerationId` 作为上一张图片参考；用户直接提交的单张参考图限制为 5MB，服务端已持久化的生成结果按 30MB 下载上限复用，不套用上传限制；旧 `presetId/skillId/prompt` 字段暂时保留兼容。
- `GET /ai/image-generations/:generationId`：读取单条任务状态。
- `PATCH /ai/image-generations/:generationId/favorite`：更新当前用户单条生成记录的收藏状态。
- `DELETE /ai/image-generations/:generationId`：删除当前用户已完成或失败的生成记录及其历史图片；生成中的任务暂不允许删除。
- `POST /ai/image-generations/:generationId/resource`：把成功结果登记为私有资源。

图片生成继续通过数据库模型目录解析 Provider。所有图片模型要求 `image_generation`；带参考图时额外要求 `reference_image`。“支持参考图”是生图模型的附加输入能力，不再作为独立的“编辑模型”呈现。

服务端 `AIImagePlanner` 先把画面描述、创作类型、视觉风格与参考图约束解析成不可变生成计划，再由统一图片生成接口接收编译后的提示词、受控尺寸和参考图。编译顺序为安全与模型能力、参考图结构、创作类型、用户描述、视觉风格和质量约束；各层拥有独立控制域，视觉风格不能覆盖参考图结构、主体身份与数量、输出用途或用户明确描述。Provider Adapter 只处理具体协议：

- SiliconFlow Adapter 使用兼容 JSON 生图协议和 Provider 对应尺寸字段。
- Amux Adapter 使用 OpenAI Images 生图协议；无参考图走 JSON `/images/generations`，有参考图走 multipart `/images/edits`。
- ARK Adapter 使用 ARK 图片 JSON 协议。
- Adapter 统一解析临时 URL、`b64_json` 等结果格式，调用方不再感知 Provider 字段差异。

模型目录通过 `image_protocol` 保存模型级图片协议，默认 `auto` 按 Provider 匹配，也允许兼容网关显式选择协议。模型目录同时保存管理员声明的能力；连接检测对声明能力执行真实最小调用，并记录未验证、部分验证、已验证或验证失败状态。检测可能产生费用，管理端必须明确提示且不得自动触发。Provider 密钥只从服务端环境变量读取。

## 数据与隐私

- `ai_image_generations` 保存 owner、模型、当时的创作类型名称与受控指令、视觉风格来源/标识/不可变指令快照、用户画面描述、比例、状态、结果资源元数据、扁平画布快照、安全错误摘要和 owner 私有的收藏状态。底层继续复用既有 `preset_*` 与 `skill_*` 列兼容旧数据，新增 `style_profile_*` 列保存明确的风格快照；收藏不复用资源库收藏，因为生成历史在保存为资源前不是资源实体。
- 不保存参考图 data URL、逐笔轨迹、独立图层、模型原始返回体或完整调用日志；AI 用量审计只记录调用元数据。
- 对话消息和会话均按 owner 隔离持久化到服务端；删除图片生成记录不会删除文字消息，但会解除对应图片关联。
- 成功图片先转存 TOS，再进入历史；远端临时 URL 不直接作为长期资产。
- 保存到资源库时复制生成图片为资源库独立对象并记录 `resource_id`；删除资源时仅解除关联，历史原图和画布快照继续保留。
- 用户删除生成历史时，同时清理历史原图和画布快照；已经保存到资源库的独立副本不受影响。

## 失败语义

- `400`：提示词、比例、清晰度、参考图或保存类型不合法。
- `404`：生成记录不存在或不属于当前用户。
- `409`：任务尚未成功或结果已经保存。
- `502`：读取上一张图片参考失败。
- `503`：模型、Provider 或 TOS 未配置。
- 异步上游失败写入任务 `failed`，前端读取安全错误信息；原始上游错误只进入服务端安全摘要与 AI 用量审计。
- 上游 HTTP 成功但结果格式无效属于响应解析失败；URL、Base64 等合法结果必须先由 Adapter 归一化，不能仅因缺少 URL 把成功调用误报为失败。

## 非目标

- 当前不做蒙版局部重绘、扩图、图层持久化、多人协作、批量组图、生成任务取消、真正的扩散预览帧或智能体图片附件。AMUX 通用编辑端点接受可选 `mask`，但在当前 `gpt-image-2` 专属能力未经受控验证前，不能将该能力展示为可用。
- 首期不新增第三方画布依赖，使用浏览器 Canvas 完成有限编辑能力。
