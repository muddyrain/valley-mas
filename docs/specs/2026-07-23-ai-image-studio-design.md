# AI 图片创作工作台设计

> 状态：AI 图片工作台继续生效；V5 独立 AI 画布与后续视觉企划页面均已移除
> 日期：2026-08-08

> [!NOTE]
> 下文关于独立 AI 画布、`CanvasDocument` 和局部蒙版的内容仅记录 V5 历史实现；`/workbench/canvas` 当前没有产品入口。旧数据与接口暂留兼容，后续删除或迁移需单独确认数据策略。

## 产品目标

在 Web AI 工作台中提供两个职责独立的创作入口：AI 图片负责通过对话描述与连续修改生成图片，AI 画布负责自由绘制、闭合填色、素材组合，以及以整张画布为参考继续生成。AI 画布只保留意图和参考图模型这两个协作必需输入，不复制 AI 图片页的创作类型、风格、清晰度等完整设置；画布工具也不占用 AI 图片的主要创作区。

完整创作体验落在独立页面；智能体后续只作为发起生成与跳转继续编辑的入口，不在首期把画布、素材和尺寸控制塞进聊天消息。

## 页面与交互

- `/workbench/images` 对应侧栏“AI 图片”，以图片对话为唯一核心创作区；右侧生成设置只保留创作类型、模型、比例、清晰度和参考图等真实生图参数。窄屏按对话区、设置区、历史区纵向排列。
- `/workbench/canvas` 对应侧栏“AI 画布”，画布下方提供紧凑的 AI 协作栏，只选择支持 `reference_image` 的图片模型并输入创作意图；不展示目标分辨率、创作类型、视觉风格等完整生成设置。
- 独立画布使用版本化 `CanvasDocument` 统一管理自由笔迹、素材和闭合图形，并支持选择、画笔、橡皮、闭合填色、撤销/重做、素材上传、对象移动、缩放、改色、纹理、层级调整、删除、比例切换和 PNG 导出。闭合填色与纹理渲染在浏览器本地即时完成，不为每个 pointer 事件调用模型。
- 画笔粗细与素材大小使用共享 Slider；素材以长边为缩放基准并保持原始宽高比，切换画布比例时重新计算尺寸但不拉伸内容。
- 画布可按选定比例导出单张 PNG，也可把当前整图作为唯一参考，以 `free + precise + 1K` 固定策略调用现有图片生成任务；页面轮询真实生成阶段，成功结果进入 owner 私有图片历史，并可作为新图层加入当前画布。加入的 AI 结果会保留父生成记录；用户选择闭合图形或图片素材后，可把整图与对象蒙版提交到现有 edits 接口执行局部修改。只有模型声明并已验证 `masked_edit` 时才开放提交。
- 版本化 `CanvasDocument` 按 owner 保存单一当前工作区，700ms 防抖自动保存并使用 revision 乐观并发保护；页面刷新或换设备后恢复比例、笔迹、图形、图片图层与可追溯父版本。图片素材以内嵌安全 data URL 保存，单文档最多 32MiB、最多 3 张图片、单图最多 8MiB且图片总量最多 20MiB。
- 对话创作首条消息直接生成图片；后续消息默认跟随本次对话最近一张成功图片，也可锁定自己的任一成功历史图片，或切换为不使用参考图。使用历史图片生成时，结果保存单一父版本 ID，历史卡片可查看来源；删除父版本时只断开子版本的来源关系，不删除子版本结果。对话消息按当前用户持久化到服务端会话，图片结果继续进入 owner 私有历史。
- 任一成功历史图片可通过“基于此图”进入变体创作：用户必须填写新的修改要求，系统以当前右侧模型、比例和清晰度将该图作为受控参考图提交，并继续记录单一父版本。该入口只在已选模型支持 `reference_image` 时允许发起。
- 任一成功历史图片也可进入局部编辑：用户在位图画布中涂抹选区后，以“局部重绘”或“擦除替换”创建子版本；扩图会先在浏览器中构造更大画布和透明扩展区域，再由模型补全。三种编辑均要求模型声明且已通过 `masked_edit`，扩图额外要求已通过 `outpainting`。编辑画布和 PNG 蒙版只在请求期间存在，不写入生成历史或审计日志。
- 使用参考图时，参考图是主体数量、轮廓、姿态、取景、空间布局和相对比例的结构真源；创作类型、视觉风格和文字不能覆盖该结构。
- 画面描述支持调用已有提示词助手：以当前输入为视觉需求，选择文本模型生成扩写结果，预览并确认后才替换当前内容；空输入不触发生成。
- 创作类型由服务端白名单控制，只声明输出用途与结构约束，提供自由创作、壁纸、草图成图、文章封面、产品展示和角色头像；自由创作不注入隐藏用途提示。视觉风格独立控制色彩、材质、光线与渲染语言，提供内置风格，并把 owner 私有已安装技能约束为风格适配器。用户也可从 AI 资源中的 owner 私有提示词选择正文，填入当前对话的画面描述；该选择不改变创作类型或视觉风格，也不自动提交生成。
- 创作类型侧栏提供可展开的快速示例和“换一些”操作。首次展示与后续轮换均来自服务端按创作类型维护的受控候选池；“换一些”即时返回三条不同于当前项的画面描述，不调用外部模型，也不产生 AI 用量记录。
- 输出比例支持 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`；目标分辨率由所选模型和输入类型共同决定。`doubao-seedream-4-0-*` 提供 `1K`、`2K`、`3K`、`4K`；`gpt-image-2` 包括参考图编辑在内均提供 `1K`、`2K`、`4K`，其 `16:9` 4K 目标尺寸为 `3840×2160`；其他当前模型只提供 `1K`、`2K`。目标尺寸是发送给 Provider 的请求意图，不是返回像素必须精确相等的合同。4K 请求返回的有效图片只要达到该目标对应的 1K 宽高基线，就按实际像素入库并显示为完成；低于最低可用尺寸的明显异常结果才标记为失败。模型目录同时返回纯文字和参考图两套可选分辨率。
- 生成结果按 owner 私有展示，可下载并保存为私有资源；方形结果默认保存为头像，其他比例默认保存为壁纸。
- 创作历史卡片不展示用户提示词，改为图片优先的信息结构；卡片只呈现清晰度、实际分辨率、画面比例、模型、Provider、创作类型、参考图与资源保存状态，并提供下载、预览、保存、基于此图、再次创作、参考图快照、详情和删除操作。详情抽屉补充视觉风格；状态、模型、仅看收藏和分页保持在 URL query，仍不展示提示词。

## 生成状态与动效

服务端生成任务使用 `queued`、`running`、`succeeded`、`failed` 状态，并提供 `preparing`、`generating`、`storing`、`completed` 阶段。前端轮询任务状态，在对话消息中展示与当前阶段对应的骨架占位和短状态文案，不伪造百分比进度；页面初次加载与创作历史加载也使用与最终布局同构的骨架屏，避免内容跳变。

提交前在设置栏显示本次请求摘要：模型、目标尺寸、参考图来源和费用边界。选择 4K 时，摘要必须与实际接口尺寸一致；请求提交后，服务商可能已按一次调用计费。系统不得自动重试；图片对话中的失败气泡允许用户手动重试，按原任务参数创建新任务，可能产生新的调用费用。其他历史任务仍可恢复原参数后主动再次提交。

图片卡片只保留轻量的预览缩放和边框、阴影反馈。表现动效只表达真实状态或空间关系，不声称展示模型扩散中间帧，不使用持续漂浮、颗粒噪点或装饰性扫描线。所有持续动画必须响应 `prefers-reduced-motion`；任务失败后停止动画并提供可重试信息。

## 服务端契约

- `GET /ai/image-options`：返回受控创作类型、内置与 owner 私有视觉风格、比例和尺寸选项；旧 `/ai/image-presets` 暂时保留兼容。
- `POST /ai/image-recipes/:recipeId/sample-prompts`：从对应创作类型的受控候选池轮换三条快速示例；请求可携带当前展示项以避免立即重复，响应中的 `model` 固定为 `local-curated`；旧模板路径暂时保留兼容。
- `GET /ai/image-generations`：返回当前用户最近的生成记录。
- `GET /ai/canvas-document`：读取当前用户的可编辑画布工作区；尚未保存时返回 `null`。
- `PUT /ai/canvas-document`：按 `expectedRevision` 保存当前用户的版本化画布文档；并发版本过期返回 409，不覆盖其他页面的新内容。
- `POST /ai/image-generations`：创建异步生成任务，输入模型目录 ID、`recipeId`、可选 `styleProfileId`、用户指令 `brief`、仅作为题材来源的 `subjectContext`、`variationMode`（`precise` / `balanced` / `exploratory`）、比例、清晰度、最多三张 data URL 参考图，或传入一条当前用户已有的 `referenceGenerationId` 作为上一张图片参考；无参考图且未指定变化模式时默认 `balanced`，带参考图时默认 `precise`；用户直接提交的单张参考图限制为 5MB，服务端已持久化的生成结果按 128MiB 下载上限复用，不套用上传限制；生成结果支持 JPG、PNG、WebP、GIF、AVIF 与 BMP 等安全栅格格式，SVG 不接纳；旧 `presetId/skillId/prompt` 字段暂时保留兼容。
- `GET /ai/image-generations/:generationId`：读取单条任务状态。
- `PATCH /ai/image-generations/:generationId/favorite`：更新当前用户单条生成记录的收藏状态。
- `DELETE /ai/image-generations/:generationId`：删除当前用户已完成或失败的生成记录及其历史图片；生成中的任务暂不允许删除。
- `POST /ai/image-generations/:generationId/resource`：把成功结果登记为私有资源。

图片生成继续通过数据库模型目录解析 Provider。所有图片模型要求 `image_generation`；带参考图时额外要求 `reference_image`。“支持参考图”是生图模型的附加输入能力，不再作为独立的“编辑模型”呈现。

服务端 `AIImagePlanner` 先把题材上下文、用户画面要求、创作类型、视觉风格、请求级变化策略与参考图约束解析成不可变生成计划，再由统一图片生成接口接收编译后的提示词、受控尺寸和参考图。题材上下文只提供文章或业务事实，不作为可执行指令；`balanced` 和 `exploratory` 为每次新请求选择不同的构图、视角、光线、配色与画面节奏组合，`precise` 不注入自动变化。变体只填补用户未指定的视觉决策，不能覆盖参考图结构、主体身份与数量、输出用途或用户明确描述；Provider Adapter 只处理具体协议，不承担随机化逻辑：

- SiliconFlow Adapter 使用兼容 JSON 生图协议和 Provider 对应尺寸字段。
- Amux Adapter 使用 OpenAI Images 生图协议；无参考图走 JSON `/images/generations`，有参考图走 multipart `/images/edits`。
- ARK Adapter 使用 ARK 图片 JSON 协议。
- Adapter 统一解析临时 URL、`b64_json` 等结果格式，调用方不再感知 Provider 字段差异。

模型目录通过 `image_protocol` 保存模型级图片协议，默认 `auto` 按 Provider 匹配，也允许兼容网关显式选择协议。模型目录同时保存管理员声明的能力；连接检测对声明能力执行真实最小调用，并记录未验证、部分验证、已验证或验证失败状态。检测可能产生费用，管理端必须明确提示且不得自动触发。Provider 密钥只从服务端环境变量读取。

## 数据与隐私

- `ai_image_generations` 保存 owner、模型、当时的创作类型名称与受控指令、视觉风格来源/标识/不可变指令快照、题材上下文、用户画面描述、变化模式/种子/指令快照、比例、状态、结果资源元数据、可恢复的扁平参考图快照、安全错误摘要和 owner 私有的收藏状态。历史记录迁移为 `precise`，新请求由计划器按是否存在参考图选择默认变化模式；收藏不复用资源库收藏，因为生成历史在保存为资源前不是资源实体。
- 图片生成记录不保存请求参考图 data URL、模型原始返回体或完整调用日志；AI 用量审计只记录调用元数据。独立 AI 画布的逐笔轨迹、图形和最多三张图片图层仅保存在 owner 私有的 `ai_canvas_documents` 当前工作区，不写入生成历史或 AI 审计。
- 对话消息和会话均按 owner 隔离持久化到服务端；删除图片生成记录不会删除文字消息，但会解除对应图片关联。
- 成功图片先转存 TOS，再进入历史；远端临时 URL 不直接作为长期资产。
- 保存到资源库时复制生成图片为资源库独立对象并记录 `resource_id`；删除资源时仅解除关联，历史原图和参考图快照继续保留。
- 用户删除生成历史时，同时清理历史原图和参考图快照；已经保存到资源库的独立副本不受影响。

## 失败语义

- `400`：提示词、比例、清晰度、参考图或保存类型不合法。
- `404`：生成记录不存在或不属于当前用户。
- `409`：任务尚未成功或结果已经保存。
- `502`：读取上一张图片参考失败。
- `503`：模型、Provider 或 TOS 未配置。
- 异步上游失败写入任务 `failed`，前端读取安全错误信息；原始上游错误只进入服务端安全摘要与 AI 用量审计。
- 上游 HTTP 成功但结果格式无效属于响应解析失败；URL、Base64 等合法结果必须先由 Adapter 归一化，不能仅因缺少 URL 把成功调用误报为失败。

## 非目标

- 当前不做多人实时协作、画布版本时间线、批量组图、真正的扩散预览帧、对象分割、矢量化或 AI 位图内部图层重建。画布局部修改只以已加入画布的 owner 私有成功生成记录作为可追溯父版本，不把任意本地图片伪装成可编辑父版本；未通过模型能力探测的 Provider 不开放提交。
- 首期不新增第三方画布依赖，使用浏览器 Canvas 完成有限编辑能力。
