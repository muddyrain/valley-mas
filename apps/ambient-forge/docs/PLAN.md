# Ambient Forge v0.1 计划

## 目标

证明一个核心体验：用户打开页面即看到以主岛为中心、同时向高空与下层延展的程序化浮空群岛；用户可直接聚焦八处地标、启动自动巡游，或用天气预设与摄影模式塑造画面。加载并播放本地音乐后，低频推动云海与岛屿轻微呼吸，中频推动植物摇摆，高频唤醒萤火虫、晶石与星屑。

## 非目标

- 不做多场景平台、编辑器、商城、登录、服务端、真实天气、定位或系统音频捕获。
- 不做 MP4、GIF、离线逐帧渲染、物理流体、写实雪地形变或可编辑地形。
- 不引入外部模型、HDRI、图片、字体或音频资产。

## 技术与体验约束

- React 19 + Vite 6 + TypeScript + 直接 Three.js；Web Audio 负责本地音乐分析与程序化环境声。
- 场景只消费经过 clamp 和平滑的 `AmbientInputs`，不依赖 UI、媒体元素或未来天气来源。
- 桌面优先，390px 宽度仍可操作；支持 reduced-motion、页面隐藏降频和完整资源回收。
- 导出只提供浏览器实际支持的 10 秒 WebM；无音频时明确说明。

## 后续迭代路线图（v0.2+）

第 1–5 项已经完成。原第 6–10 项暂缓，不再作为当前开发队列；下一批转向 NPC 居民、场景内移动与 NPC 视角。

1. [x] 自适应画质：根据 FPS 自动降级阴影、粒子和云量，稳定后再逐步恢复。
2. [x] LOD 与 `InstancedMesh`：对树木、草、云和远景岛进行批量实例化，继续降低 draw call。
3. [x] 后处理懒加载：摄影景深只在启用时创建，并使用半分辨率渲染。
4. [x] 天气生命周期：增加风暴云前沿、远近雷声、积水增长、冻结与融雪水流。
5. [x] 水体 3.0：增加瀑布折射、崖壁湿痕、动态泡沫和水潭波纹传播。

### 当前优先方向：NPC 居民与视角

6. [x] NPC 居民：先加入主岛旅人、港口工匠和温室园丁三名程序化低多边形角色，具备可辨识的造型、名称与职业。
7. [x] NPC 移动与行为：每名 NPC 沿所属区域的路点网络移动，并在行走、停留、观察和工作状态间切换；天气与昼夜影响移动速度和活动倾向。
8. [x] NPC 视角：支持点击 NPC 聚焦、跟随视角和第一人称视角；切换 NPC 或退出视角时平滑过渡并恢复之前的自由镜头。

NPC 运行时集中在独立 `NpcSystem` module：外部只负责逐帧更新、读取 NPC 快照和取得镜头姿态；路径插值、行为状态机、肢体动画、天气响应和质量档裁剪保留在 module 内部。高频状态不进入 React。第一人称默认不加入行走镜头晃动，`reduced-motion` 下进一步收敛过渡。

### 暂缓方向

- 世界活动：飞艇进出港、吊机装卸、温室植物生长和灯光作息。
- 季节与生态区：春夏秋冬、不同植被和积雪规律、区域天气差异。
- 探索交互：模型详情、隐藏地标和收集式图鉴。
- 摄影与巡游升级：自定义镜头轨迹、保存机位、高分辨率截图和分享场景配置。
- 空间音频：瀑布、风车、温室、港口和雷声按距离与方向混音。

第 1–3 项已于 2026-08-10 完成：用户质量档作为自适应上限，持续低帧率逐档降级并在稳定后恢复；树叶细节、草叶、云和远景岛预算随有效质量档裁剪；景深后处理拆为独立异步 chunk，关闭后释放，并以主画面 50% 分辨率渲染。

第 4–5 项已于 2026-08-10 完成：风暴云前沿按天气生命周期推进与退去，闪电触发远近交替雷声；地表积水会增长、冻结并在回暖时形成融雪水流；瀑布增加物理折射层、动态崖壁湿痕、流量驱动泡沫与受冰面抑制的传播波纹。

第 6–8 项已于 2026-08-10 完成：岚、铆钉和苔芽分别拥有旅人背包与围巾、工匠护目镜与工具、园丁草帽与浇水壶等职业细节；三人沿主岛、港口和温室路线循环活动，天气与昼夜影响步速；控制面板和模型点击均可进入跟随或第一视角，退出时平滑恢复自由镜头。

## v0.1 验收

- 项目 test、typecheck、check、build 全部通过。
- 默认跟随本地时间，手动时间与四种天气均连续变化。
- 本地音乐可选择、播放、暂停、清除，三频映射彼此不同且平滑。
- 环境声只在交互后启动，可调节、关闭并正确清理。
- 质量档位真实影响 DPR、阴影和粒子数量。
- 鼠标左键拖拽时场景跟随手势方向环绕，滚轮缩放有边界，双击可复位到默认构图。
- 浮岛岩层、木屋屋瓦与木构、植被和地表具备可辨识的几何及材质层次。
- 瀑布、水雾、营火、余烬、水井、围栏、路灯和灌木具备独立几何层次，并响应质量档、昼夜或天气信号。
- 云海由暗底、主体和高光冠组成簇状体积；风暴云独立变暗并加速推进，质量档真实改变可见云团预算。
- 风车叶片随风速连续转动；风车副岛、木桥、长椅、花箱、井壁石块与灯笼框架从自由视角下可辨识。
- 默认构图同时展示主岛、灯笼庭院岛与晶石林岛；环绕后可辨识遗迹水池岛，远景岛链随质量档裁剪但不移除三座主题副岛。
- 三座主题副岛共享昼夜、雨雪、风场与积雪信号；悬索桥连接主岛与灯笼庭院岛，雪天桥板和副岛顶部具有独立积雪层。
- 默认总览同时呈现高空天文台和下层瀑布洞穴的垂直层次；聚焦后可辨识天文台穹顶、望远镜、黄铜栏杆，以及洞穴入口、水潭、栈道、晶石和独立瀑布。
- 镜头面板提供总览、天文台、瀑布洞穴、灯笼庭院、晶石林、遗迹水池、空中港口和玻璃温室八处书签；点击可识别岛屿同样聚焦，自动巡游按顺序切站，拖拽或滚轮操作立即接管。
- 镜头过渡按真实时间推进，不因后台降频或高刷新率长期停在半路；双击画布返回总览。
- 飞鸟群和飞艇持续穿行于近中远景，风力影响移动节奏，昼夜影响飞艇灯光；质量档裁剪飞鸟和云影预算但保留飞艇及两座新增地标。
- 雨天主岛低洼处出现水面和涟漪，云层投下缓慢移动的阴影；下层水潭、洞穴晶石和瀑布继续响应昼夜、雨雪、风场与音乐信号。
- 瀑布具有分股水带、顶部泡沫、落水水雾、下层承水岩台、冲击池与扩散水纹；高空薄云与分层云带按质量档裁剪，雷暴可出现短促闪电。
- 地表湿度在停雨后缓慢回落，积雪在暴雪中逐步覆盖岛面、屋顶与模型细节，停雪后保留并随晴天或降雨逐渐融化。
- 空中港口具备泊位、吊机、货箱、信号塔与夜间信标；玻璃温室具备黄铜框架、透明屋面、植物床、灌溉管线和积雪层。
- 细雨、雷暴、暴雪、晨雾和金色黄昏五套预设同步调整时间、天气、强度与风力；手动修改任一环境参数后退出预设状态。
- 摄影模式隐藏常规控制面板，提供自然、暖色、冷色和电影滤镜、三分网格、景深预览与 PNG 保存；`P` 进入或退出，`Escape` 退出。
- 居民面板提供岚、铆钉和苔芽三名 NPC；各自具有可辨识的职业造型、区域路线、行走与工作动画，并可切换跟随和第一视角，`Escape` 或返回按钮恢复自由镜头。
- 无风雨近似垂直下落；强风同步改变雨线倾角、横向速度、草木和烟的方向，并出现地表溅水与压暗的暴风云层。
- 全屏状态与浏览器同步；录制防重复并产出真实 WebM。
- 1440×900、1024×768、390×844 无横向溢出，Console 无错误。
