# 小队指挥与单人任务派遣并存

2026-09-08，用户选择“小队移动/集火 + 单人任务派遣”，允许查看或更换搜索执行者。这个边界保留路线、火力站位与搜索分工的取舍，同时控制逐个角色操作的负担；后续命令和任务设计须区分掩护成员与搜索执行者，不能把所有成员永久绑定到一个共同搜索目标。

用户随后确认：默认自动派最近的可用成员，同一时间最多一人搜索；搜索者在可见入口工作，可以受伤，遇险暂停并自卫。这一方向现已落入切片，验证状态见 [PLAN.md](../PLAN.md)。每名成员独立移动和战斗不在该操作方向内。

2026-09-08 补充：用户再次要求核查原作的多地搜索与操作，并授权开始实施。新证据见 [研究记录](../DEADLY_DAYS_CONTROLS_RESEARCH.md)；本 ADR 的“全图一个任务”是当时切片的简化，不是原作规则。0.3.0 已由 [ADR-0003](0003-parallel-search-and-direct-controls.md) 替代该上限和旧键鼠方案；本页保留历史，不再作为并发限制。每个目标一名执行者、独立掩护命令及入口遇险自卫仍保留。
