# 多点搜索与直接小队操作

2026-09-08，用户要求开始实现，基础操作与原版 Deadly Days 一致。本决策替代 ADR-0001 的全图单搜索上限；依据为 [操作核查](../reference/deadly-days-reference.md)，实施状态见 [PLAN](../PLAN.md)。

本版 0.3.0 保留五日循环，优先实现已核实的基本指挥：点击地面设置集合点、按住左键持续跟随、Ctrl 停步向鼠标位置射击、Space 暂停并可下令、WASD 与鼠标拖拽镜头、滚轮缩放。右键拖拽镜头，同时支持中键；右键不再重复左键场景命令。X/按钮停止，F 保留锁定集火，R 全队召回，E 归航；Space 与 Esc 分别为战术暂停、暂停菜单。能力系统不是本次范围。

每处搜索目标一个任务、一个执行者，每名队员最多持有一个任务；并行数由可用成员决定，允许三人全搜。自动派最近的可抵达空闲成员，没有人时明确反馈。点击场景中已在搜索的地点取消该任务；侧栏可查看任务，单独取消或显式改派。忙于其他任务的角色不能被悄悄抢走。点击完成地点不重复奖励，取消/改派保留进度。

普通移动与指向射击控制未执行搜索任务的成员；搜索者自己的遇险自卫独立处理。Ctrl 不为追敌离开阵位，也不会停止远处搜索；远程朝指定方向开火，可落空、消耗弹药并受射程和遮挡约束，近战只攻击近处敌人。松开 Ctrl 后在当前位置自动迎敌。按住左键从地面开始才启动连续带队，拖过建筑不连发搜索；从 UI 或搜索目标开始的按压不转成带队，释放与窗口失焦清除持续输入。

单独取消、完成和阵亡只释放对应任务；最后一个搜索者也能召回。全队召回释放全部任务，归航则召回全部存活成员并等待到齐。HUD 同时显示全部地点的执行者、进度和当前选中任务，不能只显示最后一个任务。

建筑内免伤、出入门时间和取消进度在原作尚未实机核实，本版保留现有入口暴露、自卫中断的本作规则并明确记录；不会宣称全部玩法 1:1 复刻。美术资产不变，复用既有任务圈与指令标记。并行后的路线收益与天黑时间必须重新探测，验证三人全搜不会造成任务卡死或重复奖励。

验收：多任务各自推进、独立取消与改派、任务中死亡、无人可派、零掩护、共同完成与奖励一次性、远处搜索者回到巴士、跟随拖拽与 UI 隔离、按住/松开 Ctrl 的伤害/弹药/遮挡、暂停时不推进世界但能下令、WASD 不再触发 S 停止、失焦与 Debug 释放输入；原有跨日与存档回归、原生渲染和 Windows 独立 EXE 均重跑。
