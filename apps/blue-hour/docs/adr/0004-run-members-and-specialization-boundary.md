# 开局专精属于本轮，成员身份独立于角色模板

2026-09-09 用户确认先做三套起始套餐、现有角色随机抽两名和局内食物训练，暂缓跨局专精经验与解锁。专精选择只产生草稿，确认并成功保存才替换当前 Run；成员以本轮 ID 引用角色模板，成长、装备与伤亡属于成员，不能通过改写共享模板获得成长。
