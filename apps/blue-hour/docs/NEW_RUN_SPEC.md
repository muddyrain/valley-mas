# 开局与基地准备基础版本

状态：2026-09-09 Q1～Q4 已确认；0.4.0 已实现、构建并完成独立启动验证；详见 [VALIDATION](VALIDATION.md)。证据见 [原作核查](DEADLY_DAYS_NEW_RUN_RESEARCH.md)，术语见 [CONTEXT](../CONTEXT.md)。

## 已确认目标

新游戏 → 切换三个开局专精 Tab → 确认创建 → 随机两名成员 → 基地准备 → 现有行动 → 归航结算 → 基地。

- Q1：三个专精各赠送一个实际生效的被动和特殊能力。跨局专精经验、完整解锁树、第四专精暂缓。
- Q2：从现有三名角色中不重复抽两名；保留姓名、形象、个人 Trait，武器仍可自由分配。不新增随机姓名/外观/Trait 拼装生成器。
- Q3：加入成员详情、花食物升级及 Trait 成长；等级只属于当前 Run，新开局重置，阵亡者不能在该轮恢复。

## 本轮可玩边界

主菜单提供新游戏、存在有效进度时的继续游戏与退出。点击新游戏进入专精选择；切 Tab 同步展示当前选择、起始被动和特殊能力，最终确认才创建 Run。取消返回主菜单，不制造独立而无用途的“创建游戏”表单。

基地采用本作 3D 场景与现有模型，呈现两名队员和巴士，保留已有资源、换装、商店和出发功能；增加成员详情、升级、已装备被动与特殊能力信息。世界中的成员与右侧名单应指向同一成员。没有对应玩法的百科、房间建造、解锁树和占位按钮不加入本轮。

三个套餐保留截图的功能关系，名称、美术、平衡参数使用本作内容：

| 方向 | 被动效果 | 特殊能力效果 |
| --- | --- | --- |
| 作战 | 提高全队远程伤害 | 短时间提高全队伤害 |
| 搜集 | 每次成功归航的日结算有概率复制一把符合条件的现有武器 | 短时间提高地图上存活成员的移动速度 |
| 勘查 | 延长白昼；蓝时仍保持短暂预警 | 恢复地图上所有存活成员的生命，包括正在搜索的成员 |

特殊能力每日获得一次使用机会，使用后显示本日已用；持续效果受战术暂停控制，行动结束后清理。它们与 PROJECT_CONTEXT 第 11 节的通用紧急治疗/区域火力支援不同；Q4 已确认紧接本轮补齐通用紧急治疗与区域火力支援，不以特殊能力替代或删除该长期要求。

成员升级先只开放基地食物训练：明确显示当前等级、Trait 当前值与下级提升、成本和升级后剩余食物。等级上限、成本曲线、起始资源与效果强度均从数据读取；战斗经验自动成长、本轮道具升级与新增槽位购买另排后续，不显示无用途的 XP 进度。

开局的起始道具与特殊技能在悬停或键盘、手柄聚焦时，于对应卡牌侧边显示当前效果和明确数值的升级预览；效果标签与正文首行对齐，长说明按内容自动换行并向下推移升级区，百分比与紧随的中文语义不得被空格拆行。信息卡使用不规则纸片轮廓，指示尖角必须与纸面和外描边一体生成，不得在尖角根部保留矩形边线。预览不代表本版已经开放道具升级。

继续保留五日终点、一张行动地图和现有昼夜/并行搜索/指向射击规则。原作截图的起始食物 10 不自动变成本作五日版本的数值要求；资源配置应支持训练与口粮之间的取舍。

## 数据与保存约束

| 状态边界 | 持有内容与规则 |
| --- | --- |
| 内容定义 | 专精引用起始被动、特殊能力和可用起始角色池；角色模板、Trait 成长、武器与数值规则仍为 Resource |
| 开局草稿 | 仅保存当前预览专精；切 Tab、取消、失败均不得改变当前有效 Run |
| 本轮状态 | 固定种子与抽取结果、所选专精、成员身份与等级、装备个体、被动/能力槽、资源和既有日循环状态 |
| 行动状态 | 现场生命、移动/搜索、能力本日使用与持续效果；不得改写共享模板，重复出勤不能叠加永久倍率 |
| 长期档案 | 专精经验、永久解锁属于后续跨局系统，本轮不建立没有消费者的完整档案系统 |

本轮成员须能区分成员身份与角色模板；装备、阵亡和结算引用具体成员，不能用目录长度判断队伍。新两人逻辑不能改变旧三人档的人员、等级前状态、装备和历史，也不能删除第三名角色的战斗回归覆盖。

新档需保存抽取结果；继续、重试当天、切 Tab 都不重抽已经确认的队伍。保留行动退出重试当天且不重抽既有奖励的当前约定。武器复制结果进入一次性日结算，以新武器个体 ID 入库，不共享同一个装备身份，不在重复载入或刷新安全屋时反复复制。

旧存档的版本识别和迁移必须进入读取验证环节：当前 SaveStore 先验证再交 Campaign 恢复，只改 restore 会过晚。迁移前保留有效旧档，损坏数据不静默当作新游戏。新开局、换装、训练和结算保存失败均保留旧状态。

## 实施顺序与验收

1. 开局内容定义、本轮成员与旧档兼容；再接主菜单和创建草稿，先验证创建、取消、继续与写入失败。
2. 数据驱动的被动、特殊能力与成长，接入实际攻击、移动、白昼、生命和日结算。
3. 3D 基地与名单/成员详情/换装/训练/槽位展示，复用资产库和已有交互规则。
4. 回归五日循环、阵亡延续、剩一人搜索/撤离、全灭、三人并行旧场景、暂停与模型点击。
5. 执行 Godot Headless、原生界面与输入验证；构建 Windows EXE，复制到独立目录验证无源码启动，交付新可执行文件。

验收必须看到三套套餐在实战或归航结算产生不同结果；只显示卡片文字不算实现。自动化使用测试存档，禁止覆盖玩家进度。还需人工比较两人队伍与升级后的夜间压力，自动通过不等于平衡或体验已通过。

## 0.4.0 实际参数

- 新开局两人，从林汐、乔安、言秋中不重复抽取；保持各自既有的基础起始武器，换装自由。初始食物 6、Scrap 0、1 级。
- 成员最高 5 级；逐级消耗 1 / 2 / 3 / 4 食物。Trait 按其基础加成线性成长，减伤最高 90%。不附加战斗经验。
- 校准仪：远程伤害 ×1.25；协同爆发：全队伤害 ×2，持续 8 秒。
- 备件复制台：成功归航日结算 40% 概率复制价值最高的现有武器；价值按基础武器价格加词条价值，平价取库存中较早的个体；本轮没有史诗品质。疾行号令：移速 ×1.5，持续 10 秒。
- 咖啡：白昼延长 20 秒；全地图治疗：每名存活队员恢复 40% 最大生命。
- 每轮各装备起始被动和能力各一个，本版不能升级道具或买额外槽位；特殊能力每天一次，可在战术暂停下施放，持续时间随模拟暂停。
- 保留当前行动退出重试整天的约定，重试会重置现场状态和本日能力，不保留已搜物资；队伍、成长、商店、装备奖励与复制结算规则不重抽。

这些是本作五日试玩的可调参数，不宣称等于原作最终数值。成员边界和迁移理由见 [ADR-0004](adr/0004-run-members-and-specialization-boundary.md)。
