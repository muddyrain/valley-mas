# Standard Survivor Walking 原样验收

日期：2026-09-17。165cm 静态模板及 Idle V1 已由用户确认通过。本轮只读验收当前源 FBX 的 `Walking`，未修改 Keyframe、Rest Pose、骨架、蒙皮或任何正式动作资源。

**建议：小修后复验，不直接保留为正式 Walking；目前无需整段重构。** 基本步行节奏、左右交替和摆臂存在，但鞋底始终离地，候选支撑段有速度不一致，且循环首尾明显不闭合。需要接地、支撑速度匹配与循环专项处理；本轮没有执行这些修改。

## 完整步态阶段

下列时间是根据鞋底俯仰、前后位置和摆腿方向识别的**姿态候选阶段**，边界约到 1～2 个源帧。没有任何阶段达到真实地面接触，不能把姿态名称误写成接触通过。

| 阶段 | 左脚时间，秒 | 右脚时间，秒 | 观察 |
| --- | --- | --- | --- |
| Heel Strike 候选 | 约 0.29～0.35 | 约 0.79～0.87 | 有后跟先低、前掌较高的落脚趋势，但后跟仍离地 |
| Foot Flat 候选 | 约 0.35～0.42 | 约 0.87～0.94 | 后跟与前掌接近平行，整脚仍悬空 |
| Mid Stance 候选 | 约 0.42～0.67 | 约 0.94～结尾及 0～0.17 | 低位脚向后经过身体下方，没有真正承重接触 |
| Toe Off 候选 | 约 0.75～0.88 | 约 0.25～0.38 | 后跟抬起、脚趾向下，前掌也离地，没有实际蹬地 |
| Swing | 约 0.88～结尾及 0～0.29 | 约 0.38～0.79 | 有收腿、摆动和伸膝；左脚约 0.96 秒、右脚约 0.46 秒达到鞋底离地峰值 |

侧面与近景能辨认这五类姿态。问题在于整个循环缺少与地面的接触约束，而非完全没有步态结构。

## Foot Sliding

原地走动画中，支撑脚相对角色后移本身有意义；接入适当的前进速度后才能抵消。当前验收角色没有前进，所以地面参考下会看到脚向后滑，不能把全部后移都归为源动作缺陷。

以同一批 Forefoot 顶点的中心测量：

| 候选支撑窗口 | 地面参考下水平位移 | 向后速度范围 | 各窗口最佳恒速拟合残余前后范围 | 统一 1.450m/s 的残余前后范围 |
| --- | ---: | ---: | ---: | ---: |
| 左 0.300～0.733 秒 | 635.54mm | 1.36～1.72m/s | 18.22mm | 18.02mm |
| 右 0～0.217 秒 | 279.12mm | 0.53～1.54m/s | 34.97mm | 40.58mm |
| 右 0.817～1.042 秒 | 306.33mm | 0.83～1.61m/s | 26.27mm | 29.34mm |

窗口最佳拟合速度依次为 1.449、1.372、1.413m/s；横向范围依次为 8.10、1.49、6.84mm。右脚窗口被源片段边界分开，未跨接缝做虚假的连续线性拟合。

统一速度来自候选支撑点速度的中位数。扣除恒速仅是对离线坐标的计算，视频和动画都没有改变。结果表明，即使后续用约 1.45m/s 前进，仍有约 18～41mm 的前后残余运动；脚没有真正触地，因此这是**候选支撑滑动预测**，不是已经在真实移动 gameplay 中通过或失败的测试。

**脚尖上翘：有，主要在末端 Swing / 落脚准备阶段，左脚更明显。** 步行 Heel Strike 前背屈有正常功能，不能要求所有阶段鞋底水平；但当前前掌抬高、没有 Heel 真正接地且接触延迟，使视觉呈现过度“翘脚伸腿”。它不是 Idle 那种整周期持续上翘，后续需要按接触阶段处理。

**Toe 扭曲：四视角抽帧未见突然翻转或明显塌陷。** Toe_End 未独立旋转，不能据此宣布已知轴不镜像问题已消失。ToeBase 有实际旋转，左右整体脚部角度和摆幅并不一致，当前证据不足以把差异直接归因于 Toe_End Rest 轴。

摆臂存在且没有完全僵硬，但左肘屈伸比右肘大，正面可见单侧手臂更靠近躯干。上半身仍可保留作为基础，不能将本次结论写成“左右完全自然对称”。膝盖在单段内部未发现反折，循环跳变见下一节。

## 循环与 Root Motion

| 首尾位置差 | 数值 |
| --- | ---: |
| Hips | 14.44mm，旋转差约 0.59° |
| 左 / 右 Foot | 102.53 / 42.57mm |
| 左 / 右 ToeBase | 119.08 / 42.74mm |
| 左 / 右 Knee | 24.80 / 46.98mm |
| Mesh 任意顶点最大差 | **131.44mm** |

**循环不通过。** 侧面接缝抽帧可见摆动腿姿态跳变。以 120Hz 比较，左 Foot 源片段内部最大单步位移约 31.44mm，而首尾直接重置为 102.53mm；这不只是正常连续摆腿。Godot 与 Blender 均复现，FBX 时间范围也确认一致。未延长、截短、补帧或混合掩盖接缝。

**Root Motion：没有可直接驱动角色持续前进的位移型 Root Motion，整体表现为原地 Walking。** Armature 与 Mesh 对象矩阵整个片段恒定，场景根不动。Skeleton 没有额外 Root 骨，Hips 是根骨，并带平移和旋转摆动，因而不能说“根骨没有动画”。

Hips 首尾 Godot 坐标差约 X=-3.607mm、Y=-11.758mm、Z=+7.567mm，水平残差约 8.383mm。它远小于该步态以约 1.45m/s 行走时一个片段应前进的约 1.51m，更符合周期不闭合残差。Hips 前后轨迹的线性拟合约 0.030m/s，也不是有效步行前进速度。没有在本轮配置 AnimationTree 的 root-motion track 或累积该残差。
