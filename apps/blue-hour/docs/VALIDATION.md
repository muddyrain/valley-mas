# 蓝时归航验证入口

本页维护验收边界和运行入口。历史通过/失败记录见 [归档验证](archive/2026-10/validation-before-governance.md)；本轮文档治理没有执行游戏构建或重验游戏功能。

## 按改动验证

| 改动 | 验证范围 |
|---|---|
| 规则、内容或存档 | 资源导入、受影响规则和保存/恢复测试，覆盖旧档、失败回滚与重复结算 |
| 搜索、输入或撤离 | 派遣、并行命令、取消/死亡/恢复、一人搜索与 1/1 撤离、失焦和 UI 输入释放 |
| UI、HUD、Scene 或 Model | 原生 1600×900 画面、交互状态、打开/关闭/连续操作；动画包含中断 |
| Windows 包、发布、导出配置或平台集成 | Windows 完整 build，在独立目录验证 EXE，不依赖源码或外部 PCK |
| 文档与规则 | 根 Harness、任务入口、严格文档链接、编码；无需重新导出游戏 |

日常迭代在可用环境运行受影响专项并标注平台边界，不以每轮 Windows build 作为源码修改的完成条件。Windows 发布验收仍需对应构建与独立运行证据。

运行命令查 [项目指南](../../../docs/PROJECT_GUIDE.md)，平台、构建和资源流程查 [README](../README.md) 与 [局部规则](../AGENTS.md)。测试产物进入 `test-output/`；存档使用 `user://test-runs/`，保护玩家数据。

## 证据更新

交付回复记录实际运行命令、环境、结果和必要产物；只有稳定验收标准变化更新本页。macOS 专项、无头逻辑、原生画面、Windows 独立构建和人工体验分别标注。未执行、旧记录和自动化未覆盖的能力明确保留边界。
