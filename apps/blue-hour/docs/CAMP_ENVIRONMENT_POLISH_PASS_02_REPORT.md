# CAMP Environment Polish Pass 02

日期：2026-09-14。范围：白天营地环境第二轮精修；已完成环境实现与原生截图，等待用户视觉审核。完整 build 门禁仍失败，不能视为全部工程验收通过。

## 1. 本轮目标

保留正式主营房、蓝时号、温室、角色与操作结构，通过地面、边界、植被和规则结构件，使营地更像有人长期维护的温暖据点。保持干净大色块与轻使用痕迹，不增加夜景、玩法或新 Meshy 大件。

## 4. Blender 与资产复用

没有制作 Blender 模块，没有运行 Meshy，也没有新增依赖或改写源 GLB。复用现有 `VEG_001_tree_broadleaf_a`、`VEG_002_bush_a` wrapper 及既有营地桌椅箱体/四件正式功能道具。

旧 `BH_Fence` 为约 1.99m 高的城市金属围栏，不符合当前正式镜头下低矮、轻量的营地边界；本轮以 Godot 规则网格构成约 1.01m 高矮栏，复用营地材质与 SurfaceTool 合批，不另建资产生产管线。

## 5. 地面层次

- 草地使用约 5m 尺度的连续色域，包含深鼠尾草绿、浅绿和少量黄绿；取消庭院高频细噪声，不使用写实草坪纹理。
- 保持原切角庭院、服务通道、入口砖铺、生活区及登车平台的位置与外形。原亮色庭院硬边降低对比，加入约 0.46m 以内的干土过渡带。
- 入口与泊位外侧增加约 0.38m 的轻过渡肩部；温室、维修棚通过服务路径过渡与边缘草群衔接。
- 铺装增加低幅度砖块明度变化、柔和接缝和入口磨浅；泊位两条低对比轮迹仅影响地表，火盆周围约 1m 内轻度暗化。
- 不新增 Decal、地表碰撞或导航障碍。

## 6. 植被群组与背景

外围七组灌木，每组使用同一现有模型的三个不同尺寸实例；六株现有树组成后方与侧方树线。乔木与灌木在营地原可走范围外，保留车辆出入口。入口两个花箱、七处脚踝高度草花群分别联系墙根、服务区、生活平台和前侧围栏。

植物实例保留 wrapper 的模型纠正、共享网格与原始贴图，移除新实例的碰撞；复用现有植被风格 Shader。小草用低面数 PrismMesh 合批，花点为少量低对比浅黄；不再采用零散大方块草。植被实例 LOD bias 为 0.25，关闭灌木投影，保留树木投影以提供远近层次。

## 7. 围栏与边界

六处黑条只隐藏渲染外观，原 StaticBody、BoxShape 尺寸和开口保持原样。沿原段长铺设统一柱脚、柱帽、两道横杆及竖条；侧边段旋转 90°，前侧两段连续。矮栏使用灰绿/米灰，柱帽呼应蓝灰屋顶；道路侧仅两处小琥珀反光片。

本轮没有补上原本可通行的缺口，避免可走区域出现无碰撞的假墙；边界完整感由相同结构和外围植物延续。

## 8. 维修棚

补充侧檐边框、前横梁、前柱混凝土基脚与包脚、遮光条形灯外壳和一块简洁暖色标牌。原屋面、斜撑、工作台、发电机和轮胎保留。灯具只增加外形，没有增加实时灯；维修操作站位与道路不变。

## 9. 生活区、入口和停车区

中央桌椅关系与角色锚点保持，长椅末端增加折叠毯、收纳箱上增加整齐小盒、桌上纸张补一支笔；用品集中在已有家具轮廓内。火盆周边以轻地表暗化建立使用关系，没有扩大杂物占地。

入口两侧墙根花箱呼应公告板；公告板旁增加小信箱轮廓，仍由正式 `CAMP_PROP_003` 承担信息区视觉。停车区沿用已有维修卷线、箱子、托盘和锥桶，以轮迹和肩部过渡加强泊位。前侧原方块灯帽改为支臂、灯罩和细柱的完整灯具。

## 10. Lighting / Tone

环境光由 `(0.77, 0.80, 0.94)` / 0.34 调为 `(0.83, 0.83, 0.92)` / 0.36，略减蓝紫偏色、提高暗部暖度。主光方向、强度与投影参数保持，仍只有一盏白天方向光；无雾、无 Glow、无新增滤镜。车辆和主营房材质以及角色材质逻辑未改。
