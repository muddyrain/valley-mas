# 跨日与保存契约

Campaign 持有 Run 的成员身份、武器个体、库存、商店、食物与日期；Mission 持有单次行动状态。定义来自 Resource，存档不按内容目录或数组位置重建身份。

- 成员战斗阵亡在当前 Run 不恢复，武器个体不因同型号而合并或复制；营内死亡与野外阵亡按各自装备损失规则处理。
- 归航的奖励、扣粮、饥饿后果和日推进是一次事务。待确认结算可恢复，重复回调或打开界面不能再次入账。
- 首次缺粮给予补救机会，连续缺粮的供养对象与后果在确认前显示；足粮解除对应饥饿状态。数值查 `data/day_loop.tres`。
- 保存成功后才推进购买、换装、训练或结算；失败保留旧状态。损坏主档不能覆盖有效备份，版本迁移在读取校验阶段处理并保留原版本。
- 行动中退出按当天出发前重试，不重抽固定奖励；归航后退出恢复待结算结果，不能回退刷取同一批收获。
- 一人队伍仍能搜索和完成 1/1 撤离；零人及失败边界明确结算，不重复入账。不同出勤与留守人数按当前 Campaign/队伍规则核对。

实现入口：[Campaign](../../core/campaign.gd)、[保存](../../core/save_store.gd)、[行动账本](../../core/run_ledger.gd)、[日循环配置](../../data/day_loop.tres)。
