# 战斗设计

武器种类与武器个体分离；同型号武器可有不同属性并分别装备。武器定义位于 `data/weapons/`，库存与装备关系由 `core/equipment.gd` 和 Campaign 管理。

- 射击受射程、弹药、墙体和冷却约束；指向射击只控制掩护成员。
- 搜索成员不攻击；目标死亡后集火选择器重新选择。
- 角色被动与主动技能通过统一 Modifier 和每日状态管理器应用，不修改共享模板。
- 伤害、射速、承伤、移动和搜索倍率来自 Resource 配置；不要把视觉动画当作玩法状态来源。

效果行为见 [效果契约](effects.md)；武器系统分阶段记录见 [历史规格](../archive/2026-10/stages/WEAPON_SYSTEM.md)，后续升级接入与迁移见 [当前计划](../PLAN.md)。
