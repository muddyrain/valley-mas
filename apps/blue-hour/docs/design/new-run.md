# 开局与准备契约

开局选择仅持有草稿；切换专精、预览和取消不修改有效 Run。确认且保存成功后创建成员身份、起始内容和种子，继续或重试不重新抽取已确认队伍。

- 专精、起始角色池、训练成本与效果由 Resource 定义，不把旧角色名单或旧版本数值写死在 UI。
- 成员身份与角色模板分离；装备、成长、阵亡和结算引用具体成员，旧档保持原队伍和装备语义。
- 武器个体、效果持有清单、装备槽位和容量分别保存；升级与扩容是否开放以真实交易入口和当前数据为准。
- 派遣、营地名单和成员详情消费同一 Campaign/Definition，不因重建面板恢复已阵亡角色。
- 创建、训练或换装写入失败时保留旧状态。开局反馈和物品预览只展示真实能力，不把调试授予作为正式获取流程。

实现入口：[开局配置](../../data/new_run.tres)、[专精](../../data/specializations/)、[Campaign](../../core/campaign.gd)。旧访谈、具体套餐和迁移验收见 [开局历史规格](../archive/2026-10/stages/NEW_RUN_SPEC.md)，被后续效果系统替代的旧限制不作为当前要求。
