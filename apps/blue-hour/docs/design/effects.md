# 效果运行契约

内容定义使用 `data/effect_data.gd`、`data/effects/`、专精 Resource 与内容目录。普通/升级数值来自同一 Resource，中文名和素材名不参与逻辑身份。

- 统一 Modifier 聚合伤害、攻击频率、承伤、移动、搜索与资源倍率，不修改共享模板。
- 持有清单、装备槽和容量分离；多个技能按 `power_id` 独立持有激活状态、持续时间和冷却。`used_today` 仅为兼容记录，不代替冷却判断。
- 战术暂停冻结持续时间和冷却，行动结束清理临时效果；重复出勤不叠加永久倍率。
- 搜索耗时按成员速度与效果叠乘，最低 0.2 秒，换弹和上车不受影响。资源收益按行动累计小数余量结转，武器与独立奖励保持各自规则。
- 集火优先级遵守射程、遮挡及搜索中不攻击；手动指向射击保持玩家方向。腕表使用实际路径和距离变化判定朝向撤离，不把横移或远离判成接近。
- 暮色延缓只冻结阶段时钟，不冻结世界；夜间不可施放且不消耗，持续时间边界正确恢复。

实现入口：[Modifier](../../core/effect_modifiers.gd)、[技能管理](../../missions/special_power.gd)、[技能状态](../../missions/special_power_state.gd)、[效果定义](../../data/effects/)。
