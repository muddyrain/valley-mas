# 游戏设计

蓝时归航是 3D 小队生存与五日归航试玩。玩家每天从营地选择一个行动，带领最多四名幸存者进入固定城区搜寻资源，处理敌情并撤离；归航后结算物资、装备、伤亡与口粮，再进入下一天。

## 跨日规则

- Run 持有成员身份、武器个体、库存、装备、食物与饥饿状态。
- 战斗阵亡成员在当前 Run 不会恢复；全灭则本轮失败。
- 首次缺粮产生可恢复的饥饿惩罚；连续缺粮才会造成营内减员。
- 结算、扣粮、减员和日期推进是一次事务，不能重复入账。
- 行动中退出回到出发前重试当天；不会重抽固定行动奖励。

## 开局与结束

新游戏确认专精后才创建 Run。试玩目标为第五日归航并完成结算，至少一名成员存活即可结束；完整长期解锁和城市侵蚀不属于当前切片。
