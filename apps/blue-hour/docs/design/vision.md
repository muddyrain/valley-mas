# 产品方向

蓝时归航围绕“外出冒险，再带队归航”的情绪和每日取舍展开。Deadly Days 第一作提供体验参考，本作的品牌、角色、美术与规则按自己的产品方向发展。

当前工作以 [计划](../PLAN.md) 的明确范围为准。长期候选包括更完整的 Day Loop、设施与社区、通用支援、城市侵蚀、主线结局和跨局成长；候选存在不代表已经实现或应在普通任务中自动推进。

完整原始愿景、参考核查、移动端与小游戏导出考虑见 [历史总上下文](../archive/2026-10/project-context-before-governance.md)。涉及这些产品方向时读取相关章节再核对当前决定，不将整份旧自检作为所有任务的前置步骤。
