# 被动道具与特殊技能扩充

状态：2026-09-12 已实现并完成 Windows 0.5.0.0 构建；以本轮用户确认的 8 个被动、6 个特殊技能为准。证据与剩余边界见 [VALIDATION](VALIDATION.md)。

## 现有架构与改动边界

沿用 `data/effect_data.gd`、`data/effects/*.tres`、`data/catalog.gd`、`data/specializations/*.tres`；不新增平行内容库。此前 `missions/special_power.gd` 只读取第一个槽位，临时修改成员模板派生值；`core/campaign.gd` 的 v2 验证器只接受专精固定套餐。两处一起扩展。

统一 Modifier 负责远程伤害、攻击频率、最终承伤、移动、搜刮时长与资源倍率。普通/升级数值分别存于同一 Resource，升级只有一次；UI 从定义读取名称、图标和说明。稳定 ID 保留 `shooting_target`、`replicator`、`early_start`、`rage`、`sprint`、`aid`，中文素材名不参与逻辑。

存档升级为 v3：持有清单、装备槽位及槽位容量分开保存；正常开局仍只赠送一被动、一技能。新增内容的授予、装备、扩容、一次升级有领域接口和调试验收入口；地图奖励、费用和正式升级入口属于后续，不自行制定。

## 边界决策

- 搜刮耗时 = 基础时间 / 成员搜索速度 × 被动倍率 × 主动倍率，最低 0.2 秒；只接现有搜索任务，不作用于换弹或上车。
- 推车只提高拾取的食物/废料；按各资源在本次行动累计的小数余量结转，避免 1 单位掉落逐个取整吞掉或夸大收益。武器与其他独立奖励保持原样。
- 腕表预警从阈值到蓝时开始有效；使用实际路径段和移动后与巴士距离的变化判断，停步、远离、横移和绕路向外的路径段均不加速。公开预警状态和变化信号。
- 集火选择器独立：Boss/Elite 优先，同级按小队距离最近；目标死亡后重新选择。仍遵守射程、墙体和搜索中不攻击；手动指向射击保持玩家方向，对命中的指定目标同样加成。
- 暮色延缓仅冻结阶段时钟；敌人、移动、搜刮、撤离、其他技能持续时间照常推进。夜间不可使用且不消耗次数；跨持续时间边界准确恢复。
- v1/v2 只在内存迁移，首次保存保留对应版本备份；旧成员、武器个体和日结算不重抽。
- 病床、购物篮、报纸不注册、不加入掉落，不实现玩法。
