## 生活区、空白区域与后勤关系

生活区保留全部 Rest POI、桌椅和火盆坐标。通过地面改变空间关系：桌椅铺装从大方框收为偏右的小铺装，方向轻偏 3°、边角有切角和一处浅草地侵入；火盆处于独立的偏心压实土活动面。外层庭院去掉明亮完整边框，改为宽圆角与右前方不对称凹入。右侧用品较密、左侧火盆与通行空间较开阔，保留登车平台清晰完整边线。

原右前方两只孤立箱子缩小并集中到温室实体侧边，未新增箱体；它们留在温室原碰撞的导航留距带内。仓储架、托盘与箱子的原功能站位不动，新增的是 Shader 中与服务通道相接的地面肩部，使温室、Shelf 和围栏成为连续后勤区域。

蓝时号外侧卷线向维修棚方向移动 1.9m，以靠近已有车尾维修箱；不改变核心 Workbench、Generator、车前出发方向、VehicleEntryPoint、PartyAssembly 或 DeparturePath。

右侧大草地通过偏深色的宽植物地面区与前缘植被带压低权重；左侧树组贴近已有围栏，主楼左右后翼树组收回至场地边缘。实际可行走留白保持，不以大量实物填满。

## Lighting / Tone

本轮没有修改 Environment、主灯或主模型材质。仅在草地 Shader 中压低侧边、后缘、前围栏及右侧植物带的色阶，并稍收敛小草和花点亮度。中央受光保持原样，通过外围对比引导视线；没有暗角滤镜、Bloom、黑边、黄昏或夜景。

## 阶段结论与停止点

围栏色彩及构造已修正，六棵原树均有根部组合，左后/右后/前侧建立分层边界，生活区由地面重组减弱整块方形感，右侧后勤与维修区通过已有元素联系。导航与出发专项没有发现回归；完整工程门禁仍未通过。

本轮不需要新 Meshy 资产，也没有使用 Blender。停止于 02B 视觉审核，不自动提交，不开启 Pass 03、Ambient V2、夜晚、蓝时、HUD 重构或新玩法。
