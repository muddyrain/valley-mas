# 环境资源复用边界

既有用户确认的资产用途仍有效；归档其交付记录不撤销资源选择。完整 ID、几何参数与源件表见 [复用白名单](../archive/2026-10/stages/MEDIUM_TOWN_ENVIRONMENT_REUSE_SELECTION.md)，现有 Resource 定义为消费入口。

- 工业 Chainlink、破损围栏、混凝土路障与金属拒马不进入普通住宅院落。
- 可搜索箱体、可搜索售货机和 Camp 公告板保持原功能，不作为随机环境点缀。
- 方向箭头仅表达方向，不推断停车或具体目的地；复用围栏组合保留通道，不改变地块和源模型规格。
- 材质调整依据实际 Town 画面和已确认风格，不因审计建议自动生产新资产或增加 Gameplay。

目录引用经 [World Catalog](../../data/world_asset_catalog.gd) 与 Resource 持有，Gameplay 不直接引用原始 GLB。
