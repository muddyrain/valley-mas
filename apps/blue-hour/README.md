## 打开与验证

`[Windows]` 试玩可直接双击 `build/BlueHourHomeward.exe`，无需安装 Godot；资源内嵌在单个 Windows x64 可执行文件中。`[Windows]` 或 `[macOS]` 开发时可使用 Godot 打开 `project.godot`。本轮使用 Godot **4.7.2.stable.official.ed1daf0bf**，Compatibility 渲染。项目独立于 pnpm/Turbo，不需要额外插件、下载美术或第三方运行依赖。

`[Windows]` `run.ps1` 支持 `run`、`editor`、`art`、`import`、`test`、`smoke`、`capture`、`build`；自动查找 `GODOT_BIN`、PATH 或 Downloads 中的便携 Godot，也接受 `-GodotPath`。`build` 需要匹配引擎版本的 Windows x64 导出模板，依次执行模型与地图集成、规则、行动、派遣、并行操作、跨日规则、跨日行动、开局规则、新队伍五日流程和效果系统验证、Release 导出、独立 EXE 的 Headless 和原生启动以及内嵌模型检查，成功后更新 `build/BUILD-INFO.json`。`capture` 运行美术展示、行动、跨日界面、并行操作、开局、首页和效果系统七组原生验证。每次功能交付都构建最新 EXE。完整可复制命令集中在[仓库项目指南](../../docs/PROJECT_GUIDE.md#蓝时归航原生-godot)。

## 操作

| 操作 | 行为 |
| --- | --- |
| 新游戏 / 专精 Tab / 确认创建 | 选择起始套餐并生成两名成员；取消不替换旧进度 |
| 基地角色 / 名单 | 选择成员，查看等级、特质、武器与升级成本 |

| 升级成员 | 花食物提高本轮等级和 Trait，最高 5 级 |
| 行动特殊技能按钮 | 分别施放已装备技能；冷却结束后可再次使用，战术暂停会冻结持续时间与冷却 |

| 今日备用装备 | 花费标明的 Scrap 购买一件武器；货单每天固定，购买立即保存 |

| X / 停止 | 停止掩护成员移动并取消撤离准备；保持搜索任务和自动攻击 |
| 点击建筑、入口、车辆或右侧物资点 | 自动派最近的可抵达空闲成员；可按当前人数同时派往不同地点 |
| 点击场景中正在搜索的地点 | 查看建筑搜索卡片；点击“取消搜索”退出，其他地点继续工作 |
| 点击侧栏活动地点 / “查看搜索” | 查看当前任务，保持所有任务运行 |
| “改派当前搜索” / “取消当前搜索” | 显式更换执行者 / 单独取消；进度保留，不抢其他任务成员 |
| R / 全队集合 | 结束全部搜索，所有存活成员步行前往最近设置的集合点 |

每名存活成员最多执行一个任务，允许全员分头搜索、零人掩护；旧三人队伍继续支持三处并行。普通移动只发送给空闲、移动中或尚未开始搜索的赶路成员，进入建筑及已经开始的室内/车辆搜索受到保护，自卫暂停期间也不会被地面点击取消。主要取消入口为搜索卡的“取消搜索”；原有明确的集合、撤离和改派操作仍保留。头像选择只负责查看与定位，地面移动沿用小队指挥方式。停止、集火与 Ctrl 只指挥掩护成员；建筑搜索者抵达入口后淡出，室内搜索期间退出外部战斗目标；取消或完成后从同一入口淡入。车辆仍在外部搜索，遇险暂停自卫。搜索先按执行者特质计算，再叠乘工具腰包及搜刮狂潮的耗时倍率，最低 0.2 秒；换弹和上车不受影响。附近有可见敌人或受到攻击时暂停搜索并自卫，安全持续 1.25 秒后继续；召回、改派和中断保留进度。完成后自动归队，阵亡只停止对应任务，由玩家决定是否再派人。左右面板同时显示各任务、执行者与状态。

按住左键只有从地面开始才连续带队，拖过建筑不会连发派遣。Ctrl 松开后原地自动迎敌；移到 UI 上停止指向射击。打开菜单、Debug 或窗口失焦时清除持续输入，避免误操作。对照来源及未核实的原作细节见 [操作核查](docs/DEADLY_DAYS_CONTROLS_RESEARCH.md) 和 [ADR-0003](docs/adr/0003-parallel-search-and-direct-controls.md)。

掉落需要接近拾取。撤离会召回搜索者，巴士不会丢下仍存活的队员，阵亡会单独列入结算；全灭时本次物资遗失。

## 本切片内容

- 八座可搜建筑、三辆可搜环境车和同期新版归航巴士；16项World资源通过Wrapper接入固定街区，道路和标准围栏使用Godot规则几何，同源简单碰撞投影到原寻路网格。
- 林汐「稳准」提高攻击伤害；乔安「寻迹」提高搜索速度；言秋「坚韧」降低承伤。
- 岸灯手枪、雨燕冲锋枪、门闩霰弹枪、归途撬棍。远程自动换弹，霰弹枪具有扇形多目标命中，近战只在近处生效。
- 缓行者、疾行者、夜犬；特殊敌人鸣响者周期呼叫增援。敌人复用对象池，寻路分散在不同帧，最多同时 85 名活动敌人。
- 白昼 150 秒、BLUE HOUR 18 秒；夜晚持续提高速度、伤害和增援频率。冷暖主光、环境光、城市亮窗、巴士暖灯与合成声音共同区分阶段。
- Debug 支持切三个时段、增减食物、增加废料、生成四种敌人、清敌、给任意队员四种武器、全队无敌及 1/2/4 倍时间。

安全屋新开局随机两人、6 食物；旧三人存档保留原队伍，每人每日消耗 1；足粮后休整至满血，首次缺粮使次日生命上限降至 80%，再留一天补粮。连续不足时根据实际可供养人数选择成员，后果在确认前显示；营内死亡的装备留在库存。战斗阵亡成员本轮无法恢复，随身武器遗失；只剩一人仍可搜索和撤离，营地所有存活成员耗尽才结束本轮；仅出勤队伍全灭时，留守成员仍可继续。重新开局恢复角色可用性并清空上一轮物资与装备。

修车铺、库房和废弃轿车可带回差异武器；首批词条为长枪管、扩容、快装和近战加重。新装备需成功归航后使用；商店不因反复开界面或退出重进刷新。城区的普通点食物已降低，选择装备路线会消耗储备。

## 保存与退出

自动存档位于 Godot 的 `user://homeward/run.json`；当前 Windows 项目目录为 `%APPDATA%/Godot/app_userdata/蓝时归航 - BLUE HOUR- HOMEWARD/homeward/`。保存使用校验和、临时文件替换和 `.bak` 备份；无法写入时提示错误并保留原状态，损坏记录可回退到有效备份。

安全屋的购买、换装、训练和结算会保存。启动先显示主菜单，继续游戏恢复原队伍；版本 1/2/3 在内存迁移为版本 4，首次保存额外保留原版本 `.v1.bak` / `.v2.bak`。专精切换只是预览，创建成功才替换旧 Run。行动中退出，续玩回到当天出发前，本日技能使用随现场重试而重置，装备奖励不重抽；归航后退出会恢复待确认的结算，不能重复领取同一批收获。自动化全部使用 `user://test-runs/` 下的独立记录，不覆盖玩家存档。

| `maps/city.gd`、`maps/generation/` | 固定街区装配、模块道路、地块/Wrapper摆放、平面网格寻路和同源碰撞 |
| `data/world_asset_catalog.gd`、`scenes/world/` | 首批16项World Resource目录及规范化Runtime Wrapper |
| `vfx/`、`blue_hour/`、`audio/` | 可替换占位模型、射击反馈、昼夜灯光和声音 |
| `ui/`、`debug/` | Godot Control 原生界面与调试入口 |
| `tests/` | 基础与跨日规则、行动集成、原生输入与路线诊断 |

跨日规则、价格和装备奖励池来自 `data/day_loop.tres`，词条来自 `data/affixes/`。新增内容先改资源定义与 `.tres`，联查目录校验和消费模块。模型替换只改表现层，玩法不读取具体 Mesh 子节点。网格路径使用 Godot 内置 [AStarGrid2D](https://docs.godotengine.org/en/stable/classes/class_astargrid2d.html)，占位音效使用 [AudioStreamWAV](https://docs.godotengine.org/en/stable/classes/class_audiostreamwav.html)。

## 当前局限

正式外出环境使用首批16项用户World资产；旧Blender资产保留在营地、展厅或资源库。新版蓝时号与普通感染者使用用户GLB，角色动画仍在开发；声音为程序生成的短音和环境低频，尚无配音或高级视效。源招牌伪字、树冠稀疏和顶棚遮挡见街区报告。数值仍是第一轮基线，路线探测不等于真实玩家体验或压力基准。仅验证当前Windows Godot环境；其他版本和平台未验证。运行截图、日志、导出物和编辑器缓存忽略提交，交付文档纳入源码。

本版没有每日地点三选一、营救补员、战斗经验、跨局专精解锁、通用治疗/区域火力支援、基地经营、主线或完整 10～20 日循环；五日终点只是这一小步的试玩范围。开局与成长规格见 [NEW_RUN_SPEC](docs/NEW_RUN_SPEC.md)，跨日基础见 [DAY_LOOP_SPEC](docs/DAY_LOOP_SPEC.md)。

## 美术资产生产与检查

图片与 UI 的新增归属及文件命名见 [资源目录说明](art/RESOURCE_LAYOUT.md)：游戏对象素材归对应领域，共享控件归 `assets/ui/common/`，界面专属素材归 `main_menu/` 或 `route_selection/`。目录整理历史见 [资源迁移记录](docs/ASSET_MIGRATION_2026-09-12.md)，当前 122 个资源的旧名与新名映射见 [命名迁移记录](docs/ASSET_NAMING_2026-09-12.md)。

新增美术先读 [ART_BIBLE](art/ART_BIBLE.md)、[ASSET_PIPELINE](art/ASSET_PIPELINE.md) 与 [MODEL_CATALOG](art/MODEL_CATALOG.md)，优先复用现有模块。`art/build_assets.ps1` 按道路建筑、道具、车辆、枪械、感染者五批依次执行 Blender → GLB 校验 → Godot 导入与实例化，失败即停止；运行资产在 `assets/generated/`，可编辑源文件在 `art/blender/sources/`。

运行 `./apps/blue-hour/run.ps1 -Mode art` 可查看旧资产库与新版蓝时号；首批World环境按正常流程从营地出发验收。`test` 和 `build` 包含模型导入与街区回归，`capture` 增加正式街区原生闭环；`build` 同时验证独立EXE中的菜单、营地、外出与展厅资源。完整步骤见资产管线文档。
