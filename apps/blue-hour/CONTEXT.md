# 蓝时归航术语

本文件统一《蓝时归航》的玩法用语。产品方向见 [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)，实现状态与迭代讨论见 [docs/PLAN.md](docs/PLAN.md)。

## Language

**单次行动**：
小队从安全屋出发，在城区搜寻与战斗，直到归航或全灭的一次外出。
_Avoid_: 用“一局”同时指单次行动与持续多日的游戏进程。

**一轮生存 / Run**：
从一次新开局开始，跨多个游戏日延续，直到达成终点或失败的一段游戏进程。
_Avoid_: 单次行动、游戏日。

**游戏日**：
围绕安全屋准备、外出和归来结算推进的每日循环单位。
_Avoid_: 与行动中的 Day 时段混用。

**搜索点**：
可以派成员执行搜索的具体地点，例如一栋建筑或一辆车。

**行动目标**：
一次外出希望完成的具体任务，例如获取补给、回收空投或营救幸存者。
_Avoid_: 把建筑名称不同直接视为任务不同。

**Day / 白昼**：
单次行动中适合搜寻物资、位于蓝时之前的时段。

**BLUE HOUR / 蓝时**：
白昼与夜晚之间的短暂临界预警，提醒玩家评估继续搜寻和归航的风险。
_Avoid_: 独立的稀有材料奖励阶段。

**夜间临时威胁**：
单次行动进入 Night 后随停留时间增长的危险程度。
_Avoid_: 城市侵蚀等级。

**城市侵蚀等级**：
跨游戏日积累、影响后续行动环境的长期危险程度。
_Avoid_: 夜间临时威胁。

**归航**：
仍存活的小队成员完成巴士撤离并返回安全屋；归航可以伴随伤亡。

**全员归航**：
出发时的小队成员全部生还并返回安全屋。
_Avoid_: 把“所有剩余幸存者撤离”称作无伤亡的全员归航。

**阵亡**：
幸存者死亡并退出当前一轮生存，无法在该轮恢复；重新开局仍可使用该角色。
_Avoid_: 暂时重伤、永久删除角色内容。

**饥饿**：
每日补给不足带来的生存惩罚；首次发生后有一个游戏日的补粮机会，连续不足会造成人员损失。

**Trait / 特质**：
影响幸存者表现、形成成员差异的个体特性。
_Avoid_: 固定职业或固定武器限制。

**开局专精 / Specialization**：
创建一轮生存时选择的队伍发展方向，决定该轮获得的起始被动道具和特殊能力。
_Avoid_: 成员 Trait、角色职业。

**被动道具**：
占用道具槽、装备后持续或在满足条件时生效的队伍装备。
_Avoid_: 需要玩家主动施放的特殊能力、成员持有的武器。

**特殊能力**：
占用特殊能力槽、由玩家在行动中主动施放的战术效果。
_Avoid_: 被动道具、无需装备的通用战术命令。

**成员等级**：
一名幸存者在当前一轮生存中的成长程度，可以增强其个人 Trait。
_Avoid_: 跨局专精等级。

**专精经验**：
衡量某个专精跨多轮生存积累的进展，用于解锁后续开局或掉落的可能性。
_Avoid_: 成员经验、当前游戏日数。

**角色模板**：
具有既定姓名、形象和主要 Trait 的角色设定，可在不同轮次出现。
_Avoid_: 当前队伍中已经获得等级、武器与生死记录的具体成员。

**本轮成员**：
当前一轮生存中的具体幸存者，具有独立的成长、装备与生死状态。
_Avoid_: 角色模板、可重复抽取的角色目录条目。

**小队指挥**：
玩家围绕队伍的移动、集火和任务分配作出的行动指挥。
_Avoid_: 把小队指挥等同于所有成员始终执行同一种工作。

**任务派遣**：
将一个具体搜索目标交给一名成员临时执行的分工。不同成员可同时承担不同目标，每人最多一项任务。
_Avoid_: 固定职业分配。

**搜索者**：
当前承担某个搜索任务、在可见入口工作的幸存者；工作时让出火力，遇险时暂停工作并自卫。

**掩护成员**：
未承担搜索任务、在外负责移动与战斗的队员。
_Avoid_: 固定的守卫职业。

**召回**：
结束指定搜索分工，让搜索者返回掩护成员身边；搜索点已有进度保留。全队集合则取消所有搜索，前往最近设置的集合点。
_Avoid_: 全队归航或瞬间传送。

**指向射击**：
按住 Ctrl 让掩护成员停步向鼠标位置射击；远程可能落空，近战只防守近处敌人。
_Avoid_: F 锁定敌人并按射程追近的集火命令。

**携带物资**：
本次行动中已收集、尚未通过归航带回安全屋的物资。
_Avoid_: 安全屋库存。

**安全屋库存**：
已经通过归航结算带回社区的物资储备。
_Avoid_: 携带物资。

**武器种类**：
具有共同基础用途与战斗方式的一类武器，例如手枪或霰弹枪。

**武器个体**：
实际拥有、可交给一名幸存者使用的一件武器；同种武器的不同个体可以具有不同特性。
_Avoid_: 把同种武器视为同一件装备。

**Food / 食物**：
支撑社区成员每日生存，并可用于成员训练的补给资源。

**Scrap / 废料**：
供购买、修理和强化使用的通用经济资源。
_Avoid_: 把 Tools / 工具视作同一种资源。
