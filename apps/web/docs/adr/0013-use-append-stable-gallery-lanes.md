# 公共图库分页使用追加稳定的列分配

状态：已接受，待实施。

公共图库当前使用 CSS 多栏布局。多栏算法会在分页追加 DOM 节点后重新平衡整段内容，导致已经进入视口的图片换列和跳位；资源数组本身没有重排，因此问题根因不在图片分辨率或接口顺序，而在布局算法。

图库改用明确的 3 / 2 / 1 列容器和追加稳定的列分配。首次加载按资源顺序和宽高比估算卡片高度，将图片依次放入当前最短列；分页追加只为新资源计算列归属，不重新分配旧卡片。同一列数和同一资源前缀下，已有卡片的位置必须保持不变。窗口跨越桌面三列、笔记本两列或手机一列断点时允许重新计算全部列，因为列数变化本身改变了可用布局约束。

资源缺少有效宽高时使用统一安全比例，不等待图片解码后再次移动卡片。公共资源接口提供稳定总排序，在时间相同的情况下使用资源 ID 作为次级排序键，避免分页边界出现重复、遗漏或随机换序。这个决定不新增图库合集、人工策展或独立图片排序后台。

验收以用户可观察行为为准：同一视口连续加载多页时，任何已显示卡片都不得换列；跨响应式断点后可以重新排布，但不得出现重复、裁切、横向溢出或无法继续分页。
