# 公共站使用有感但克制的编辑式动效

状态：已接受并实施。

公共站动效用于解释内容层级和观看顺序，而不是展示动画技术。首屏可以让标题、摘要和元数据分层进入，让主图通过裁切显影、副图稍后错位跟进；文章条目与图库图片可以在首次进入视口时分批揭示；图片悬停只使用轻微缩放、裁切或标题位移。

公共站不使用滚动劫持、固定滚动叙事、持续漂浮、夸张视差、跟随光标特效或长时间入场。动画不得延迟链接和主要内容可用时间，不得让加载完成后仍需等待表演结束。所有动效都必须在 `prefers-reduced-motion` 下退化为即时可见状态。

图库进入单图查看时，动效应表达“正在走近同一幅作品”。支持的浏览器使用基于资源 ID 的原生共享图片过渡，让缩略图与详情主图保持对象连续性；主图只进行一次轻微缩放与清晰度变化，详情信息随后依次淡入。直接打开详情、浏览器不支持 View Transition 或前序图片状态不存在时，必须无缝降级为普通淡入，不能阻塞路由和内容可用性。

当前仓库已经包含 GSAP，本轮不为公共站动画新增第三方依赖。实现应以公共站范围内的共享动效入口集中管理生命周期与清理，避免在每个页面散落互不一致的时间参数。
