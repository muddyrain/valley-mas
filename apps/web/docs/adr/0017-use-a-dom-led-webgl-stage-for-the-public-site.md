# 使用 DOM 主导的 WebGL 舞台重构公共站

状态：已接受，已实施；待 owner 完成 Safari / iOS 与最终观感验收。

“雨迹”公共站以 Haoqi 风格的 DOM / WebGL 协作舞台替代液态雨膜、固定二次元品牌影像和暖纸首页主视觉。DOM 与 CSS 继续拥有真实内容、响应式布局、路由和无障碍语义；WebGL 只镜像需要增强的 DOM 对象，并承担空间材质、指针反馈、图片变化和整页转场。第一阶段完整重做公共壳、首页、文章索引和文章详情：入口与索引可以高表现，文章正文回到安静阅读；图库和关于只继承新 token 与共享转场，后续再扩展其舞台表现。

该决定取代 ADR 0011 对首页和文章索引的克制动效限制、ADR 0015 的稳定液态品牌滚动，以及 ADR 0016 的液态雨膜实现。它借鉴参考站的职责分层和视觉语法，但不复制对方的品牌资产、文案或项目内容。最终实现采用 Lenis、React Three Fiber、原创程序化 3D 几何与自定义封面 shader，不引入 Drei、Motion 或通用后处理链。

## 已确认的视觉契约

- 首页使用约一屏的原创 3D“雨迹”玻璃字标舞台，以浅天青天空、非对称三栏信息、原创彩色信号贴纸和三行超大中文宣言建立第一视口；随后进入简短宣言、舞台文章索引、少量图库与关于入口，不再使用长距离固定叙事。
- 舞台文章索引由真实 DOM 和 CSS Grid 决定结构，WebGL 镜像封面矩形，并使用负片显影、滚动速度形变、点阵悬停和全屏点阵路由转场增强同一对象；首期复用单张文章封面，不为第二悬停图修改数据模型。
- 文章详情默认使用近黑安静阅读层和受控正文宽度，关闭持续 WebGL，只保留点阵与文字反馈余韵；同时保留完整设计的浅色模式。
- 系统主题下，首页、文章索引、图库和关于默认使用浅天青发现层，文章详情默认进入近黑安静阅读层；访客显式选择明暗主题后，全站尊重该选择。两层共享电光钴蓝或靛蓝、冰青高光和一种酸性激活色，不沿用暖纸与低饱和雨蓝主视觉，也不逐值复制参考站配色。
- 桌面提供完整材质、点阵、滚动形变和指针反馈；移动端关闭高成本后处理与滚动形变，保留 3D 字标、点阵转场和文章显影；减少动画模式直接显示最终内容。

## 已确认的技术边界

- 为 `apps/web` 新增与 React 19 配对的 `@react-three/fiber@9` 和 `lenis`；不同时新增 Drei、Motion 或通用后处理框架。现有 GSAP 继续负责 DOM 时间线，Three 与自定义 shader 负责渲染。
- R3F 持有公共舞台的主帧循环，并在同一帧内先推进关闭自动 RAF 的 Lenis，再写入 ScrollBus，最后由 WebGL 消费同一快照；PointerBus 同时为 DOM 与 WebGL 提供统一坐标和离开状态。
- 原创 3D `yuji` 字标由仓库内生成脚本以 `CatmullRomCurve3 + TubeGeometry` 与圆形端帽构建为独立 GLB，运行时使用原创 Fresnel、薄膜色散、指针响应与颗粒 shader；不转换字体轮廓，不包含第三方模型、纹理或参考站资产，也不依赖 Spline 或 Blender。
- 首页以 PointerBus 同时驱动玻璃字倾斜、动态光束、指针光迹和实时坐标 HUD；六枚原创 SVG 信号贴纸只承担视觉节奏，不伪装为按钮。
- 首页文章索引读取最新 8 篇已发布文章，不新增人工精选字段、第二封面字段或服务端接口；单封面通过负片、双色和点阵规则形成第二视觉状态。
- 中文承担品牌、导航和真实内容，英文只用于品牌遥测。第一阶段不提供声音，不显示无功能的声音按钮。
- 文章转场支持点击进入、浏览器返回时恢复索引滚动位置、直接打开详情和减少动画四条路径。文章详情删除固定装饰侧注，只在长文章中显示粘性目录。
- DOM 封面始终作为可靠底图；Canvas 建立不代表单张纹理已成功，WebGL 只能覆盖增强，不能仅因 renderer ready 就隐藏 DOM 封面。全屏转场结束后直接卸载遮罩节点，移动菜单关闭时不保留离屏合成层，避免失败或陈旧 GPU 图层遮住真实内容。

## 实施记录

- 单一固定 Canvas 只在首页与文章索引存在；文章详情、图库与关于不保留持续 WebGL。
- 首页读取最新 8 篇文章，文章索引由真实 DOM 链接和 CSS Grid 持有结构，WebGL 只镜像已注册封面。
- 原创 GLB 字标、动态光场与指针光迹都定义在公共舞台渲染层中；DOM 字标在 GLB、shader 或 WebGL 未就绪和失败时原位显示。首页加载门读取 GLTFLoader 的真实下载事件并设置八秒 fail-open，不让模型失败演变为永久空白或滚动锁死。
- 2026-08-20 的第三轮视觉纠偏将上一版“浅蓝网格加装饰几何”改为动态光束、玻璃管字、原创 SVG 贴纸、实时指针 HUD 与封面反相切片共同组成的舞台；2026-08-21 的第四轮进一步改为连续圆管手写 GLB、自定义虹彩 shader、原创 3D 箭头、印刷贴纸、全宽版面、雨迹珊瑚选区和真实进度加载门。真实 Chrome 已验证首页、文章索引、卡片转场、详情页与 390px 移动单栏布局；桌面 900、1280、1366、1440、1920px 与移动 390px 已完成真实浏览器检查。Safari / iOS 和 owner 最终观感验收仍是关闭本 ADR 的外部条件。
