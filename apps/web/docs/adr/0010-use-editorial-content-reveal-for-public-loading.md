# 公共站加载使用编辑式内容显影

状态：已接受并实施。

“雨迹”公共站是面向访客的内容体验，首次加载不能直接复用私有创作室和后台页面的转圈、三点 Orbs、灰条 Skeleton 或全页 loading 遮罩。请求开始后的前 `300ms` 不显示 loading，避免快速请求闪烁；超过阈值后，页面显示纸张底色、公共导航和与最终内容比例接近的低对比度轮廓，只做轻微呼吸，不使用大面积空白横线或后台式状态框。

文章与图片使用独立加载状态，先就绪的内容在各自稳定区域揭示，不让一个慢请求阻塞整页。首页重点文章区域是一个原子构图：文章请求结束前不允许拿已经返回的图库图片临时充当文章封面，避免最终封面到达时发生内容错认和大幅跳变。真实内容到达后在原位置分层淡入并轻微上移；加载期不渲染默认标题、假图片或其他可能被误认为真实内容的占位信息。请求失败或请求层超时后必须停止占位并提供原地重试；只有请求成功且确实无数据时才显示空状态。加载动画不得人为延长等待，并必须在 `prefers-reduced-motion` 下退化为即时替换。

这套状态边界覆盖首页、文章列表、文章详情和单图查看。公共页面模块与公共壳同步进入，不经过私有应用使用的全页 loading 卡；私有创作室仍以任务效率为目标，可以继续使用现有产品型 loading 组件。公共站的内容显影是品牌层表现，不替换全站通用状态组件，也不要求新增第三方依赖。
