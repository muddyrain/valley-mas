# 雨迹个人内容站产品规格

> 状态：现有高保真原型与生产公共站已接入；稳定品牌首屏与液态雨膜魔法滚动已进入生产实现
> 日期：2026-08-15

## 1. 产品定义

“雨迹”是 `muddyrain` 的个人内容站，用文章表达观点与经验，用图库展示风景、动漫和其他精选影像。AI 只服务站主的创作与整理任务，不作为公共站的产品主角。

公开品牌写作 `雨迹 · by @muddyrain`，辅助说明为“文章与影像”。`Valley` 仅作为内部项目代号。

### 目标

- 访客在五秒内理解这是一个个人文章与影像站。
- 公共页面具有独立杂志气质，不再像后台管理端或 AI 工具导航。
- 站主可以从 Markdown、零散观点或一批图片开始，由 AI 减少摘要、标签、命名和封面准备等重复劳动。
- 保留旧内容与数据关系，重构过程不要求一次性迁移历史数据。

### 非目标

- 不建设创作者平台、内容社区、访客会员体系或 SaaS 服务。
- 不让 AI 自动发布内容，不把模型、智能体或工作流放在公共主导航。
- 不以运营指标、排行榜或增长漏斗组织站主体验。

## 2. 用户与权限

### 访客

无需登录即可浏览、搜索、查看图片出处，并在许可允许时下载图片。访客没有关注、收藏、通知、个人资料或下载历史入口。

### 站主

唯一需要登录的内容维护者，通过私有创作室完成写作、图库整理、预览和发布。

## 3. 信息架构

### 公共站

- 首页
- 文章
- 图库
- 关于
- 全站搜索

公共站使用顶部杂志式导航，不使用全局侧边栏。

### 私有创作室

- 创作室首页
- 文章库
- 内容画布与发布检查
- 图库批量导入
- 图片库
- AI 图片创作
- 私有实验室（次级入口）

智能体、工作流、技能和知识库保留在私有实验室，不进入主任务流。

## 4. 公共站体验

### 首页

- 首屏是面向技术同好与潜在协作者的稳定“品牌首屏”，先表达站主兼具技术判断与影像审美的个人世界，不由最新文章、文章封面或图库更新自动定义。
- 品牌首屏以覆盖整个视口的一整张“液态雨膜”为持续视觉核心：“雨迹”字标只作为克制的品牌署名，并固定显示宣言“在技术与影像之间，留下思考的痕迹。”；无色液态玻璃覆盖深墨 `#161B1B` 环境，以低饱和雨蓝 `#9CB9B3` 形成边缘高光，三幕“魔法滚动”通过挤压、拉伸、折射和揭开同一层材质形成雨迹世界，最后露出暖纸 `#F3F0E7` 内容层。
- 液态雨膜下只放置人工选定的三至五张长期品牌影像，平时呈现为模糊色块，压痕、拖曳或滚动经过时才局部折射出清晰片段；它不读取最新文章封面或实时图库内容，更新公开内容不会改变品牌首屏。
- 旧原型内容图只用于验证折射构图，不作为长期生产品牌素材；生产首页使用站主人工确认并保存在 `apps/web/src/assets/yuji-brand/` 的固定二次元角色影像包。
- 固定影像包以四张宽幅二次元角色场景组成明暗递进：月夜遗迹、雨中观测站、晴空花瓣和日伞近景。人物可以成为长期品牌视觉，但影像必须保留环境层次与横向裁切空间，不能读取最新文章封面或随公开内容更新自动替换。
- 动效节奏以缓慢、厚重的材质阻尼为主，只在影像折射开启和暖纸内容层揭开时使用两次锐利释放；不让碎裂、冲击或强位移持续贯穿三幕。
- 桌面端指针只对局部材质产生压痕与影像折射，离开后带惯性回弹，不改变滚动控制的主叙事；移动端不模拟指针，手指滑动只产生短暂压力波。
- 桌面端完整叙事约占三屏原生滚动距离；移动端压缩为约两幕，并为系统减少动画设置提供不依赖滚动演出的等价静态入口。三幕正向与反向滚动完全可逆，不吸附节点或留下只能向前播放的状态。
- 首次绘制立即提供静态深墨品牌首屏、宣言、导航与可访问入口；品牌纹理准备完成后在原位无缝升级为液态场景，不显示专门的 loading 动画、不全黑等待，也不延迟链接可用时间。
- 第三幕让液态雨膜从中央产生裂隙并向两侧退开，露出暖纸层上的“文章 / 影像”双入口；入口获得键盘焦点或指针悬停时，膜下局部折射出对应预览，再进入近期文章和精选影像。文章依然是核心内容，但不再统治首页第一印象。
- 首页不再建设“专题精选”策展对象或历史专题；双入口之后依次展示三篇近期文章、四至六张精选影像和简短作者署名/关于入口。
- 顶部导航在三幕中始终可用，但使用极简悬浮形态，只保留“雨迹 / 文章 / 图库 / 关于 / 搜索”，登录站主额外显示“创作室”，作者署名不再占用导航；深墨阶段显示浅色内容，进入暖纸层时平滑反转，不使用巨型字标或完整页头与液态雨膜争夺主视觉。
- 暖纸内容层继续使用既有纸色、深墨和雨蓝 token，但重新收紧文章列表、影像入口、排版比例和留白节奏，并以少量静态裂隙或局部折射呼应品牌首屏；shader 不继续覆盖长文和图库内容。
- 默认浅色模式在第三幕揭开暖纸内容层；用户选择深色模式时改为揭开深炭纸内容层，保持相同裂隙与材质叙事，不用亮屏闪烁覆盖用户主题偏好。
- 本次视觉重构覆盖首页、共享公共导航和首页内容层；文章列表、文章详情、图库与关于页只做共享 token、导航反色和页面衔接所需修订，不同步重做整组公共页面。
- 固定宣言位于首幕左下角并使用正常正文尺度，液态雨膜开始明显变形后逐渐淡出；视口中央不放置巨型文字或持续占据主视觉的品牌文案。

### 文章列表

- “博客”和“图文”在公共站统一称为“文章”。
- 文章可以选择一个“专栏”，例如 React、TypeScript 或 LangGraph。
- 专栏沿用现有 `PostGroup` 数据和绑定关系；默认按最新发布排列，允许少量置顶。
- 分类作为隐藏兼容字段保留；标签作为可选检索元数据，仅在详情页低调显示。
- 不新增“系列”概念。

### 文章详情

- 长篇杂志阅读布局，包含大封面、标题、引言、正文、目录、代码块和相关文章。
- 署名使用 `by @muddyrain` 并链接 GitHub。
- 标签只承担检索和关联浏览，不抢占标题层级。
- 支持适合搜索和分享的 metadata、Open Graph、站点地图与 RSS。

### 图库

- 当前生产阶段在没有显式策展数据时按资源用途分开浏览：`/gallery` 默认展示壁纸，`/gallery?type=avatar` 展示头像；每个用途视图都按现有数据顺序进入桌面三列、笔记本两列、手机一列的响应式瀑布流，并保留原始比例。
- 同一列数下分页追加只能把新图片放入既有列尾，已经显示的图片不得重新换列；只有窗口跨越 3 / 2 / 1 列响应式断点时允许重新排布。
- 不根据资源类型或检索标签自动生成“主题合集”，不让界面表达尚不存在的内容关系。
- 只有在独立合集数据、标题、引言和人工选择的图片关系落地后，主题合集才成为图库的主要浏览单元；合集内部继续使用不规则编辑式图片编排。
- 单图进入沉浸查看器；普通手工导入图片不展示空来源或许可信息，并默认允许预览与下载。平台 AI 图片工作台保存的图片显示“AI 生成”标记；旧资源已有明确出处或限制时继续按兼容字段展示。

### 关于

- 展示简短介绍、当前兴趣、链接与联系方式。
- 作者头像、简介、代表仓库和贡献记录由服务端读取 GitHub 并缓存。
- 代表仓库由站主明确选择；GitHub 失败时返回最近成功数据，贡献记录允许独立隐藏。

### 搜索

- 同时搜索文章、专栏、标签、主题合集和图片标题。
- 搜索服务于内容发现，不提供 AI 对话式推荐入口。

## 5. 创作室体验

### 创作室首页

首要动作是“写文章”“导入图片”“管理图片”“AI 图片”。页面补充最近草稿，不展示运营仪表盘。

### 文章库

- 文章库是站主管理全部文章的统一入口，默认展示草稿、已发布和已归档内容；创作室首页的“最近草稿”只是快捷视图。
- 列表使用带 16:10 封面的紧凑行布局，显示标题、摘要、专栏、更新时间、状态、编辑和永久删除操作。
- 没有封面时显示明确的文字占位，不从正文自动抽取图片。
- 永久删除沿用现有接口，执行前必须说明文章与关联封面将无法恢复；当前阶段不提供回收站。

### 内容画布

- 可以从完整 Markdown、粗略观点或素材开始。
- AI 协助准备正文、摘要、标签和封面，默认根据任务自动选择模型；模型覆盖放入高级设置。
- AI 改写以逐段建议或差异形式呈现，支持接受、拒绝、扩写、精简和润色。
- 持续自动保存；每次 AI 改写前保留可恢复快照，并支持撤销。
- 文章状态只有草稿、预览、已发布。

### 发布检查

正文保持视觉中心；发布前集中确认标题、摘要、专栏、可选标签和封面。AI 不得绕过确认直接发布。

### 图库批量导入

- 一次选择多张图片，保留批次级资源类型、可见范围和视觉模型设置；不再要求填写来源、许可或原始出处。
- 保留批量 AI 标题、批量 AI 标签，以及每张图片单独生成标题或标签的操作；AI 不推断图片来源与许可。
- 尚未入库的图片、顺序、设置、标题、标签和处理状态保存在当前浏览器的本地工作区，关闭弹窗、刷新或再次进入创作室后可以继续；它不跨设备同步，也不创建服务端后台导入任务。
- 同一张图的标题和标签由一次视觉识别同时生成并缓存，批量处理使用有限并发；用户仍在 AI 处理和检查完成后主动开始正式上传。
- 正式上传使用固定的选图顺序。成功项从本地工作区移除，失败和未导入项保留并允许继续处理。

### 图片库

- 默认分页展示站主账号下的全部壁纸与头像，不用“最近导入”替代完整管理入口。
- 支持按资源类型和可见范围筛选，筛选与页码保存在 URL 中。
- 点击图片进入编辑详情，可修改标题、描述、类型、可见范围和标签；永久删除必须二次确认。
- 新增图片统一进入批量导入工作区，不在图片库中维护另一套上传表单或没有数据支撑的合集入口。

### AI 图片创作

- 首先选择文章封面、加入图库或自由创作。
- 模型、尺寸和技术参数默认收进高级设置。
- 生成结果先成为私有图片草稿，只有明确选择“设为封面”或“加入图库”后才进入公开内容流。
- 封面遵循三至五套站主视觉方向，同一方向保持识别度，同时改变构图、主体与配色。

## 6. 数据兼容边界

- 保留现有 `blog` 与 `image_text` 类型字段，新的公共站和创作室统一显示为“文章”。
- 保留现有 `PostGroup` 关系并改称“专栏”，不批量迁移旧绑定。
- 保留 Category 作为隐藏兼容字段，不让站主在日常发布中重复选择。
- 资源 `type` 用于壁纸与头像的明确用途筛选，`tags` 保留检索用途，两者都不承担主题合集语义；没有独立策展数据时每个用途视图使用单层影像墙。
- 资源已有的 `sourceKind`、`sourceUrl`、`license` 与 `downloadAllowed` 字段继续保留以兼容旧数据；新手工导入不要求来源或许可表单，并自动采用允许预览与下载的策略。只有平台 AI 图片工作台保存的资源自动标记为 AI 生成。
- 保留旧收藏、关注、下载历史、通知和用户资料数据及兼容代码，先隐藏入口，后续再单独评估清理。

## 7. 视觉与响应式原则

- 公共内容层是浅色优先的独立杂志，支持跟随系统深色模式；首页品牌首屏使用深墨雨夜入口，并在魔法滚动末尾揭开为暖纸色内容层。
- 标题与专题使用中文衬线字体，正文、界面和代码使用清晰的无衬线与等宽字体。
- 页头、公共页面主体与页脚共享约 `1240px` 的最大内容宽度，在 1366–1440px 的笔记本视口保留稳定外侧留白；文章正文继续限制在约 `760px`，单图沉浸查看器可以突破公共内容框架。
- 公共站依靠排版、留白、比例和图片节奏建立层级，避免满屏卡片、彩色徽章、数据面板和后台式侧栏。
- 公共站首次加载使用品牌化“内容显影”：前 300ms 不显示 loading，随后才呈现与最终内容比例接近的低对比度轮廓，文章与图片在各自稳定区域就绪并从原位揭示；品牌首屏不等待文章或图库请求，首屏后的内容模块独立加载。失败后停止占位并提供重试，不展示转圈、三点 Orbs、灰条 Skeleton、透明全页遮罩或永久空白线框。公共页面模块与公共壳同步进入，私有创作室继续使用清晰高效的产品型 loading，不与公共站混用。
- 公共站移动端完整可用；创作室桌面优先，移动端至少支持查看草稿和简单编辑。
- 品牌首屏集中使用三幕“魔法滚动”，由原生滚动进度驱动同一动态品牌场景连续演化，不劫持滚动或强制自动播放。首屏以外继续采用克制的编辑式动效：文章与图库进入视口时分批揭示，悬停只做轻微缩放与标题位移；所有动效支持 `prefers-reduced-motion`。
- 魔法滚动沿用现有 GSAP，并使用 ScrollTrigger 将一个固定全视口舞台约三屏的原生滚动进度映射到统一时间轴；只动画舞台子层，不平滑或替换浏览器滚动。
- 液态雨膜使用新增的 `three` 与自定义 `ShaderMaterial` 渲染单一全屏画布；不引入 React Three Fiber、Lenis、额外平滑滚动或后处理框架。Three 负责渲染器、纹理和 WebGL 上下文生命周期，shader 只接收滚动进度、指针压力和有限品牌纹理。
- 完整首页实现前先交付单屏材质技术样片，只验证雨膜厚度、膜下折射、局部压痕、惯性回弹、品牌色与帧率；样片未通过视觉和性能门槛时不扩展为三幕首页。
- 单屏材质样片在常用桌面设备上应稳定接近 `60 FPS`，在中端手机降质后不低于 `30 FPS`；未达标时优先降低像素比、纹理尺寸和 shader 复杂度，不以持续掉帧换取视觉细节。
- 桌面端使用完整 shader；移动端压缩为两幕低质量 shader、限制像素比并取消指针输入；系统减少动画、WebGL 不可用或上下文恢复失败时直接显示包含品牌宣言与“文章 / 影像”入口的静态首屏。

## 8. 高保真原型范围

现有原型与生产页面隔离，不接生产接口，不修改现有路由。内容使用从当前公开 API 读取后本地化的真实文章、封面和图片；其中首页仍记录旧专题首屏，只作为内容层和相邻页面的历史视觉参考，生产首页不再读取该原型或其内容图。

完整原型位于 `apps/web/prototypes/yuji`，已确认的 v0 快照保存在 `apps/web/prototypes/yuji-v0`。

### 公共站页面

- 首页
- 文章列表
- 文章详情
- 图库合集
- 单图查看
- 关于

公共站覆盖桌面与移动关键状态。

### 创作室页面

- 首页
- 内容画布与发布检查
- 图库批量导入

## 9. 实施顺序与验收

### 顺序

1. 公共站视觉与信息架构
2. 创作室任务流
3. 私有实验室与旧入口收敛

### 第一阶段验收

- 页面不再具有后台管理端观感。
- 首次访问者五秒内理解“文章与影像”。
- 首页、文章、图库和关于形成连贯的内容浏览路径。
- 公共站移动端具备完整导航、阅读和单图查看体验。
- 现有公开文章和图片仍可被访问。

### 原型验证状态
