# 雨迹个人内容站产品规格

> 状态：公共站 DOM / WebGL 舞台已实施；待 owner 完成 Safari / iOS 与最终观感验收
> 日期：2026-08-20

> [!IMPORTANT]
> 当前生产代码已经用 DOM 主导的 WebGL 舞台替代液态雨膜。首页、文章索引、文章详情与公共壳已完成重构；图库和关于页本阶段只继承新 token 与共享转场。

## 1. 产品定义

“雨迹”是 `muddyrain` 的个人内容站，用文章表达观点与经验，用图库展示风景、动漫和其他精选影像。AI 只服务站主的创作与整理任务，不作为公共站的产品主角。

公开品牌写作 `雨迹 · by @muddyrain`，辅助说明为“文章与影像”。`Valley` 仅作为内部项目代号。

### 目标

- 访客在五秒内理解这是一个个人文章与影像站。
- 公共页面具有独立杂志气质，不再像后台管理端或 AI 工具导航。
- 站主可以从 Markdown、零散观点或一批图片开始，由 AI 减少摘要、标签、命名和封面准备等重复劳动。
- 保留旧内容与数据关系，重构过程不要求一次性迁移历史数据。

### 非目标

- 不建设创作者平台、内容社区、访客会员体系或 SaaS 服务。
- 不让 AI 自动发布内容，不把模型或工作流放在公共主导航。
- 不以运营指标、排行榜或增长漏斗组织站主体验。

## 2. 用户与权限

### 访客

无需登录即可浏览、搜索、查看图片出处，并在许可允许时下载图片。访客没有关注、收藏、通知、个人资料或下载历史入口。

### 站主

唯一需要登录的内容维护者，通过私有创作室完成写作、图库整理、预览和发布。

## 3. 信息架构

### 公共站

- 首页
- 文章
- 图库
- 关于
- 全站搜索

公共站使用顶部杂志式导航，不使用全局侧边栏。

### 私有创作室

- 创作室首页
- 文章库
- 内容画布与发布检查
- 图库批量导入
- 图片库

- 私有实验室（次级入口）

工作流、技能和知识库保留在私有实验室，不进入主任务流。

## 4. 公共站体验

### 首页

- 第一视口是约一屏高的公共舞台，以原创程序化 3D 玻璃管 `yuji` 字标为中心对象，使用动态光束与云雾构成的浅天青天空、非对称信息、六枚原创 SVG 信号贴纸和三行中文宣言；不再使用液态雨膜、固定二次元品牌影像、暖纸首页或三屏固定叙事。
- 中文承担品牌、导航、宣言和真实内容；时间、指针位置、滚动状态等低层级英文品牌遥测围绕舞台建立仪器感，但不替代真实导航和说明。
- DOM 与 CSS 始终拥有宣言、链接、文章标题、文章封面占位和响应式布局；固定 WebGL 画布只镜像需要增强的对象，并承担 3D 字标材质、封面显影、滚动速度形变和点阵反馈。WebGL 不可用时完整 DOM 内容直接成立。
- 首次进入首页时使用浅纸色品牌加载门展示 3D 字标 GLB 的真实进度，并至少保留一个可辨识的起拍节奏；加载完成后导航、遥测、贴纸、宣言与舞台分层入场。GLB 或 WebGL 失败时八秒内 fail-open 并保留 DOM 字标，不让加载门阻塞文章入口。
- 指针与滚动各自只有一个全局状态来源，DOM 与 WebGL 在同一帧读取同一快照；玻璃字倾斜、动态光束、指针光迹和实时坐标 HUD 使用同一 PointerBus，不允许每个效果重复监听、换算坐标或维护独立滚动循环。
- 一屏舞台之后立即进入简短个人宣言和最新 8 篇已发布文章组成的舞台文章索引，末尾提供“全部文章”；随后只保留少量图库和关于入口，不新增首页策展数据、人工精选字段或第二封面字段。
- 文章封面进入视口时从负片显影为原色，滚动速度只产生受控的水平形变，悬停或键盘焦点使用统一点阵规则形成第二视觉状态；所有文章标题和链接均为真实 DOM，不使用 Canvas 点击热区。
- 顶部导航保持“雨迹 / 文章 / 图库 / 关于 / 搜索”，登录站主额外显示“创作室”；公共壳、全屏转场、loading 和移动菜单共享点阵反馈与文字解码节奏。
- 桌面端提供完整 3D 材质、指针反馈、封面形变和点阵转场；移动端关闭高成本后处理与滚动形变，保留 3D 字标、点阵转场和文章显影；减少动画模式直接显示最终 DOM 内容。
- 系统主题下，首页、文章索引、图库和关于默认使用浅天青发现层，文章详情默认进入近黑安静阅读层；访客显式选择明暗主题后，全站尊重该选择。第一阶段不提供环境音或交互音，不显示无功能的声音按钮。
- 本次完整重做公共壳、首页、文章列表和文章详情；图库与关于页只继承新 token 与共享转场，保持现有内容模型和浏览行为。

### 文章列表

- “博客”和“图文”在公共站统一称为“文章”。
- 文章可以选择一个“专栏”，例如 React、TypeScript 或 LangGraph。
- 专栏沿用现有 `PostGroup` 数据和绑定关系；默认按最新发布排列，允许少量置顶。
- 分类作为隐藏兼容字段保留；标签作为可选检索元数据，仅在详情页低调显示。
- 不新增“系列”概念。
- 列表结构由真实 DOM 与 CSS Grid 决定，WebGL 镜像封面矩形并复用首页的负片显影、速度形变和点阵悬停规则；单张封面必须足以完成全部状态。DOM 封面始终保留为可靠底图，单张 WebGL 纹理失败时不得出现空白入口。
- 点击文章通过全屏点阵关闭与打开进入详情；浏览器返回时执行反向转场并恢复文章索引滚动位置。直接打开详情 URL 使用较短正文显影，减少动画模式立即切换。

### 文章详情

- 默认使用近黑安静阅读层，标题、引言、作者和宽幅封面组成文章首屏；正文控制在约 `800px`，不保留持续 WebGL、滚动表演或固定装饰侧注。
- 长文章显示粘性目录，短文章没有有效目录时自动使用单栏；代码块、图片、引用和表格继续服务长时间阅读。
- 署名使用 `by @muddyrain` 并链接 GitHub。
- 标签只承担检索和关联浏览，不抢占标题层级。
- 文末显示标签、相关文章和返回文章索引入口；浅色模式使用完整的冷白阅读表面，不简单反相近黑主题。
- 支持适合搜索和分享的 metadata、Open Graph、站点地图与 RSS。

### 图库

- 当前生产阶段在没有显式策展数据时按资源用途分开浏览：`/gallery` 默认展示壁纸，`/gallery?type=avatar` 展示头像；每个用途视图都按现有数据顺序进入桌面三列、笔记本两列、手机一列的响应式瀑布流，并保留原始比例。
- 同一列数下分页追加只能把新图片放入既有列尾，已经显示的图片不得重新换列；只有窗口跨越 3 / 2 / 1 列响应式断点时允许重新排布。
- 不根据资源类型或检索标签自动生成“主题合集”，不让界面表达尚不存在的内容关系。
- 只有在独立合集数据、标题、引言和人工选择的图片关系落地后，主题合集才成为图库的主要浏览单元；合集内部继续使用不规则编辑式图片编排。
- 单图进入沉浸查看器；普通手工导入图片不展示空来源或许可信息，并默认允许预览与下载。平台 AI 图片工作台保存的图片显示“AI 生成”标记；旧资源已有明确出处或限制时继续按兼容字段展示。

### 关于

- 展示简短介绍、当前兴趣、链接与联系方式。
- 作者头像、简介、代表仓库和贡献记录由服务端读取 GitHub 并缓存。
- 代表仓库由站主明确选择；GitHub 失败时返回最近成功数据，贡献记录允许独立隐藏。

### 搜索

- 同时搜索文章、专栏、标签、主题合集和图片标题。
- 搜索服务于内容发现，不提供 AI 对话式推荐入口。

## 5. 创作室体验

### 创作室首页

首要动作是“写文章”“导入图片”“管理图片”“AI 图片”。页面补充最近草稿，不展示运营仪表盘。

### 文章库

- 文章库是站主管理全部文章的统一入口，默认展示草稿、已发布和已归档内容；创作室首页的“最近草稿”只是快捷视图。
- 列表使用带 16:10 封面的紧凑行布局，显示标题、摘要、专栏、更新时间、状态、编辑和永久删除操作。
- 没有封面时显示明确的文字占位，不从正文自动抽取图片。
- 永久删除沿用现有接口，执行前必须说明文章与关联封面将无法恢复；当前阶段不提供回收站。

### 内容画布

- 可以从完整 Markdown、粗略观点或素材开始。
- AI 协助准备正文、摘要、标签和封面，默认根据任务自动选择模型；模型覆盖放入高级设置。
- AI 改写以逐段建议或差异形式呈现，支持接受、拒绝、扩写、精简和润色。
- 持续自动保存；每次 AI 改写前保留可恢复快照，并支持撤销。
- 文章状态只有草稿、预览、已发布。

### 发布检查

正文保持视觉中心；发布前集中确认标题、摘要、专栏、可选标签和封面。AI 不得绕过确认直接发布。

### 图库批量导入

- 一次选择多张图片，保留批次级资源类型、可见范围和视觉模型设置；不再要求填写来源、许可或原始出处。
- 保留批量 AI 标题、批量 AI 标签，以及每张图片单独生成标题或标签的操作；AI 不推断图片来源与许可。
- 尚未入库的图片、顺序、设置、标题、标签和处理状态保存在当前浏览器的本地工作区，关闭弹窗、刷新或再次进入创作室后可以继续；它不跨设备同步，也不创建服务端后台导入任务。
- 同一张图的标题和标签由一次视觉识别同时生成并缓存，批量处理使用有限并发；用户仍在 AI 处理和检查完成后主动开始正式上传。
- 正式上传使用固定的选图顺序。成功项从本地工作区移除，失败和未导入项保留并允许继续处理。

### 图片库

- 默认分页展示站主账号下的全部壁纸与头像，不用“最近导入”替代完整管理入口。
- 支持按资源类型和可见范围筛选，筛选与页码保存在 URL 中。
- 点击图片进入编辑详情，可修改标题、描述、类型、可见范围和标签；永久删除必须二次确认。
- 新增图片统一进入批量导入工作区，不在图片库中维护另一套上传表单或没有数据支撑的合集入口。

### AI 图片创作

- 首先选择文章封面、加入图库或自由创作。
- 模型、尺寸和技术参数默认收进高级设置。
- 生成结果先成为私有图片草稿，只有明确选择“设为封面”或“加入图库”后才进入公开内容流。
- 封面遵循三至五套站主视觉方向，同一方向保持识别度，同时改变构图、主体与配色。

## 6. 数据兼容边界

- 保留现有 `blog` 与 `image_text` 类型字段，新的公共站和创作室统一显示为“文章”。
- 保留现有 `PostGroup` 关系并改称“专栏”，不批量迁移旧绑定。
- 保留 Category 作为隐藏兼容字段，不让站主在日常发布中重复选择。
- 资源 `type` 用于壁纸与头像的明确用途筛选，`tags` 保留检索用途，两者都不承担主题合集语义；没有独立策展数据时每个用途视图使用单层影像墙。
- 资源已有的 `sourceKind`、`sourceUrl`、`license` 与 `downloadAllowed` 字段继续保留以兼容旧数据；新手工导入不要求来源或许可表单，并自动采用允许预览与下载的策略。只有平台 AI 图片工作台保存的资源自动标记为 AI 生成。
- 保留旧收藏、关注、下载历史、通知和用户资料数据及兼容代码，先隐藏入口，后续再单独评估清理。

## 7. 视觉与响应式原则

- 公共发现层默认使用浅天青天空与黑色超大排版，文章阅读层默认使用近黑表面；显式浅色/深色选择覆盖系统默认。各层共享钴蓝、冰青、粉红、橙色和酸性激活色的信号关系，不再使用暖纸与雨蓝液态视觉。
- 大标题使用高字重无衬线与原创程序化 3D 玻璃管字标，正文使用清晰的无衬线字体，品牌遥测与代码使用等宽字体。
- 页头、公共页面主体与页脚共享最大约 `1500px` 的公共壳，文章正文限制在约 `800px`；图库和单图查看可以按自身媒体需求使用更宽区域。
- 公共站依靠排版、留白、比例和图片节奏建立层级，避免满屏卡片、彩色徽章、数据面板和后台式侧栏。
- 首屏 3D 字标使用独立的品牌加载门，只等待 GLB / WebGL 舞台且不等待文章或图库请求；首屏后的文章与图片继续使用品牌化“内容显影”：前 300ms 不显示 loading，随后才呈现与最终内容比例接近的低对比度轮廓，并在各自稳定区域就绪后原位揭示。失败后停止占位并提供重试，不展示转圈、三点 Orbs、灰条 Skeleton、透明内容遮罩或永久空白线框。私有创作室继续使用清晰高效的产品型 loading，不与公共站混用。
- 公共站移动端完整可用；创作室桌面优先，移动端至少支持查看草稿和简单编辑。
- 首页使用约一屏的 3D 字标舞台，不再使用三屏固定滚动；文章索引通过同一 Canvas 镜像真实 DOM 封面，正文路由不保留持续 WebGL。
- React Three Fiber 持有唯一舞台帧循环，Lenis 关闭自动 RAF 后由同一帧推进；ScrollBus 与 PointerBus 是滚动、指针和 WebGL 消费的统一状态源。
- 常用桌面设备目标稳定接近 `60 FPS`，中端手机降质后不低于 `30 FPS`；未达标时优先限制 DPR、停用速度形变并减少材质成本，不以持续掉帧换取视觉细节。
- 桌面端使用完整 3D 材质、封面 shader 与指针反馈；移动端使用平衡档，系统减少动画、WebGL 不可用或上下文失败时直接显示完整 DOM 字标、封面和链接。

## 8. 高保真原型范围

现有原型与生产页面隔离，不接生产接口，不修改现有路由。内容使用从当前公开 API 读取后本地化的真实文章、封面和图片；其中首页仍记录旧专题首屏，只作为内容层和相邻页面的历史视觉参考，生产首页不再读取该原型或其内容图。

完整原型位于 `apps/web/prototypes/yuji`，已确认的 v0 快照保存在 `apps/web/prototypes/yuji-v0`。

## 9. 实施顺序与验收

### 顺序

1. 公共站视觉与信息架构
2. 创作室任务流
3. 私有实验室与旧入口收敛

### 第一阶段验收

- 页面不再具有后台管理端观感。
- 首次访问者五秒内理解“文章与影像”。
- 首页、文章、图库和关于形成连贯的内容浏览路径。
- 公共站移动端具备完整导航、阅读和单图查看体验。
- 现有公开文章和图片仍可被访问。

### 原型验证状态

- 公共站与创作室共 11 个原型页面视图已经落地；生产创作室另已接入完整图片库。
- 公共站已在 390px、900px 和 1440px 验证导航、无横向溢出与图片加载。
- 创作室已在 1280px 验证写作、发布检查、批量导入和 AI 图片状态流转。
- 原型浏览器控制台无错误或警告；原型目录仍与生产代码隔离，生产数据迁移尚未开始。

### 生产实施状态

- 公共首页、文章列表、文章详情、图库影像墙、单图查看和关于页已接入 `apps/web` 生产路由，并复用现有公开文章、分组与资源 API；首页使用约一屏原创 3D“雨迹”字标，并在其后读取最新 8 篇文章与少量图库内容。
