# 雨迹完整高保真原型

这是与生产 `apps/web` 路由隔离的可点击原型，覆盖公共站和私有创作室的主要浏览、整理与发布路径。不接真实接口，也不会写入数据库。

## 打开方式

可以直接打开 [`index.html`](./index.html)，也可以从仓库根目录启动静态服务：

```bash
python3 -m http.server 4175 --directory apps/web/prototypes/yuji
```

然后访问 `http://localhost:4175`。

## 页面

### 公共站

- 首页
- 文章列表与专栏筛选
- 文章详情
- 图库首页
- 主题合集
- 单图沉浸查看
- 关于与搜索

### 创作室

- 创作室首页
- 内容画布与发布检查
- 图片批量导入
- AI 图片创作

左下角 `Views` 切换全部页面；右下角 `Tweaks` 切换“留白 / 分栏 / 海报”首页版式、浅色 / 深色和动效状态。

已确认的 v0 快照保存在 [`../yuji-v0`](../yuji-v0)，当前目录继续承载完整原型。

## 当前边界

- 图片与头像是从现有公开内容复制的本地素材。
- 文章标题、摘要和正文片段来自现有公开文章。
- 发布、导入和生图交互只改变当前浏览器中的原型状态。
- 图片出处与许可没有真实数据时明确显示为待补充，不推断下载权限。
- 生产路由、接口、数据迁移和登录权限不在本原型中实现。
