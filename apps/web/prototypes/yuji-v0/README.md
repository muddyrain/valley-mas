# 雨迹 v0 原型

这是与生产 `apps/web` 路由隔离的可点击原型，用于确认公共站与创作室的视觉方向，不接真实接口，也不会写入数据库。

## 打开方式

可以直接打开 [`index.html`](./index.html)，也可以从仓库根目录启动静态服务：

```bash
python3 -m http.server 4175 --directory apps/web/prototypes/yuji
```

然后访问 `http://localhost:4175`。

## v0 页面

- 公共首页
- 文章详情
- 创作室内容画布与发布检查

左下角 `Views` 切换页面；右下角 `Tweaks` 切换“留白 / 分栏 / 海报”首页版式、浅色 / 深色和动效状态。

## 当前边界

- 图片与头像是从现有公开内容复制的本地素材。
- 文章标题、摘要和正文片段来自现有公开文章。
- 单图查看、完整图库、关于页和其他创作室任务留到 v0 方向确认后完成。
