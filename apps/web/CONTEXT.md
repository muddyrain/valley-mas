# Web 个人内容站

Web 是站主展示个人文章与精选图片的内容站。它将面向访客的浏览体验与站主私有的内容创作体验分开。

## Language

**个人内容站**：
以站主的文章和精选图片为主体，通过内容传达站主的观点与审美。
_Avoid_: AI 平台、创作者社区、综合门户

**文章**：
公共站中统一的文字内容单元，可以是纯文字、Markdown 或图文混排；展示和创作体验不再把“博客”与“图文”视为两种产品。
_Avoid_: 博客类型、图文类型

**公共站**：
面向访客的内容浏览空间，内容优先，站主信息和个人审美自然融入其中。
_Avoid_: 管理前台、功能门户

**内容显影**：
公共站等待文章或图片数据时使用的品牌化过渡。请求开始后的前 300ms 不显示 loading，超过阈值后才呈现与最终内容比例接近的低对比度轮廓；成功后内容原位显现，失败后停止占位并提供重试。它不使用后台式转圈、三点 Orbs、灰条 Skeleton、虚构标题或永久空白线框。
_Avoid_: 全页遮罩、后台 loading、假内容、无限等待、为了动画延长等待

**编辑式动效**：
公共站用于强调标题层级、图片顺序和浏览节奏的短时动画。首屏文字分层进入，主副图片依次显影，文章与图库在进入视口时分批出现；悬停反馈保持轻微，并尊重系统减少动画设置。
_Avoid_: 滚动劫持、持续漂浮、夸张视差、长时间入场、展示型动效 Demo

**站主**：
个人内容站的内容作者与编辑，是唯一需要登录并进入创作室的人。
_Avoid_: 平台管理员、创作者用户

**作者署名**：
公共站使用的低调作者标识，默认显示为 `by @muddyrain` 并链接到站主的公开 GitHub 主页；关于页可以另行决定是否公开真实姓名。
_Avoid_: 必填真实姓名、用户档案

**品牌标识**：
公共站公开名称为“雨迹”，标准署名写作 `雨迹 · by @muddyrain`，并在品牌区补充“文章与影像”说明内容范围；`Valley` 只保留为内部项目代号，不出现在公共品牌中。
_Avoid_: Valley 公开品牌、平台式产品名称、只显示名称而不说明内容范围

**GitHub 作者资料**：
关于页使用的头像、简介、代表仓库和公开贡献记录。数据由服务端统一读取并缓存，代表仓库由站主明确选择；外部请求失败时优先展示最近一次成功数据，并允许贡献记录单独降级，不让 GitHub 可用性阻塞个人内容站。
_Avoid_: 浏览器直接携带 Token、自动展示全部仓库、把 GitHub 当作本站内容源

**访客**：
不需要账号即可浏览、搜索、查看出处并在许可范围内下载内容的公共站访问者。
_Avoid_: 会员、关注者、普通用户

**创作室**：
仅供站主使用的私有空间，用于创作、整理、预览和发布内容。
_Avoid_: 个人管理中心、AI 工作台、后台

**文章库**：
创作室中管理站主全部文章的统一入口，默认包含草稿、已发布和已归档内容，并提供封面、状态、更新时间、编辑与永久删除操作；“最近草稿”只是创作室首页的局部视图。
_Avoid_: 把全部文章入口称为文章草稿、只展示最近内容、把永久删除写成移除

**图库**：
公共站中用于欣赏和探索的精选图片空间，可包含站主原创、AI 生成和保留授权信息的收藏。没有显式策展数据时，图库以单层编辑式影像墙呈现，不从资源类型或标签推断主题合集。
_Avoid_: 资源库、图片资源

**编辑式影像墙**：
图库在尚无显式主题合集时使用的默认浏览形态。所有公开图片按现有数据顺序进入响应式瀑布流，保留原始比例并使用统一间距，访客可以直接进入单图查看；它只表达观看节奏，不制造内容分类或图片之间的策展关系。
_Avoid_: 自动合集、类型分组、标签分组、任意放大重点图、大面积装饰性空白

**专题精选**：
公共站的独立杂志式首页策展，由一篇重点文章与一组重点图片共同表达一个主题。它独立引用已有文章和主题合集，不改变内容的专栏或标签；没有固定频率或连续期号，由站主手动发布和切换，AI 只提供组合建议。
_Avoid_: 周刊、月刊、自动更换的推荐流、数据仪表盘

**专题版式**：
专题精选可选择的三至四套受控杂志布局之一，AI 可以推荐版式，站主可在发布前预览切换。
_Avoid_: 自由拖拽画布、AI 随机生成布局、每期固定同一版式

**专栏**：
文章可选择的单一主题归属，例如 React 或 TypeScript；它是站主在日常发布中唯一需要看到的分类字段。专栏内默认按最新发布排列，可将少量重要文章置顶。
_Avoid_: 分组、分类、系列

**检索标签**：
用于描述文章具体话题并辅助搜索的可选关键词，可由 AI 建议和维护；它不是日常发布的必填字段，只在文章详情中低调展示并提供关联浏览。
_Avoid_: 主栏目、文章系列、手工必填项

**主题合集**：
站主基于独立合集数据按主题和审美显式编排的图片集合。只有存在真实合集、标题、引言和人工选择的图片关系时才在公共图库呈现；资源类型与检索标签都不等同于主题合集。
_Avoid_: 文件夹、资源分类、从 `type` 或 `tags` 自动推断合集

**分发许可**：
兼容旧图片来源与下载限制的内容属性。新手工导入不再要求站主填写许可，默认允许预览与下载；旧资源已有明确限制时继续遵守兼容字段。
_Avoid_: 新导入必填许可表单、把空许可展示给访客、删除旧资源兼容字段

**AI 创作助手**：
在站主提供观点、素材或草稿后，协助组织、扩写、润色和准备发布素材的能力；系统默认按任务选择模型，站主可从高级设置临时覆盖，最终内容仍由站主确认。
_Avoid_: AI 作者、自动发布机器人、智能体平台

**改写建议**：
AI 对正文提出的可见变更，站主可逐段接受或拒绝；扩写、精简和润色等常用动作可从当前段落发起。
_Avoid_: 直接覆盖、聊天回复

**编辑快照**：
内容画布在 AI 改写前自动保留的可恢复状态，与持续自动保存和撤销一起防止站主的原文被误覆盖。
_Avoid_: 手动保存节点、完整版本管理系统

**内容画布**：
创作室中用于放入完整 Markdown 或零散观点的主要创作空间，AI 在其中准备正文、摘要、标签和封面，并由站主统一预览确认。
_Avoid_: 字段表单、对话记录、工作流画布

**发布检查**：
站主在发布文章前集中确认的内容摘要，包含 AI 已准备的标题、摘要、专栏、检索标签和封面；正文仍是视觉中心。
_Avoid_: 分步字段设置、隐藏的 AI 元数据、直接发布

**图库导入批次**：
站主在正式入库前统一整理的一组本地图片。批次共享资源类型、可见范围和视觉模型，可批量或逐图生成标题与标签；未入库文件和处理状态保存在当前浏览器的本地工作区，之后可以继续。
_Avoid_: 来源许可表单、服务端后台导入任务、关闭弹窗即丢失、逐图重复看图

**追加稳定瀑布流**：
公共图库在同一响应式列数下只把分页新图片追加到既有列尾，不重新分配已经显示的图片。跨越桌面、笔记本和手机列数断点时可以重新排布。
_Avoid_: CSS 多栏自动重平衡、分页后旧图片换列、为绝对不重排制造永久空洞

**图片草稿**：
AI 生成后默认保留在创作室的私有图片，只有站主明确选择“设为封面”或“加入图库”后才进入公开内容流。
_Avoid_: 自动公开的生成结果

**图片创作意图**：
站主进入独立 AI 图片创作时首先选择的任务类型，只包含文章封面、加入图库和自由创作；模型、尺寸和技术参数属于高级设置。
_Avoid_: 模型选择器首页、生成参数面板

**文章草稿**：
尚未公开的文章工作副本，可在创作室中继续编辑和预览；站主确认发布后才成为公共站内容。
_Avoid_: 待审核任务、自动发布队列

**封面视觉方向**：
属于站主的有限封面视觉语法，总数保持在三至五套；同一方向保留风格识别，但每篇文章改变构图、主体和配色。
_Avoid_: 完全随机风格、单一固定模板

**私有实验室**：
创作室中用于保留智能体、工作流、技能和知识库等试验能力的次级空间，只从创作室导航底部的次级入口进入，不定义个人内容站的主体验。
_Avoid_: AI 工作台、主导航

**内容回响**：
站主在创作室中查看的单篇文章或单张图片浏览、下载数据，用于了解内容是否被发现，不组织成运营仪表盘或排行榜。
_Avoid_: KPI、运营数据、创作者排名
