# Eon Vale · 纪元谷

Eon Vale 是一个浏览器单机 2D 像素神明沙盒。当前正在规划 5.6 核心重构：保留种子地图与像素表现基础，按原创的同类神明沙盒规则重建生命、生态、聚落、王国、战争、神力与观察层。新规则已经接受，但尚未进入运行时代码；当前页面仍运行旧内核。

## 启动

```bash
pnpm --filter @valley/eon-vale dev
```

打开 `http://127.0.0.1:5184`。拖动平移地图，滚轮按固定倍率在世界、聚落和居民三级视角间缩放；从底部工具栏选择地形、生物或神力，再点击地图施放。双击居民可进入近景跟随，顶部人口数字可展开出生、死亡、迁徙、承载力和年龄结构，底部可暂停并切换 `1×/2×/4×/8×` 时间倍率。

以下操作与能力说明描述当前旧内核，仅用于查看历史实现；5.6 实施并通过新验收门禁后会更新。

新世界支持 128、256、384 三种尺寸，以及群岛、主大陆、空白海洋三种形态。阶段 0 压测可直接使用设置面板的 100、500、1000 居民入口，也可打开 `?stress=1000`。性能面板展示 FPS、P95 帧时间、模拟 Tick、寻路队列、批次估算 Draw Calls 和三角形数。

树木、露天石料和金属矿脉是可采集、可悬停查看的独立节点。居民会按村庄需求预留节点、采集、携带并送回仓库；建筑要经历清障、分批运料和施工，矿场只能建在有限矿脉附近。资源和地图运行时都使用增量同步，不会每秒整图重绘。

聚落与王国批次已经完成：逐格领土、四级聚落、空间规划、工作热点、首都与前线、事实纪事和跨对象定位均可观察。兵营会训练在场守卫，议事厅增强领土治理，城墙在被攻破前阻止占领，瞭望塔会射击范围内敌军；损毁建筑立即失去对应能力。

第四批“完整野生生态与食物闭环”已经完成：动物死亡会留下可腐烂尸体，缺粮聚落的猎人追猎成年野生动物、屠宰并搬运肉类；采集者只能从陆地岸边消耗真实鱼群，渔获送达前不会进入库存，在没有可达野外食物和岸边鱼时会回退到可运行农田。生态面板可观察尸体、屠宰、捕获和腐烂累计值；250 年、2,000 年和 30 分钟 8× 长门禁均已通过。

第五批“全地图视觉推广”已经完成：正式像素资产覆盖居民、七种动物、树木、石料、矿脉和十二类建筑，完整地形在世界、聚落与居民三级 LOD 使用不同信息密度。相机按视口实际可见地图范围选择 LOD，宽屏下不会再把整岛误判为居民近景；正式资产与树冠前后遮挡已通过 owner 真实页面 `8×` 视觉验收。

第五批与 5.5 曾完成资产、食物来源、仓储、口粮、王国存续、群体诊断和长局验证，但完整世界观察发现 LOD 数量突变、视觉装备与权威数据冲突、野生威胁无文明响应、饥饿与捕猎脱节、空聚落无衰败反馈和“受阻”误报。原产品验收已撤回；第六批“海洋交通扩展”暂停，当前阶段为 5.6“核心可玩性重构”。

当前代码仍能读写 V13 开发期世界档案，但 5.6 新内核切换时将明确废弃 V13：不提供只读、迁移或旧 JSON 导入兼容。新存档使用独立 IndexedDB 命名空间，只保存新领域模型确认的权威事实。
