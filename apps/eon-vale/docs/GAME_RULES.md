# Eon Vale 地图规则

## 已接受

- 首版是桌面浏览器的原创像素地图沙盒，以 WorldBox 的地图可读性和功能广度为参照，但不复制其美术资产或界面。
- 借用 WorldBox 的方格像素、块状生境、分层海岸、簇状植被、俯视地面与直立物件等视觉语法；颜色、轮廓和具体素材全部原创。
- 最终方向是高可读性的手工像素生态地图：区域视图优先，使用干净像素簇、统一左上受光和克制主体色，不使用抗锯齿、半透明描边、整圈黑描边或高频抖色。
- 世界格、地表图块与物件帧是三个独立尺度：世界格承载地理事实，地表图块表现地面材质，物件帧表现独立物件，不再统称为 `tile`。
- 每个世界保持为可由种子复现的有限 `1024 × 1024` 世界格；扩大世界格总量不作为解决资源构图问题的手段。
- 世界视图按视口自动适配到约 `0.75–1` 屏幕像素/格，区域视图以 `4` 屏幕像素/格为基准，近景以 `16` 屏幕像素/格为基准。
- 每个世界格使用 `4 × 4` 原生像素的基础地表图块；相邻 `4 × 4` 世界格组成一个 `16 × 16` 原生像素材质组，用于控制斑块、纹理节奏并避免逐格棋盘噪声。
- 所有正式素材绘制在 `1px` 原生网格上，tile 与 sprite 画布原则上使用 `4px` 整数倍；普通 sprite 底部中心对齐整数世界格中心，画布、可见轮廓、逻辑占地和排斥区分别定义。
- 每种基础生境拥有三套由湿度、遮蔽、裸露程度或地表基质驱动的子材质；素材预算按“基础生境 × 地表材质族”的材质包计算，不再使用每种生境统一 `24/18/12` 的旧预算。
- 地表材质与基础生境分离：首套材质族为植被土壤、裸土、沙、泥、岩地、雪、冰和幻想叠层；基础生境从材质族中组合三套子材质，幻想叠层不成为独立 biome。
- 植被土壤与岩地材质包各包含 `16` 个基础变体、`12` 个材质组和 `12` 个叠层；裸土、沙、泥、雪各为 `12/10/10`；冰为 `10/8/8`；幻想叠层为 `12` 个小遮罩、`8` 个组级遮罩和 `12` 个主题细节。
- 同一基础生境内使用 `24–80` 格的大尺度地表斑块组织子材质；主体、次要、裸露或特殊子材质通常分别占核心区的 `60%–75%`、`20%–35%`、`5%–12%`，不得逐格随机混合。
- 区域视图是地图视觉验收的主场；世界视图约束大陆轮廓与生境分区，近景约束单个物件和局部构图。
- 首套生境以自然地理为核心，同时允许腐化、魔法侵染等环境主题叠加在基础地理之上。
- 每个世界格的自然视觉由三层事实组合：地貌带描述水陆与高程，基础生境描述气候与生态，环境主题描述可选的幻想侵染；三层不能重新合并成单一互斥 biome。
- 首套地貌带固定为深海、外海、浅水、岸缘、低地、高地和山地七级；浪线属于结构细节，不是地貌带。
- 首套水系同时包含海洋、湖泊与河流；河流是具有连续宽度和入海口的地理结构，不是叠在地表上的蓝色装饰线。
- 普通海岸的岸缘宽度为 `2–4` 世界格，浅水宽度为 `4–8` 世界格，并允许沿海岸缓慢变化。
- 首套岸型固定为沙岸、石岸、湿地岸和冰岸；岸型由相邻基础生境与局部高程决定，不为每个生境复制一套海岸。
- 海岸保留无抗锯齿的像素阶梯，但移除无意义的单格毛刺；主要凹凸、短湾和小半岛以约 `2–6` 世界格的尺度组织。
- 约 `5%–10%` 的高地或山地海岸可以形成悬崖岸；悬崖可缩窄或中断岸缘，但仍保留浅水和浪线。
- 世界视图的水面保持静态；区域与近景只使用稀疏的 `1–2` 原生像素高光、波纹和岸边浪花动画，深海主体保持低频平静。
- 水面由静态 tile、美术动画叠层和受限程序效果组合；shader 只做原生像素网格上的低频明度或色阶变化，不负责边界、浪花形状、平滑扭曲或亚像素波浪。
- 深海、外海、浅水分别至少拥有 `8/6`、`12/8`、`16/12` 组基础变体/材质组；浅水另有 `8` 个海床叠层。每种岸型至少有 `12` 个基础变体、`10` 个材质组和 `8` 个岸缘细节；外海、浅水和岸型分别有 `3`、`4`、`3` 组动画序列。
- 外海通常形成 `12–32` 格宽缓层，浅水保持 `4–8` 格，岸缘保持 `2–4` 格；小水体可压缩层宽但不能颠倒顺序。
- 湖岸使用 `2–4` 格浅水和 `1–3` 格岸缘；较大湖泊可以拥有外海核心，只有极大深湖允许深海核心。
- 支流宽 `1–2` 格，普通河流宽 `2–4` 格，主河道宽 `4–6` 格，入海口可以扩展到 `6–8` 格；河岸使用约 `1` 格过渡，不套用完整海岸带。
- 相邻基础生境通过约 `4–12` 格宽的块状交错带过渡；每格仍归属于明确生境，不使用连续颜色渐变。
- 生境交错使用三步桥接：先改变子材质权重，再引入双方共有或中性的材质族，最后逐步替换覆盖物、灌木和树种；不为每对生境制作专属混合 tileset，也不创建混合 biome。
- 低地到高地使用 `2–4` 格破碎抬升带；高地到山地使用 `3–6` 格岩脊、碎石坡和局部阴影，边缘必须留有缺口而不是形成整齐围墙。
- 超过 `90%` 的相邻树冠在区域视图保留 `1–4` 原生像素的可见缝隙；最多约 `10%` 可轻微前后叠压，但不允许三棵以上连接成连续树冠色块。
- 植被密度以用户指定的 WorldBox 区域视图为标尺：树木遍布适生区域但密度缓慢变化，局部形成不规则林团、口袋空地和地面通道；最密处仍持续露出地表，生境边缘通过降密度与树种混合渐进过渡。
- 各基础生境核心区的区域视图树冠覆盖率固定为：温带草原 `4%–10%`、温带林地 `18%–28%`、热带雨林 `22%–34%`、稀树草原 `8%–16%`、沙漠 `0%–3%`、湿地 `6%–14%`、苔原 `0%–5%`、极地 `0%–1%`；覆盖率不凌驾于树冠间隙规则。
- 植被分布使用三层空间结构：`64–192` 格的宏观密度区控制缓慢密度变化，`12–40` 格的局部林团控制聚集形状，`6–24` 格的空地与地面通道保留连续负空间；三层不能合并为一个噪声阈值。
- 地表覆盖物分为丰富、普通、稀疏三个密度档：温带草原、热带雨林和湿地为丰富，温带林地和稀树草原为普通，沙漠、苔原和极地为稀疏；生境差异主要来自素材组合，不能只靠增加数量表达。
- 稀疏、普通、丰富档分别让 `20%–35%`、`40%–55%`、`55%–75%` 的材质组承载独立覆盖物；每个有效材质组分别放置 `1`、`1–2`、`2–4` 个锚点，且 `8×8px` 覆盖物每组最多一个。
- 普通装饰拆成结构细节、环境覆盖物和稀有焦点三个层级；大型环境地标独立管理，不与普通装饰共用密度预算。
- 每种基础生境至少提供 `12` 个环境覆盖物轮廓、`6` 个小型地图物件轮廓和 `3` 个稀有焦点轮廓；另有已经计入地表系统的 `12` 个地表叠层素材。
- 树木、主要植物和高饱和焦点必须为生境专属；普通岩石、枯枝等中性物件最多约 `40%` 可跨生境共享，但必须适应所在生境的色阶与资源组合。
- 高饱和装饰只出现在约 `5%–12%` 的材质组中，至少 `25%` 的材质组不放独立覆盖物或焦点装饰，只保留基础地表材质。
- 普通覆盖物形成跨 `2–6` 个材质组的松散斑块，高饱和装饰只形成 `1–3` 组的小簇，同类稀有焦点之间至少相隔 `32–64` 世界格；装饰不逐格随机撒点。
- 环境覆盖物与稀有焦点必须让位于岸线、河道、高程边缘、地图物件和地标占地；低矮覆盖物可进入树冠阴影，但树干周围至少保留 `1` 格净空，并保住林间空地和地面通道。
- 海岸、河岸、高程边缘和生境交错共享直边、内外角、末端、狭窄通道和孤立小块六种几何角色；每种至少有 `3` 种不规则边缘节奏，各方向按左上光单独处理，不机械旋转。
- 地貌与封闭地表边界使用八邻域、对角受正交约束的 `47` 种拓扑；bitmask 只决定几何连接，每种拓扑至少有 `3` 种确定性选择的不规则节奏，不决定材质或 atlas 坐标。
- autotile 使用 `141` 个可复用二值几何遮罩与材质边缘叠层组合，不为每对生境制作整套全彩图块；高程断面、悬崖和浪花保留独立素材。
- 八种基础生境的资源主语分别为：草原的明亮草地与野花、林地的湿润阔叶与蕨、雨林的宽叶与异形高树、稀树草原的暖草与伞冠树、沙漠的沙纹与耐旱植物、湿地的泥水与芦苇、苔原的地衣与矮灌木、极地的雪冰裂纹与裸岩；不能只靠换色表达差异。
- 首套基础生境固定为温带草原、温带林地、热带雨林、稀树草原、沙漠、湿地、苔原和极地八种，并可与地貌带自由组合。
- 自然地图视觉完成后只制作一个“腐化”环境主题作为叠加验证；其他幻想主题不进入首套资源范围。
- 腐化使用 `6–16` 格不规则侵染前缘，地表叠层最多覆盖局部约 `20%–35%`，最多替换约 `15%–30%` 的植物和装饰，并至少保留 `60%` 的原生境色彩与材质关系；不得抹除基础地理或使用统一单色滤镜。
- 单靠地表颜色与纹理应提供约 `60%–70%` 的生境识别，植被、岩石和覆盖物补足其余差异。
- 森林采用有明显间隙和空余位置的植被簇；即使树木较多，树冠也不能连接成连续铺满的树墙。
- 地表采用正俯视投影；树木、岩石等地图物件以底部锚定的直立轮廓表现，并遵守统一的左上方受光。
- 首套地图资源包括树木、灌木、岩石、矿簇，以及遗迹、巨树、洞口、陨石坑等大型环境地标；当前资源美术不作为质量基线，全部重新设计。
- 普通地图物件由一个世界格锚定，视觉轮廓允许跨越多个世界格；大型环境地标可以拥有明确的多格占地区域。
- 每个 `64×64` 格区域允许 `0–2` 个中型环境地标；大型地标平均每 `160–256` 格出现一个。中型与大型地标周围分别保留 `4–8` 格和 `8–16` 格降密度区。
- 世界视图以 `1–4px` 专用轮廓或色点保留大型地标，区域与近景分别以 `1×` 和 `4×` 显示原生素材；地标的位置、朝向、占地和净空不随缩放改变。
- 遗迹只作为无法归属具体文明的环境残迹，不引入建筑类型、文化、国家或历史模拟。
- 三档观察读取同一批地图事实：世界视图只保留林团色块和少量像素点，区域视图显示清晰但简化的独立物件，近景显示完整轮廓；不把同一张近景素材直接缩小到所有层级。
- 世界视图使用专用色点与林团表达；区域和近景共享同一套原生物件帧，分别以 `1×` 与 `4×` 最近邻显示。
- 世界视图把普通覆盖物聚合为少量纹理像素或色点，区域视图显示独立覆盖物，近景以 `4×` 最近邻显示同一素材；缩放不重新生成位置或改变覆盖物斑块范围。
- 资源使用受控尺寸族：覆盖物为 `4×4` 或 `8×8`，小型物件为 `8×8` 至 `12×16`，普通树木由 `16×24` 扩展至最大 `32×48`，中型地标为 `32×32` 或 `48×48`，大型地标为 `64×64` 至 `96×96`。
- 正式资产分类为地表材质、地表叠层、低矮覆盖物、小型直立植被、树木、枯死植被、岩石与矿物、环境地标和动态效果；同名材质与独立 sprite 必须使用不同语义资产 ID。
- 树木使用幼树、成熟树、老树/高大树三档视觉年龄，尺寸分别为 `16×24`、`24×32`、`32×40`，比例约 `20%–25%`、`60%–70%`、`10%–15%`；年龄不产生生长模拟。
- 树木另有紧凑/宽冠、标准、高干/细长三档高度形态，比例约 `30%/50%/20%`；幼树只用前两档，成熟树与老树可用三档。最大普通树画布为 `32×48`，高度不产生生长模拟。
- 同一树种必须变化冠幅、树干、枝叶偏心、顶部缺口和风蚀形态；枯树、烧焦树和腐化树使用独立资产族，不由活树调色代替。
- 八种生境共至少 `19` 套专属树木原型：草原 `2`、林地 `4`、雨林 `4`、稀树草原 `3`、沙漠 `1`、湿地 `3`、苔原 `2`、极地 `0`；主、次、稀有树种比例分别约为 `60%–75%`、`20%–30%`、`5%–10%`。
- 每套树木原型至少有 `15` 个真实轮廓：幼树 `3`、成熟树 `8`、老树 `4`；`19` 套原型共至少 `285` 个活树轮廓，枯树、烧焦树和腐化树另计。
- 任意世界格都可成为普通地图物件的锚点；实际放置由环境条件、植被簇和物件排斥半径共同决定，不使用固定间隔锚点或小数坐标。
- 地图资源采用紧凑但不规则的原创像素轮廓，不使用整圈黑描边或高频抖色；深色侧面与落地阴影负责分离物件，顶部和左侧统一受光。
- 每个基础生境使用约 `6–10` 个地表主色；普通物件通常使用 `3–5` 个主要色阶，并共享全地图的光照与阴影色族。
- palette 采用共享色彩角色与生境局部色盘：全地图共享暗部、落影、高光、中性岩石及水体色阶，单个素材最多使用 `1–2` 个高饱和强调色；placeholder 保持同一明度和角色关系。
- 地图生成只输出语义资产 ID、地理事实和确定性变体种子，不引用文件名或 atlas 坐标；视觉 manifest 映射当前 tileset。正式素材必须保持尺寸族、锚点、占地、层级和动画状态契约，但允许重新打包 atlas。
- 常用装饰按类别锁定真实轮廓下限：草簇、灌木、小石各 `8`；花、苔藓/地衣、蕨、芦苇/高草、仙人掌/多肉、独立岩石/岩簇、枯树、岸缘碎屑各 `6`；蘑菇、矿物/晶体、枯枝/树桩各 `5`。
- 常见树木、灌木和草簇每轮廓允许 `2–3` 个人工校准 colorway，花与高饱和植物 `3–4` 个，岩石/枯枝/枯树 `2` 个，稀有焦点 `1–2` 个；colorway 不计入 variant，程序不得任意 HSV 染色，本阶段不加入季节系统。
- 素材选择使用确定性洗牌袋与局部重复冷却：树木轮廓 `12–20` 格不重复，同一轮廓/colorway `20–32` 格不重复，低矮覆盖物 `4–8` 格、灌木与岩石 `8–16` 格内避免重复；相同种子保持完全一致。
- variant 必须在轮廓、主要像素簇、宽窄、高矮、偏心、缺口或姿态上形成区域视图可辨差异；换色、镜像、旋转、动画帧、shader 相位和无关噪点不计数。带方向光照素材不得程序镜像或旋转。
- 必须动画的素材仅包括水面稀疏高光、岸浪、河流局部流纹和少量腐化焦点；芦苇、高草、大型花与少量宽叶植物允许低频局部动画，普通树木、灌木、岩石、枯树、基础地表和环境地标保持静态。
- 运行时 atlas 按 `terrain-ground`、`terrain-transition`、`water`、`vegetation`、`ground-decoration`、`landmark`、`effects` 和 `lod-world` 分类，由 manifest 映射，不按枚举行号定位。
- 区域视图直接使用正式 sprite 原生 `1×`，近景使用同一素材 `4×` 最近邻；不存在独立 `lod-region` atlas。世界视图的聚合由程序计算，但使用美术提供的 LOD 符号与 palette。
- 语义 ID 使用点号分层与小写 `snake_case`，variant/帧使用 `v01`/`f01`；源文件名不包含 atlas 坐标、打包页或作者信息。
- 独立交换源素材使用无损 PNG；运行时 atlas 页最大 `2048×2048px`，sprite 间保留 `2px` padding。tile 不裁切，sprite 裁切时必须在 manifest 保留原始画布、锚点与偏移；禁止缩放打包、颜色压缩、抗锯齿和 mipmap。
- 美术负责所有可见像素形状、动画关键帧、palette、明暗、shadow mask 与世界 LOD 符号；程序只负责语义、权重、bitmask、组合、确定性选择、分布、LOD 切换和水体低频色阶变化，禁止用程序生成轮廓或 shader 掩盖素材不足。
- 物件自身明暗画入主体 sprite，落地阴影由同 variant、同画布、同锚点的独立 shadow mask 提供；程序只统一调整阴影色与透明度，不自动生成模糊投影。低矮覆盖物通常不需独立阴影，大型树木、岩石和地标必须提供。
- 现有四张 SVG atlas、枚举行序、帧布局和材质美术全部作为旧原型废弃；新 placeholder tileset 从头建立，不承担视觉兼容。
- placeholder 分为 P0 契约占位、P1 温带草原/林地与完整水岸/高程/腐化视觉切片、P2 八生境全覆盖三档；P2 每类只需达到正式 variant 下限的约 `25%–40%`，正式替换不得改变地理事实、物件位置或确定性种子。
- visual manifest 必须版本化，并完整记录语义标签、atlas 帧、源画布与裁切偏移、锚点、占地与净空、层级与溢出、palette/colorway/权重、shadow mask、动画和世界 LOD 引用；生成器不消费打包坐标。
- palette library 使用命名色盘：全局结构色约 `12–16` 色、水体约 `12` 色、每个生境 `6–10` 个地表色与 `4–8` 个物件/强调色、每个环境主题 `6–8` 个强调色；普通 sprite 使用 `3–5` 个主要色阶。
- 所有新素材必须同时通过 manifest/尺寸/锚点/atlas/palette/alpha/动画的自动检查，以及 `1×/4×` contact sheet、`64×64` 密度重复测试、`47×3` 过渡图集、跨 LOD 和四组视觉验收板检查。
- 新世界只由内置模板与种子生成；模板约束宏观海陆结构和参数范围，种子决定具体地貌、生境、植被与装饰。同一模板和种子必须得到相同地图事实。
- 当前产品不提供地图编辑、保存或加载。选择模板后进入 loading，生成成功时一次性显示完整新世界；半成品地图不成为当前世界。
- 正式逻辑 chunk 为 `64×64` 世界格；详细 chunk 按视口构建和淘汰，不在世界视图常驻整套区域/近景纹理。
- 桌面浏览器首轮性能门槛为：可信进度反馈 `≤1.5s`、完整 snapshot 与世界视图 `≤5s`、可见区域/近景细化 `≤150ms`、稳定交互 `60 FPS` 且 P95 帧时间 `≤25ms`、地图自有 CPU 与 GPU 内存合计 `≤256MiB`。
- 正式发布前不兼容旧地图、旧生成器或旧 visual bundle；生成规则变化时直接提升版本并重新生成测试世界。
- 首版提供大陆、双大陆、群岛、岛链、内海、环陆、破碎海岸和三洲八个原创宏观模板；模板不固定 biome 配方，具体世界可以自然缺少个别生境。
- seed 默认自动生成且不在玩家入口展示；只有开发诊断模式允许输入或复用。模板概念图只表达宏观类型，不冒充当前 seed 的结果。
- 已有世界时重新选择模板必须确认替换；生成期间使用独立全屏 loading，可取消返回模板选择，不显示旧世界或半成品地图。
- loading 只显示真实加权百分比、当前阶段和具体状态；visual bundle 更新必须原子校验，失败时保留上一套有效目录，首次失败回退内置 P0。
- LOD 使用屏幕像素密度、迟滞区间和 `100–160ms` 交叉淡化；详细 chunk 在固定内存预算中按视口距离、相机方向和最近使用时间混合淘汰。
- `WorldSnapshot` 只保留高程、地貌带、水系、基础生境、地表材质、环境主题和最终稀疏物件；温湿度、噪声、斑块场与植被簇场在生成完成后丢弃。
- 水系逐格保存海洋/湖泊/河流类型、河流等级与流向，不建立海洋、湖泊或河流对象；地表斑块和植被簇也不拥有长期 ID。
- 地图物件使用按 chunk 和锚点排序的稀疏紧凑数组，保存稳定会话 ID、锚点、语义族、形态标签和 variant seed，不为百万格建立对象表。
- `WorldRulesCatalog` 独立拥有模板、生态、密度、尺寸族、逻辑占地和排斥规则；生成器不得读取 visual manifest。资产导入必须验证 `VisualCatalog` 满足相同语义族和资产契约。
- `RenderChunkPlan` 按地表、过渡、低矮覆盖物、落影、直立物件、前景遮挡、水面/环境效果、选择反馈组织紧凑批次；Pixi 不重新解释 biome 或选择 variant。
- 动画使用全局视觉时钟和位置/seed 相位偏移，只更新可见 chunk；页面失焦暂停，低动态模式关闭可选植物动画并降低水体更新频率。
- 生成失败保留原模板和 seed，允许相同输入重试或返回模板；不得自动换 seed，也不得提交半成品 snapshot。
- Worker 完成后使用 Transferable ArrayBuffer 一次性交出 snapshot，主线程不复制完整地图；过期 job 的迟到消息必须忽略并释放。
- `MapSession` 是页面唯一地图 seam；React 只读取模板、seed、loading、错误和 LOD 等低频状态，不持有地图数组、Pixi 对象或 chunk 缓存。
- 地图生成、visual catalog 校验与 atlas 解码在 loading 中并行；snapshot、有效视觉目录和世界视图 texture 全部完成后才进入地图。
- 静态地表、过渡和静态低矮覆盖物预栅格化为 `64×64` chunk texture；直立物件、落影、前景片和动画只为可见/预取范围建立 sprite batch。
- 世界视图使用独立的 `1024×1024` 静态 texture；它不缩小区域 texture，也不播放动画。
- `MapCache` 统一核算 projection、CPU 与 GPU 资源；相机交互时 projection/上传预算约 `4ms/帧`，静止或 loading 时约 `8ms/帧`，过远未完成任务可以取消。
- 区域与近景共享静态 texture、已解析物件和 sprite 来源；近景只整数放大并开启允许的细节，不建立第二套完整缓存。
- 八种模板是 `WorldRulesCatalog` 内部类型化只读数据，不提供运行时 JSON、用户模板或 mod 接口。
- 世界内 visual bundle 替换必须先准备完整新目录、世界视图和当前可见 chunk，再原子交叉淡化；失败保留旧画面，任何帧不得混用新旧 catalog。
- snapshot checksum 覆盖所有权威元数据、逐格数组与稀疏物件数组；每种模板使用固定 seed 的精确 checksum 和结构不变量双重验证。
- projection 使用 plan golden 与拓扑/halo/variant/重复冷却属性测试；renderer 自动验证资源生命周期，最终像素使用真实浏览器 contact sheet、LOD 和地图视觉板验收。
- 性能降级只能依次缩小预取、降低可选动画和水体更新频率、淘汰不可见近景/区域缓存；不得改变可见物件、variant、锚点、像素清晰度或当前 LOD。
- P0、P1、P2 每阶段都必须通过 loading、内存、帧时间和可见细化门槛，失败阻断后续推进。
- 新 P0 链路完成模板、loading、世界视图和一个区域 chunk 后切换应用入口，并立即删除旧四张 SVG、旧 loaders 和旧 renderer；不保留双运行时或兼容 adapter。
- `MapSession` 顶层状态固定为模板选择、loading、失败、世界和销毁；loading 不保留旧世界，销毁是终态，visual bundle 准备只是世界内部状态。
- 正式 renderer 要求 WebGL2，不维护 Canvas2D fallback；DPR 支持 `1–2` 并封顶 2，静止相机对齐设备像素，所有地图 texture 使用最近邻。
- Pixi/MapSession 内部拥有平移、缩放、LOD 和高频 viewport；React 只接收低频状态与选择摘要。
- 首版保留世界格和地图物件 hover/click，只公开稳定 ID、格坐标和语义摘要；选择反馈不修改地图事实。
- UI 只接收生成失败、素材包无效、GPU 不支持、内存预算超限和渲染失败五类稳定错误；详细异常只进入开发诊断，P0 回退是非致命状态。
- 新运行时统一进入 `src/map`，页面只从唯一公共入口创建和订阅 `MapSession`，不得深层引用生成、投影、视觉、渲染或缓存实现。
- 首版只实现地图效果：远景辨识地貌、生境与海岸轮廓，近景辨识规格统一、分布克制的树木和岩石等地图物件。
- 居民、动物、房屋与其他建筑、聚落、王国、经济、时间模拟、神力、旧地图和旧存档兼容全部不在首版范围。
- 首版只保证桌面浏览器的鼠标和键盘交互。
