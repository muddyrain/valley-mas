# 让重新武装和流亡继续遵守聚落事实

首轮不以家庭团聚为例外开放跨国迁居。跨国亲属关系和分离历史继续保留，真实团聚等完整接纳、国籍、路线、住房、食物与外交规则形成后再实现。新征服聚落只有在安全、领袖、生存、生产、训练、装备、人口和近期征服稳定条件满足后才能正常训练，先建立本土守备，再恢复远征能力。

战后恢复完成由危险解除、食物/住房/储存安全底线、核心生产、治理与最低防御事实派生，不依赖固定年份或全建筑满耐久。完成只解除战后运行限制，征服历史、政治履历、近期征服与战争积怨继续按各自规则保留和衰减。

原聚落被占但仍在外部的旧国军队不再是普通本村军队，而转为失所军队。成员保留旧国、队长、伤势、装备和携带物，但没有聚落库存、住房、训练、生产或补员能力；他们必须真实撤往旧国存续聚落并在抵达后接纳重组，或在无聚落时维持流亡并按真实定居条件求生，不能同时属于被占聚落与旧王国。
