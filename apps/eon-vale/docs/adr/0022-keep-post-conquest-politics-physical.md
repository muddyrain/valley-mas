# 让驻防、归属、继任与历史保持真实

首轮不创建独立永久占领军。完成占领的现有军队只在战争或局部威胁仍成立时临时驻防，继续使用自己的成员、队长、装备和真实补给，并占用母聚落的远征能力；条件解除或母城守备不足时沿真实路线撤回。新征服聚落只能通过普通训练、装备和人口容量重新建立本地军队。

被占居民的当前王国随所属聚落改变，家庭、住宅、亲属、物品和本地身份不重置；原王国和旧政治职位只作为政治履历与忠诚解释保留，不形成永久双重国籍。国王与领袖只能真实逃离，未能撤离者在归属改变时失去旧职位；旧国仍有存续聚落时迁都并按真实资格继任，有公民而无聚落时流亡，无公民时灭亡。

占领扩散、原子换旗、驻防、撤军、损毁和恢复必须在居民、聚落和世界三层连续可见。每次征服形成结构化事件，连接战争、目标聚落、旧/新王国、战役主张方、军队、伤亡、军队解散和政治结果，并进入人物履历、聚落纪事、王国纪事与战争历史；临时特效可以消退，历史事实不能丢失。
