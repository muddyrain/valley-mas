# 由聚落组成王国并保持真实资源所有权

王国由真实聚落组成，而不是直接拥有一批居民或一份全局库存。独立聚落建立自己的王国；既有王国居民完成殖民建村时，新聚落继承原王国；同种族或距离接近不会自动合并独立王国。居民先属于聚落，王国归属由聚落派生，迁居或殖民途中只暂时延续原归属，避免居民、聚落和王国三份成员事实互相漂移。

建国聚落成为稳定首都，合格建国者成为首任国王；国王与聚落领袖是不同角色，后续国王从合格聚落领袖中产生。首都仍属本国且可以恢复时不因规模变化迁移，只有失守、毁灭或持续不可恢复时才从存续聚落中按可观察事实选择新首都。

资源继续归各聚落库存，王国不建立可以瞬时共享的资源总仓库。同王国供应必须由缺口、供给方真实余量、本地安全储备、可达路线、运输者和实际交付共同成立。这个边界保留断粮、运输、劫掠与围困的因果空间，也避免王国层政治决定覆盖居民和聚落的日常自治。

跨王国贸易、外交援助、战争赔款和复杂王朝继承只作为后期候选记录；在分别形成行为契约前，不增加运行时字段、占位入口或空法则。
