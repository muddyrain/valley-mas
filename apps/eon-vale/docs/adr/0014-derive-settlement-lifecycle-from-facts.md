# 从权威事实派生聚落生命周期

聚落只保存人口、生存供给、安全、住房、库存、生产承诺和建筑健康等权威事实；正常、承压、饥荒、濒危、废弃、衰败、被接管和毁灭是确定性派生状况，用于规则触发与玩家解释，不能被系统任意切换。只要仍有一名真实居民归属聚落，它最多处于濒危而不是废弃；最后一名居民死亡、迁出或放弃归属的同一模拟步骤结束后，聚落立即废弃。

废弃不等于从世界删除。当前原子结果完成后，聚落取消任务、机会、预留和在途承诺，停止生产、训练、建设、防御、领土扩张与新项目；建筑、库存、现场资源、领土残余和历史身份仍是事实。建筑按材料、损伤和环境衰败，储存端点失效时物资成为现场资源，领土逐格消退。

相容居民必须真实进入、确认安全、建立归属并修复至少一个文明锚点，才能接管并恢复旧名称、历史和仍存在的资产；敌对文明需要占领过程。只有零居民、领土归零且全部文明锚点不可恢复时，聚落才毁灭，剩余建筑成为可交互遗迹。停产、灯火消失、建筑破损、资源暴露、植被回长、修复和遗迹必须投影到地图，不能只改变检查器文字。

居民层按建筑真实健康连续显示停产、褪色、污损、缺口、坍塌、现场资源和植被回长；聚落层使用降饱和、领土淡化、破碎轮廓与活动密度表达阶段；世界层只标记战略性废弃地、正在接管的地点和大型遗迹。接管先显示勘察、清障、运输和修复，只有文明锚点真正恢复时才同步恢复名称、基础灯火、局部活动与功能，领土和其他建筑随后按事实进度回来。
