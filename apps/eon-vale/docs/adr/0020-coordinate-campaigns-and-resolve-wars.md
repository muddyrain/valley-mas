# 稳定目标、事实占领与可解释停战

征服战争只从陆路可达的敌方聚落中选择战役目标，优先邻接或连续推进并综合补给距离、守军、防御与战略价值。目标在完成、失效、路线断绝或军队安全撤退前保持稳定；每支聚落军队同一时间只承担一个目标，多军通过所需兵力、承诺、集结点、路线和抵达事实协同，不把所有军队合并成一个王国兵力数字。

占领只在目标聚落的真实逐格领土内由持续军事控制推进。组织化守军和有效防御设施会阻断完成，防守恢复、进攻撤离或第三方夺取控制会暂停或逆转进度；普通平民不计作守军。完成时原子转移聚落王国归属，并由成员聚落并集派生新王国领土，居民、建筑、库存、现场资源、损伤和历史都保留为原对象。

议和与投降根据战役目标、占领结果、剩余军力、伤亡、疲劳、食物、首都风险与长期无进展共同派生。活跃接敌或占领提交期间不瞬间停战；战争结束后取消未完成敌对命令，军队真实撤离，并把关系转入具有最短稳定窗口的休战。具体评分与时间只在新内核场景中校准，不迁移旧随机公式。

地图把王国领土显示为可切换的低透明度王国色、强外边界、细聚落分界、名称/旗帜和首都标识；悬停、选择和关系层可以强化目标并用颜色、线型、纹理或图标表达盟友、敌人、和平与休战。所有边界、战役箭头、占领和停战视觉均来自权威事实，不另建装饰性的“势力范围”。
