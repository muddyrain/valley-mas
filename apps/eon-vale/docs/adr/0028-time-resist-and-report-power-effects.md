# 统一世界时间、显式抗性与神力事件反馈

所有有期限神力状态、环境过程和灾害生命周期以剩余模拟 Tick 为权威，暂停冻结且时间倍率只改变现实等待，存档必须从同一剩余时间与阶段继续。抗性只来自物种或明确能力：疾病免疫、强心智、防火和抗寒分别作用于登记的感染、狂暴、燃烧和冻结结果；王国、职位、家庭、收藏与屏幕可见性都不提供保护。

雷击使普通目标重伤，火焰和冰霜按暴露累积，龙卷风通过路径中的击退与多次伤害致险，陨石中心通常致命并破坏脆弱建筑，地震以广域建筑和资源破坏为主。具体数值通过居民、武装士兵、动物与基础建筑的确定性场景校准，护甲只减少能够解释的物理伤害。

一次成功的连续画笔手势、点灾害或外交提交形成一个神力事件，持续汇总命中、抗性、感染、死亡、损坏、受影响聚落和结束原因。局部视听、三级地图、检查器、全局通知与长期历史共享该事件摘要；收藏人物和重要目标只触发风险提示与更高通知优先级，不获得隐形免疫。
