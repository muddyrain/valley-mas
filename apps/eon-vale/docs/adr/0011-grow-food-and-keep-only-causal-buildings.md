# 真实种植食物，只保留有因果作用的建筑

首条单聚落切片用野外食物支持开荒，以农田作物提供稳定主粮，并允许成年野生动物提供机会性肉食；捕鱼在陆地切片通过后恢复。农田必须经过整地、播种、生长、收割和运输，不能按建筑数量被动增加库存。

第一条切片只保留营火、帐篷/住宅、基础储存点/仓库、农田、工坊/铁匠和训练场/兵营。木材、石料与普通金属直接从地图节点采集；其他旧建筑只有在后续行为契约证明不可替代时恢复。

首轮只有帐篷升级住宅、基础储存点升级仓库。前者提高床位、休息效率、家庭稳定性和耐久，后者提高分类容量与并行取放能力；两者必须在轮廓、材料和状态反馈上明显不同。没有独立行为效果的升级不进入状态或存档。

农田、工坊和训练场提供有限工位。只有工人在场、输入真实可用并完成持续工作后才产生输出；输出仍需送达储存端点。损毁、缺料、满仓或无人时停止生产。
