# 按语义投影世界，并揭示被遮挡生命

缩放不能改变世界成员，也不能按对象标识随机留下少数树木和生命。居民层绘制视口内真实对象，聚落层把同源成员聚合为带精确数量和严重度的森林、生命群与活动热点，世界层只保留战略事实；过渡使用稳定边界和短渐变，选中、收藏与关键对象保持连续。

场景按地面接触点交错排序，树冠拆成真实遮挡层。未选生命被严重遮挡时仍有克制轮廓，悬停或选中只局部揭示必要树冠；这样居民在森林里可读，又不会把全部树木永久透明。拾取从真实可见生命及其轮廓开始，并在活动工具下收敛到合法目标类别。

全世界语义投影替代常驻小地图，`M` 和观察返回栈保留相机上下文。居民、聚落、王国、军队、战争和灾害使用统一右侧检查器；近景动作、中景热点和远景事件都来自同一权威事实，超出屏幕预算时按来源、空间和严重度确定性聚类，而不是随机隐藏。
