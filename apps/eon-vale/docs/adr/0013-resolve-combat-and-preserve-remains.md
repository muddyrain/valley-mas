# 只提交事实伤害，死亡保留可回收尸体

个体攻击在动作命中检查点提交一次权威伤害：身体或物种、真实武器与技能构成攻击，攻击速率控制频率，护甲按比例减伤，有限暴击来自确定性随机序列；首轮不使用普通命中率。真实武装守卫可以主动响应聚落威胁，猎人只在有效狩猎任务中主动攻击猎物，平民优先逃跑并仅在被困、受击或近亲直接遇险时自卫。重伤、精力不足或孤立允许战斗者脱离，个人投降、俘虏和战俘系统后置。

死亡不会把实体直接变成烟尘或掉落奖励。原位置生成保留稳定身份、死因、死亡时间、装备和携带物的尸体，并释放活体任务与岗位；物品只能通过本方回收或敌方搜取行动转移，尸体腐烂后耐久物品仍留在地面。近景使用克制的武器轨迹、命中火花、少量血点、受击、有限击退、按情境血条、撤退、倒地与尸体，声音按区域和时间限流；首轮只实现徒手、单手挥击、长柄突刺、动物攻击和基础防御/脱离动作。

动物尸体只在有限屠宰窗口内提供肉食，之后自然腐烂。人类尸体同样只有有限存在窗口，聚落可以发布受人口、安全、距离、库存和生存压力约束的遗物回收机会，但不搬运尸体；窗口结束后尸体自然腐化，耐久物品留在原地，死者身份、死因与地点进入历史。大量死亡不会创建无限并行任务，也不会通过自动删除复制或吞掉遗物。
