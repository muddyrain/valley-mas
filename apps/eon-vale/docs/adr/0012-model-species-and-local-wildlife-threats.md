# 用物种档案、本地种群和局部威胁事件驱动动物

新内核为每个动物物种建立独立档案，定义体型与生命阶段、寿命、不同移动速度、可通行环境、感知、饮食与目标矩阵、繁衍、逃跑、攻击、危险等级和栖息偏好。动物围绕连续适生栖息地活动；饥饿、威胁、伴侣和局部容量压力可以扩大搜索，但不能绕过通行、风险、体力与追逐上限。

种群容量按本地栖息地结算。繁衍需要合格成年个体、伴侣、营养、安全和剩余容量；人类普通狩猎不选择幼体。开启自然回归时，只有该世界曾存在过、当前低于本地恢复下限且仍有适生环境的物种，才允许小群回归。

聚落根据食物净缺口发布有限狩猎机会，合格猎手自主领取并预留可达成年猎物。食物必须通过追踪、真实战斗、死亡、尸体、屠宰、携带和送达储存端点产生；目标或路径失效、危险和紧急生存会按类型中断任务，不能远程入库或复制肉食。

危险动物进入聚落领土或居民可感知危险范围就产生局部野生威胁事件。该规则同样覆盖“捕食者正在追逐另一只动物但穿过营地”的场景：平民感知并避让，经过训练且真实装备的守卫进入警戒并评估响应。事件记录来源、位置、严重度、范围和最近感知时间；动物离开且一段时间未再被发现、没有正在发生的攻击后解除，守卫不得跨地图无限追击。

首条陆地切片启用鸡、羊、牛、鹿、狼和熊；鱼只保留物种档案，待捕鱼切片恢复。默认 `384×384` 世界按适生面积自然维持约 `400–700` 只陆生动物，新内核必须通过 `1,000` 名人类与 `1,000` 只活跃陆生动物并存的 Web 门禁，但不会把性能门禁误作强制世界上限。野生入侵采用分级响应：路过触发警戒、避让和拦截，继续接近文明目标时升级，实际追逐或伤害居民时进入战斗；离开感知范围后解除，守卫不跨地图无限追杀。
