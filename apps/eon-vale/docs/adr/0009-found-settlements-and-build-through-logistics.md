# 居民自主建村并通过真实物流施工

新世界默认生成自然生态而不生成文明居民；玩家通过文明生命工具逐个点击或拖动投放真实个体。一个不属于现有聚落的成年文明居民，只要附近具有连续可建空间、可达食物与树木，并远离不可适应地形、持续威胁和其他聚落，就可以形成定居意图并真实移动到选址建立营地；附近未归属且相容的同类居民随后自主加入。当前区域不合格时只做有限搜索，并向检查器报告原因，不传送或跨地图游荡。

新聚落不获得食物、木材或石料礼包。首个营火、帐篷和基础储存点是零材料原始设施，但仍需要合法选址与居民劳动；玩家新投放的居民以健康、营养充足和正常精力开始。一个成年人可以建村，但人类繁衍需要真实合格的成年伴侣，系统不生成免费伴侣或允许单人无性繁衍。

聚落根据住房、食物、仓储、生产和安全净缺口选择建设项目，并检查人口、前置建筑、资源、场地和劳动力。营地初期只允许一个项目，后续只增加有限并行槽位。项目先预留合法工地，再发布真实材料运输和施工机会；材料与劳动都完成后建筑才启用。

工地失效时释放未领取预留，已经送达的材料保留在现场等待搬回、复用或损失。取消和失败不能把材料瞬移回库存，也不能直接生成完成建筑。
