# 让神力自由施放但按明确目标提交

首版保留现有神力主题，但所有效果按新内核重新定义，并把旧“和平/战争”拆成两个工具，形成十七项神力。神力不消耗法力、资源，不设置通用冷却、次数或解锁；自由沙盒的误触与性能风险由清晰预览、取消、有限画笔档位和确定性输入预算处理，不能通过隐藏丢弃或设备相关结果解决。

地形与生态、单点灾害、生命状态和外交分别使用连续画笔、点目标、单位/区域目标和双对象目标。预览只解释范围与合法性；模拟变化、历史、音效和视觉必须来自同一次权威施放提交，连续拖动按世界距离采样并保持提交顺序。

“挑起战争”只在选中的两个王国之间创建玩家强制战争，绕过自主政治计划但不绕过军队、补给、路线、占领与停战；“缔结和平”只结束选中的真实战争。旧的全世界关系切换废弃，关闭外交与战争法则时禁止挑起战争但仍允许结束战争。
