# 保留被征服聚落的真实对象与因果

聚落占领完成时解散其原军队并取消敌对命令，但不删除幸存者或重置人物。原士兵保留家庭、伤势、经历和个人装备，退出原军事职责且不能立即加入征服方；聚落外的旧国军队仍属旧国并按真实路线撤退。这样既延续 WorldBox 可观察的“被占城市军队解散”，又避免用阵营改色复制或清空居民事实。

新征服聚落保留近期征服经历：它带来可解释的忠诚压力，同时提供有限稳定保护，避免刚占领便循环叛乱。安全、食物、住房、王国内供应、治理和时间推动恢复，长期失管仍能在保护结束后形成叛乱。居民、建筑、库存、现场资源、损伤、生产设施与历史保持原对象；普通任务重新验证，旧军事和政治任务取消，不自动掠夺、治疗、补货或传送资源。

多盟国共同进攻时，战役目标在出征前确定唯一主张方。发起战争的主战王国与目标真实接壤且具备治理路线时优先，否则从接壤、可补给且可治理的参战盟国中预先选择；最后一击、现场人数或偶然队长位置不能改变归属。主张方失效只能在安全检查点重建目标，不能在占领提交时暗改结果。

占领完成、军队解散、近期征服、任务重新验证和最终换旗必须作为同一原子结果对外投影。居民、聚落与世界层分别显示个人服役连续性、忠诚/库存/任务事实和领土归属，避免模拟、检查器与地图出现不同版本的征服结果。
