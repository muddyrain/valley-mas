# 从真实队伍与聚落事实提交殖民、叛乱和联盟

殖民队由母聚落的真实居民组成，目标约六名合格成年人并尽量保持伴侣与未成年子女完整；母聚落在派出后仍必须维持生存、家庭、生产与防御。队伍从聚落库存领取真实口粮，武器和护甲继续归携带者；斧、镐和锤仍是任务阶段派生的职业工具，不为殖民新增隐藏工具库存。

殖民者抵达后只建立临时殖民营。至少一名合格成年人仍在、地点保持合法，且首个营火和基础储存锚点真实可用时，才在一个检查点创建新聚落、提交成员归属、最小领土种子和已经卸载的库存。此前失败必须返航、重新选址或按幸存者的独立建村条件重新判断，不能提前生成正式村庄。

叛乱完成时，发起聚落成为新王国首都，发起领袖成为首任国王；直接相邻、同样低忠诚且具备领袖与自保能力的聚落可以同时加入。居民、建筑、库存和领土通过聚落归属进入新王国，不复制或重置资产；新旧王国立即形成叛乱战争。

联盟是至少两个王国组成的独立政治共同体，通过政治计划建立、加入、退出和解散。首轮共同防御外部侵略，但进攻战争与叛乱必须由每个成员依据好感、共同威胁、战备和自身生存状态单独决定是否参战，避免局部冲突无条件拖入所有盟国。
