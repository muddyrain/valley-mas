# 以单一运行时垂直替换，并发布可恢复观察

重构不建设并行 V2，也不一次删除全部玩法后长期失去可执行世界。新状态、命令、固定 Tick 与场景骨架先落地，随后按单聚落垂直链逐领域接管；每个领域接管时删除对应旧状态、执行链、协议和错误测试，任何时刻只有一套权威模拟。

每个 `20 Hz` Tick 按命令、环境与身体、感知、低频规划、意图与预留、行动与战斗、结果提交、清理与历史、观察发布的固定阶段推进。领域只能在自己的阶段写入拥有的事实，跨领域变化通过类型化命令和结果提交；结构化历史用于解释结果，但世界以严格快照而非完整事件重放恢复。

Worker 向 Pixi 发布可转移动态帧、脏区与定期关键帧，向 React 低频发布摘要和按需检查结果。主线程可以合并过期视觉帧，不能丢命令结果与历史；序号或校验异常时用关键帧恢复。IndexedDB 将手动、自动、安全和观察数据分开，先写校验过的临时快照再原子切换清单，配额清理永不静默删除手动槽。

第一条单聚落切片必须同时通过行为、可读性、确定性和 Web 性能门禁，才允许继续王国与战争。当前决定只授权形成实施计划；运行时代码仍需独立授权后修改。
