# Reset Eon Vale to a map-first pixel sandbox

Eon Vale will replace its pre-release living-world product with an original browser pixel map sandbox. The first release is a deterministic `1024 × 1024` world map with multi-scale terrain, biome, coast, tree, and rock expression; residents, buildings, civilization, simulation, old worlds, and compatibility are excluded so the new map can have one coherent data and visual foundation.

## Considered options

- Incrementally clean the living-world implementation: rejected because residents, settlements, houses, and simulation determine both its data model and its visual clutter.
- Preserve old worlds or saves: rejected because incompatible state would constrain the new map foundation without benefiting the map-first release.
