# 将核心身体需求建模为分阶段事实

首轮权威身体状态只有健康、营养和精力。危险从当前可感知威胁派生；住所、家庭职责和生活满意度作为行为资格与优先级上下文，不建立持续下降的独立需求条。

营养和精力连续变化，但只在跨越带迟滞的阶段边界时触发重新决策。营养依次表现为健康、饥饿、挨饿和持续损害健康；精力依次表现为正常、疲劳和极度疲劳。旧内核的具体阈值不迁移，进入线、退出线、衰减和恢复速度由新内核短场景重新校准。

食物必须经过生产与交付进入聚落库存。居民预留一餐并前往可达取餐端点；领取使库存转为真实携带餐食，进食才增加营养。普通饥饿可以携回住宅，挨饿阶段允许在取餐点附近进食。任务失败必须释放预留或保留真实携带事实，不能复制、瞬移或提前消费食物。

居民优先在所属住宅的真实床位睡眠；无房、损毁、满员或不可达时，在安全聚落中心、营火或空地低效休息。极度疲劳在安全检查点暂停普通工作，危险立即唤醒居民。
