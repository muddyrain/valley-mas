# 让平民和聚落从真实缺口中恢复

首轮不创建战争专属难民或全村自动迁徙系统。普通平民只在当前聚落内远离真实战团并寻找安全位置，家庭成员在不穿越危险时优先靠拢；占领后仍在村内的居民随聚落转属。家庭和亲属关系跨国保留，但不产生双重国籍、瞬移或尚未决定的跨国迁居流程。

被占聚落在即时战斗结束后从当前真实成年居民中重新评估领袖，原领袖只有满足新归属、存活和治理资格才可再次当选；没有合格人选时允许无领袖并承受真实治理缺口。战后恢复依次处理持续危险、食物与休息、住房与储存、关键生产与防御、本地守备、仍有效的旧工程和新扩张，每一步都使用真实劳动、库存、携带与时间。

战争、征服与伤亡历史永久保存，但当前影响分层衰减：居民的避险和休息较短，聚落的近期征服、忠诚与治理恢复居中，王国间战争积怨较长。重复事件可以在有上限的范围内刷新或累积，同一事件来源同时驱动人物、聚落、王国和关系 UI，避免永久仇恨、即时遗忘或隐藏情绪黑箱。
