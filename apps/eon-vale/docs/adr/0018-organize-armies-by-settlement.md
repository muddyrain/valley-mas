# 由聚落组织军队并保留本土守备

每个满足条件的聚落最多组织一支持续军队，成员来自本村真实居民并由一名队长带领。王国形成战略目标，聚落领袖依据本地战备和风险决定是否参与及选择目标；多支聚落军队可以协同，但不合并所有权、成员或库存。这个边界保留聚落自治，也避免一个王国级调度器直接覆盖所有居民行为。

只有健康成年人完成真实训练并持有真实武器后才计入士兵，护甲缺失会降低战斗结果但不阻止入伍。兵力容量从成年人口、食物安全储备、训练设施、可用装备、生产劳动力和家庭延续需求派生；士兵职责可以退出，但训练、经历、伤势和实际装备不会因职责变化消失或瞬移回库存。

主动出征前，士兵必须真实前往集结点。队长、目标、路线、武器与口粮有效，且到达人数达到计划远征兵力约八成后才开始行军；本土紧急防御可以用当前战力立即响应。队长死亡后从合格成员中接任，没有接任者则取消远征、返乡或就地防御。

每个聚落依据人口、威胁、城防与战略重要性保留动态本土守备，只有超出底线的力量远征；军队外出期间的新兵留守。殖民护卫在新村提交后，只有母城与新村都满足各自防御底线时才能转属，否则真实返航。居民、聚落和世界三层观察分别显示装备与队形、集结与守备、军队归属与路线，缩放不能合并不同聚落军队或提前统计未到场士兵。
