# 资源真实运输，装备表现读取所有权

首条单聚落切片只使用食物、木材、石料和一种普通金属；武器与护甲是独立物品。高级矿物、金币、奢侈品和多级材料后置。

聚落维护一份权威资源库存，营火、基础储存点和仓库只提供真实取放端点与分类容量。采集与生产产物先成为居民携带物或现场资源，只有送达有效端点后才进入库存；携带者死亡、任务中断、端点失效或容量下降不能复制、瞬移或静默删除资源。

首轮斧头、镐和锤子由当前任务阶段派生，只在实际工作动作中显示，不进入装备栏或提供隐藏属性。武器与护甲由工作站消耗材料制作，成品进入聚落物品库存，再由满足训练、岗位和资格的居民领取并形成真实所有权。

居民基础模型不包含武器。只有实际装备存在且当前处于警戒、战斗或明确持武动作时才显示武器；护甲外观、检查器与战斗数值读取同一装备事实。手持表现只能从当前武器、职业工具、携带资源或空手中选择一个，不根据职业补画。
