# 限制战争目标并保持居民生存规则

首轮自主进攻战争只有征服战争。持续低好感、真实边界或扩张冲突、缺少安全发展空间、有效国王、稳定聚落、可出征军队、真实口粮和陆路可达敌方聚落必须同时支持战争计划；强国不能仅因对方较弱随机开战。防御、叛乱、联盟防御和玩家神力战争由各自明确事实产生，首轮不引入灭族、掠夺、宗教或文化战争。

士兵优先攻击敌方士兵、队长和仍在阻挡当前军事目标的防御设施。普通平民不是主动攻击目标，民用建筑也不因战争自动可被破坏；只有直接攻击军队的平民才作为当前威胁自卫处理，脱离威胁后停止追击。

指挥失效、可战兵力过低、伤员与疲劳过多、口粮进入返程储备、队形长期失散、目标或路线失效、敌方明显占优都会驱动军事撤退。军队可以在安全位置建立战地营地休息、处理伤员和重新集结，但营地不生成领土、食物、治疗或装备。

士兵继续使用居民领域的营养、精力、健康、伤势、装备耐久、家庭与死亡事实；补给只来自真实携带、运输或合法友方端点。王国 UI 必须显示双边好感、趋势、主要原因、关系状态、政治计划和稳定窗口，地图关系层仅在选择或主动开启时投影这些事实，避免后台黑箱与常驻连线噪声。
