# 使用离散范围、有限叠加并在暂停时冻结演化

连续环境与区域生命神力只使用小、中、大、特大四档圆形世界范围，各神力可以限制最大档；雷击、龙卷风、陨石和地震保持固定物理范围。祝福、繁盛、狂暴和诅咒重复命中只刷新时长，祝福与诅咒互相替代；治愈可重复恢复至上限，瘟疫不重复感染，环境事实受上限约束，重复灾害保持独立事件。

首版不增加万能灾害清除。火焰由燃料、衰减、降雨或冰霜结束，冰霜随时间和升温解冻，龙卷风按寿命或世界边界消散；灾害结束不回滚死亡、损坏、地形与历史。

暂停仍允许选择、预览和提交神力；即时结果立即生效，所有依赖世界时间的传播、移动、周期伤害、状态倒计时、成长和环境衰减保持冻结，恢复后从同一权威事实继续。旧统一冷却、固定半径和主线程预演成功路径不迁入新内核。
