# 居民按分层优先级拉取任务机会

居民先过滤不可行意图，再按“致命危险、紧急生存、家庭与安全职责、聚落任务、自主生活”分层，只在当前最高可行层内按紧迫度、距离、技能、风险和任务等待时间评分。稳定 ID 负责确定性平局，承诺窗口与切换冷却抑制反复换工。

居民只在空闲、完成、失败、危险出现或生存阈值跨越等决策点，从空间与资格索引低频拉取任务机会；中央调度器不得每 Tick 扫描所有居民并强制派工。机会必须声明目标、容量、资格、紧迫度、预期产出和过期时间；接受时创建带版本任务和有期限预留，过期的机会、目标或路径结果不能修改世界事实。

工作角色是随聚落需求改变的当前劳动分工，技能和经验是居民持久事实。守卫必须占用真实岗位容量并具有训练和装备，不能通过切换职业枚举凭空获得武器或战斗能力。

任务采用分级中断。致命危险可以立即中断移动或工作；紧急生存在最近的安全检查点暂停；普通优先级变化等待当前阶段、承诺窗口或任务完成。已经开始修改库存、伤害、建造进度等权威事实的原子结果必须完整提交。暂停任务只有在机会、目标版本和预留仍有效时恢复，否则按明确原因取消。

失败按原因处理：目标消失时释放预留并重选；不可达时使旧路径失效、冷却该目标并寻找替代；资源不足时更新需求并退避；系统异常进入可诊断受阻。每类可恢复失败使用有限重试和独立退避，不允许永久随机重试。

没有紧急需求和合格机会时，居民可以进入有期限的自主生活，包括回家、休息、社交、娱乐或聚落附近短距离活动；到达决策期限或出现更高层事件后重新选择。合法空闲不属于受阻，也不能覆盖生存、危险或已承诺职责。

首轮自主生活限定为回家休息、聚落内短途散步、交谈、发笑、歌唱和儿童玩耍，不建立娱乐建筑、消费或专门职业。生活满意度由安全、住所、真实社交和近期经历派生，首轮只影响自主生活候选与诊断。社交必须有真实可达的空闲对象；邀请失败立即回退单人活动。检查器展示具体活动和对象，地图只做短暂表达，聚落统一汇总为自主生活。
