# 优先显示重要观察，并分离通知与历史

名称与图标不按对象遍历顺序争抢屏幕，而按选中、收藏、危险、政治军事与普通对象的稳定优先级避让。生命跟随采用允许临时脱离的软相机；目标死亡后停在死亡地点，由玩家显式决定查看击杀者、亲属或原位置，避免镜头自动跳到陌生对象。

普通动作只生成即时反馈，持续异常形成可清理且按来源聚合的近期通知，重要世界结果写入持久结构化历史。清除通知不删除历史，大量死亡必须引用同一战斗、灾害、饥荒或疾病事件并保留实际成员与最后位置。

地图最多启用一个连续填色层，并可组合军队、战争、灾害、收藏等稀疏标记。相机与覆盖作为每个本地世界的旁路观察元数据，新世界仍以全世界、无选择、无覆盖开始。键鼠和触控明确区分观察与工具输入；标签、热点、通知和历史统一压入相机位置、定位事实并打开右侧检查器，只有显式返回才恢复旧相机。
