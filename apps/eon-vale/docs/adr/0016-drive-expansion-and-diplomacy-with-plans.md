# 用事实与政治计划驱动扩张、叛乱和外交

殖民不能由固定计时器或单一人口阈值直接生成新村。王国只有在存在持续发展压力，同时具有真实食物余量、合格成年人、有效统治者和合法可达候选地时才形成殖民计划；饥荒、战争、严重威胁、人口过低或已有弱小聚落需要支援时暂停扩张。候选地必须在真实可达范围内，并按建设空间、生存资源、距离、危险与领土冲突比较；抵达前不产生聚落或领土。

聚落忠诚从王国治理容量、首都可达性、供应与军事支援、近期征服或换王、战争疲劳等事实派生，并使用迟滞保持稳定。只有持续低忠诚、拥有合格领袖和基本自保能力的非首都聚落，才能形成可观察且可取消的叛乱计划，避免随机翻旗和无法生存的空壳叛乱。

王国关系只保存和平、联盟、战争和休战四种明确事实。双边好感由边界冲突、战争历史、相对威胁、共同敌人和真实互助经历派生，用于解释政治计划机会，但不能直接替代关系状态。联盟、宣战、议和与叛乱必须经过政治计划准备，再由计划完成、战争结果、神力或世界法则在一个检查点提交，并遵守冷却或最低持续窗口。

首轮不引入氏族、文化、宗教、声望或 WorldBox 的精确城市上限与 plot 数值；这些系统不能作为当前殖民、忠诚或外交成立的隐藏前置。
