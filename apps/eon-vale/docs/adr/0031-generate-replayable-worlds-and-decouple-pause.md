# 生成可复现世界，并把暂停与倍率解耦

新世界只暴露少量可理解参数，地图事实把海拔与地表生境分开；非空白预设必须在同一种子下验证并最小修复足量的可定居区域。这样种子仍然精确复现，基础生态可以关闭，空白海洋保持真正空白，文明则始终由玩家投放生命后自主产生，而不是由生成器预先安排。

新世界默认暂停和全世界观察，但时间倍率是跨世界保留的浏览器偏好，不是暂停的别名。暂停只冻结世界时间，恢复时继续使用玩家原先选择的倍率；保存只持久化世界是否暂停，不用世界存档覆盖浏览器倍率。

首轮不提供局部或因果撤销。高风险手势必须预览并在连续手势开始时确认，随后于确定性边界创建限流的完整世界安全快照；快照失败则拒绝提交。恢复安全快照意味着整个世界回到该边界，不能只复原被编辑对象，否则已经发生的逃生、死亡、损坏、关系和历史会出现第二份真相。
