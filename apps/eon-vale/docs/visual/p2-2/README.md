# P2-2 干燥生境验收记录

> 当前状态：P2-2 地表已通过用户检查，装饰物件精修已实现并停在用户 Web 视觉验收点；不是最终正式美术。

## 固定验收场景

- 模板：`continent`
- 种子：`8`
- 稀树草原与干旱海岸：chunk `126`，左上角 `(896,448)`
- 沙漠与草原过渡：chunk `141`，左上角 `(832,512)`
- 运行时目录：`p2-dry-2`
- atlas 路径：`public/map/p2-2/`

固定镜头由 `P22AcceptanceScene` 提供。生成 seed `8` 的主大陆后，可使用开发调试栏的“草原 / 沙漠”按钮切换；镜头只定位已有事实，不修改生成结果。

## 本批资产

- 裸土与沙地分别提供 `4 base + 4 group + 3 overlay`；base 不承担均匀噪点，低频场和材质组承担大尺度节奏。
- 3 类稀树草原树与 1 类罕见沙漠树保留年龄/高度组合，共 32 个树木候选。
- 旱草、高草、荆棘灌木、仙人掌、小石、岩簇、树桩、枯树与岸边残骸按适用生境提供每族至少 3 个候选。
- 旱草、高草、灌木、仙人掌、小石、岩簇、树桩和枯树的 3 个候选均为真实剪影差异；atlas 构建会裁切并比较 alpha mask，换色、平移或只改噪点不能通过门禁。
- 物件共享现有树木的顶左受光、底右暗部、落地暗像素与受控色阶。仙人掌使用柱状、桶状簇生、掌片状三类轮廓；其余类别使用分叉、偏心、宽窄、高矮与姿态差异建立辨识。
- 稀树草原与沙漠继续遵守“稀疏”密度语言，不用增加统一装饰数量区分生境。
