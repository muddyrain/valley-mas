# P1 温带海岸视觉切片

状态：P1-1 已于固定 Web 场景复验通过；P1-2 结构切片已实现并通过自动门禁，等待用户视觉验收。

## 固定验收场景

- 世界模板：`continent`
- Seed：`0x1a2b3c4d`
- Chunk：索引 `162`，左上角世界格 `(128, 640)`
- 必须同时出现：浅水、岸缘、草原、林地，以及不少于 `30` 个树木/覆盖物对象。
- 浏览器验收图：世界、区域、近景、近景拖动和四种 debug 视图统一输出到 `output/p1-acceptance/browser-smoke/`。

## 首批运行时资产

- P1-1 运行时目录：`p1-temperate-coast-4`；当前 P1-2 运行时目录：`p1-structure-1`。

- `vegetated_soil`：`16` 个基础 tile、`12` 个材质组和 `12` 个低对比叠层插槽；草原与林地拥有独立候选池和材质节奏，非温带插槽继续保持 P0 合同占位。
- `16×16px` 材质组使用多团椭圆融合形成的圆润像素斑块；边缘保持像素阶梯、局部缺口与不同长宽比，禁止模糊、抗锯齿和规则圆点平铺。
- v4 降噪门禁：无树地表截图的高频边缘占比不得超过 `5%`；水体与沙岸基础帧保持安静，纹理由稀疏结构水纹承担；温带材质组不描边且只覆盖约 `18%` 的候选组。
- 水岸：深海、外海、浅水和岸缘四类，共 `11` 个静态/动画帧。
- 温带树木：草原 `2` 套、林地 `4` 套树木原型；每套覆盖幼树、成熟树、老树及允许的紧凑/标准/高干组合，共 `48` 个 P1 sprite。
- 常见陪衬：草簇、花、苔藓、蕨、蘑菇、高草、灌木、小石、海岸碎屑、岩簇、树桩和枯树的首批可读轮廓。
- 水面程序效果：不再逐格绘制整行高光；改为按地貌控制频率、由稳定种子选择位置的短水纹。
- 内陆生境边缘由 renderer 使用两侧地表角色生成低对比色，不再把 coast 的暖沙色作为通用描边。完整中性桥接带仍留给 P1-2。
- 草原/林地地表现在按三层验收：`19/46` 格量化明暗场、透明不规则 `16×16px` 材质色面、低频 `4×4px` 环境 overlay。枯草、裸土与林下落叶只形成少量橄榄色簇，不允许回退为均匀棕点。
- coast 从相邻权威 landform 派生湿沙、主体沙与内侧沙丘三种视觉带；视觉侵入不修改 landform 或生成 checksum。
- 调试栏的“地表”模式会隐藏全部物件层，固定截图为 `output/p1-acceptance/browser-smoke/debug-ground.png`。

## 性能整改门禁

- 冷启动世界→区域的可见 9 chunk 必须整体原子出现，不允许局部矩形切片。
- 可见细化必须 `≤150ms`，P95 帧时必须 `≤25ms`。
- 固定场景最终浏览器记录为约 `59.3ms` 和 `15.8ms`；原始测量保存在 `output/p1-acceptance/browser-smoke/cold-transition-performance.json`。

## P1-2 固定结构镜头

## 原创边界

用户提供的 WorldBox 截图只用于判断地图尺度、四层海岸节奏、树木间隙和俯视地面/直立物件关系。不得复制截图中的 palette、树形、地形轮廓、UI 或任何具体 sprite。

[`temperate-coast-direction-v1.png`](./temperate-coast-direction-v1.png) 是使用内置图像生成工具制作的原创内部方向板，不作为运行时 atlas。运行时 PNG 由项目自己的确定性像素资产脚本生成，并继续服从 visual manifest、二值 alpha、最近邻和可整体替换契约。
