# Eon Vale 地图视觉系统

> 状态：地图视觉规则与最终美术资产体系均已确认；P0、P1-1、P1-2、P2-1 与 P2-2 已通过复验。P2-3 寒冷生境已实现并等待 Web 视觉验收；专用世界远景美术与最终正式美术仍未完成。

## 目标

建立一套可缩放、可复现且原创的像素地图视觉语言。区域视图是主要验收距离；世界视图必须保住大陆、生境与海岸轮廓，近景必须保住地表材质、独立物件轮廓和局部构图。

## 已确认的视觉语言

- 借用 WorldBox 的视觉语法，而不复制其颜色、轮廓、素材或界面。
- 地表保持方格像素和块状生境；海岸由可辨认的水陆层次组成；植被按局部簇分布。
- 地表采用正俯视投影；地图物件使用底部锚定的直立轮廓和统一左上方受光。
- 地表颜色与纹理承担约 `60%–70%` 的生境识别，植被、岩石和地表覆盖物补足剩余差异。
- 森林不是连续树冠。树木即使组成簇，也必须逐株可辨并保留明显间隙、林间空地和可放置其他地图资源的位置。
- 首套内容以自然生境为基础；腐化、魔法侵染等幻想内容以后作为环境主题叠加，不能抹去基础地理。
- 普通地图物件由一个世界格锚定，但轮廓可以跨格；大型环境地标拥有独立的多格占地，不要求塞进单个地表图块。
- 三档观察共享相同的地图事实与位置：世界视图将植被压缩成林团色块和少量像素点，区域视图使用清晰但简化的独立物件，近景使用完整轮廓。
- 当前树木、灌木、岩石和矿簇素材不构成质量基线；它们与遗迹、巨树、洞口、陨石坑等大型环境地标一起重新建立原创资源目录。

### 最终像素美术方向

正式方向定义为“高可读性的手工像素生态地图”：

- 区域视图优先；世界视图先读色块与轮廓，近景再读像素细节。
- 使用干净、成簇的像素形状，不使用抗锯齿、半透明描边或高频抖色。
- 不使用整圈黑描边，以共享暗部、统一左上受光和落地阴影建立层次。
- 主体颜色自然克制，高饱和颜色只承担少量生态焦点。
- 参考 WorldBox 的信息密度与构图语法，不模仿具体造型、配色、素材或界面。

## 地理视觉分层

| 层 | 负责表达 | 示例 | 不负责表达 |
| --- | --- | --- | --- |
| 地貌带 | 水陆关系与高程 | 深海、外海、浅水、岸缘、低地、高地 | 气候、树木数量、幻想侵染 |
| 基础生境 | 气候与自然生态 | 温带、热带、干旱、寒冷、湿地 | 海拔、海岸位置、魔法效果 |
| 环境主题 | 叠加的幻想环境 | 腐化、魔法侵染 | 替换下层地貌或自然生境 |

三层共同决定最终地表和资源目录。例如同一套规则可以表达沙漠高地、极地岸缘或被腐化的温带低地，而不需要为每种组合发明一个互斥 biome。

## 首套自然地理目录

### 地貌带

| 顺序 | 地貌带 | 主要视觉职责 |
| ---: | --- | --- |
| 1 | 深海 | 最低频、最深色的大洋主体与世界外缘 |
| 2 | 外海 | 连接深海与沿岸水体的中层海水 |
| 3 | 浅水 | 显示近岸海床色、浅水纹理和浪花关系 |
| 4 | 岸缘 | 水陆接触处的陆地材质与轮廓过渡 |
| 5 | 低地 | 大多数开放陆地与生境主体 |
| 6 | 高地 | 抬升地表、岩地与山地前缘 |
| 7 | 山地 | 最高地貌、连续山脊与大型岩体 |

岸缘不是“统一沙滩”的同义词；它可以依据基础生境和局部地貌表现为沙岸、石岸、湿地岸或冰岸。

### 水系

- 海洋、湖泊和河流全部进入首套视觉系统。
- 水系负责连通关系；地貌带负责把具体水域位置表现为深海、外海、浅水或岸缘。
- 河流必须具有连续宽度、清晰河岸和入海口，不能表现成覆盖在陆地上的蓝色装饰线。

### 水面动态

- 世界视图保持静态，只呈现深海、外海、浅水色块、水体轮廓和主要水系。
- 区域与近景使用稀疏的 `1–2` 原生像素高光、波纹和岸边浪花动画。
- 深海主体保持低频平静；不得用全屏滚动纹理或高频白色波浪抢夺陆地注意力。
- 水面采用“静态 tile 打底 + 美术动画叠层 + 受限程序效果”：tile 负责固有色、深度边界、海床和 bitmask 轮廓；美术帧负责浪花、岸浪与可识别涟漪；程序负责确定性选择、相位错开、稀疏生成和低频色阶循环。
- 水 shader 只允许按原生像素网格产生轻微明度或色阶变化，不得平滑扭曲、模糊或产生亚像素波浪。

### 水体与岸缘素材预算

| 层级 | 静态素材下限 | 动画素材下限 | 视觉特征 |
| --- | --- | --- | --- |
| 深海 | `8` 个基础变体、`6` 个材质组 | 不制作独立帧动画 | 最暗、最低频，只接受程序低频色阶变化 |
| 外海 | `12` 个基础变体、`8` 个材质组 | `3` 组高光序列 | 中层水色、稀疏长纹理与缓慢亮点 |
| 浅水 | `16` 个基础变体、`12` 个材质组、`8` 个海床叠层 | `4` 组涟漪序列 | 最亮、可见海床、局部波纹丰富 |
| 每种岸型 | `12` 个基础变体、`10` 个材质组、`8` 个岸缘细节 | `3` 组浪花序列 | 沙岸、石岸、湿地岸与冰岸分别原创 |

- 外海通常在深海与浅水之间形成约 `12–32` 世界格的宽缓层；浅水保持 `4–8` 格，岸缘保持 `2–4` 格。
- 海湾、群岛和小湖可以按水体尺度压缩层宽，但层级顺序不能颠倒。
- 深海不通过增加高频素材制造丰富度；浅水和岸缘最接近玩家，因此获得更高静态与动画素材预算。

### 湖泊

- 湖岸复用海岸的分层语法，但缩窄为 `2–4` 世界格浅水和 `1–3` 世界格岸缘。
- 普通湖泊只使用浅水；较大湖泊可以加入外海核心，只有极大深湖允许深海核心。小湖由浅水和岸缘组成，避免被完整海岸带吞没。

### 河流

| 河流等级 | 宽度 |
| --- | ---: |
| 支流 | `1–2` 世界格 |
| 普通河流 | `2–4` 世界格 |
| 主河道 | `4–6` 世界格 |
| 入海口 | 最宽可达 `6–8` 世界格 |

- 河岸只使用约 `1` 世界格的材质过渡，不套用完整海岸的浅水与岸缘宽度。
- 河道宽度按等级和汇流关系变化，不逐段无规则抖动。

## 海岸系统

### 分层顺序与宽度

普通海岸从水向陆依次为：

1. 深海；
2. 外海；
3. `4–8` 世界格宽的浅水；
4. 水陆接触处的浪线；
5. `2–4` 世界格宽的岸缘；
6. 低地、高地或山地。

浅水和岸缘宽度可以沿海岸缓慢变化，但不能逐格随机跳变。区域视图中，岸缘约占 `8–16` 屏幕像素，浅水约占 `16–32` 屏幕像素；近景提供足够空间容纳浪花和岸缘覆盖物。

### 岸型

| 岸型 | 主要来源 | 视觉方向 |
| --- | --- | --- |
| 沙岸 | 温带草原、热带雨林、稀树草原、沙漠 | 明亮砂色、稀疏贝壳与漂流物 |
| 石岸 | 高地、山地及部分温带林地 | 灰褐碎石、裸岩与较硬边缘 |
| 湿地岸 | 湿地 | 泥色软岸、芦苇和不连续浅水斑块 |
| 冰岸 | 苔原、极地 | 冷色雪冰、深色裸岩和碎冰 |

岸型是岸缘材质类别，不是新的基础生境。

### 轮廓纪律

- 保留方格像素与阶梯状轮廓，不使用平滑曲线或抗锯齿。
- 移除没有构图价值的单格尖刺、单格凹洞和连续锯齿。
- 内角、外角、短湾和小半岛以约 `2–6` 世界格的尺度形成可读变化。
- 小岛可以保留更紧凑的轮廓，但仍需具备可辨认的岸缘与浅水层。

### 悬崖岸

- 悬崖岸只出现在约 `5%–10%` 的高地或山地海岸。
- 悬崖可以缩窄或中断普通岸缘，让高地直接接近水面；浅水和浪线不得消失。
- 悬崖是稀有构图焦点，不得沿所有高地海岸连续生成。

## 地形过渡

### 基础生境交错

- 两种基础生境通过约 `4–12` 世界格宽的块状交错带过渡。
- 交错带中的每个世界格仍归属于明确生境，不创建连续混色或语义不明的第三种生境。
- 双方的地表图块、覆盖物和少量植被可以互相穿插，但核心区资源不得越过整个交错带。
- 交错形状以材质组为主要节奏，避免逐格椒盐噪声或一条平直分界线。

#### 三步桥接

基础生境之间不制作两两专属的混合 tileset，而按三步形成视觉过渡：

1. 改变双方子材质的区域权重；
2. 使用双方共有或中性的地表材质族作为桥梁；
3. 逐步替换覆盖物、小型植被和树种组合。

- 草原到林地共享植被土壤，并逐渐增加湿土、落叶、蕨和树木。
- 草原到沙漠先出现裸土，再进入硬沙和松沙。
- 林地到苔原先降低树高与覆盖率，再混入裸土、地衣和雪。
- 湿地到草原先减少浅水与泥，再增加湿草并进入普通草地。

程序负责交错带归属、材质权重、bitmask 和确定性选择；美术负责材质边缘、桥接叠层和过渡资源。过渡中的每个世界格仍属于明确基础生境，不创建混合 biome。

### 高程抬升

- 低地到高地使用 `2–4` 世界格宽的破碎抬升带，由上缘高光、下缘暗部、裸地和零散岩石共同表达。
- 高地到山地使用 `3–6` 世界格宽的岩脊、碎石坡与局部阴影。
- 抬升边缘必须存在自然缺口和缓坡段，不能环绕整个区域形成整齐围墙。
- 高程变化不依赖平滑颜色渐变，也不能只靠地表换色表达。

### Autotile 与 bitmask

- 地貌和封闭地表边界使用八邻域、对角受正交约束的 `47` 种标准拓扑。
- 上下左右决定主体连接；只有相邻两个正交方向都连接时，对应对角连接才生效。
- 深海、外海、浅水、岸缘、高程边缘和封闭地表斑块共享拓扑语法。
- 每种拓扑至少提供 `3` 种确定性选择的不规则边缘节奏，避免同形边界机械重复。
- bitmask 只决定几何形状，不决定颜色、材质、生境或具体 atlas 坐标。
- 基础生境的 `4–12` 格交错带仍由区域级分布决定，不能压缩成单格渐变边线。
- 美术提供 `47` 种拓扑 × `3` 种不规则节奏，共 `141` 个可复用二值像素遮罩。遮罩只决定两种材质的覆盖关系。
- 各材质另行提供自己的边缘色阶、碎屑、高光、暗部和磨损叠层；程序依据语义、邻接关系与确定性变体种子组合遮罩和材质。
- 不为基础生境的每一种两两组合绘制完整的 `141` 张全彩图块。高程断面、悬崖和浪花仍使用独立美术，不能由普通平面遮罩冒充。

### 基础生境

| 基础生境 | 核心区分方向 |
| --- | --- |
| 温带草原 | 开放草地、低木本密度、清晰留白 |
| 温带林地 | 湿润地表、间隙型阔叶植被簇 |
| 热带雨林 | 深绿地表、宽叶植被与高覆盖物丰富度 |
| 稀树草原 | 暖色草地、分散树冠与灌木群 |
| 沙漠 | 裸露砂地、耐旱植被与岩石焦点 |
| 湿地 | 潮湿地表、浅水斑块、芦苇与软岸 |
| 苔原 | 低矮耐寒覆盖物、裸地与稀疏木本 |
| 极地 | 雪冰主导、极低植被与高对比岩体 |

### 首个环境主题

自然视觉系统完成后，只制作“腐化”作为首个叠加验证主题。它必须能跨越多种地貌带和基础生境，同时保留下层水陆、高程、岸缘和主要生态结构。

- 腐化区域使用 `6–16` 世界格宽的不规则侵染前缘。
- 腐化地表叠层最多覆盖局部约 `20%–35%` 的可见地表，并最多替换约 `15%–30%` 的植物与装饰轮廓。
- 腐化后至少保留 `60%` 的原基础生境色彩和材质关系。
- 腐化不得抹除岸线、水系、高程或主要植被密度结构，也不得使用覆盖整个区域的统一紫色、黑色或其他单色滤镜。
- 合格的腐化区域必须同时让观察者读出“这里受到腐化”以及“这里原本属于哪种基础生境”。

## 观察层级

| 层级 | 视觉职责 | 地图物件表达 |
| --- | --- | --- |
| 世界视图 | 完整世界轮廓、生境色块、海岸层次和总体植被分布 | 林团色块与少量像素点，不显示完整近景素材 |
| 区域视图 | 主要视觉验收距离；同时检查地表、过渡、留白和资源构图 | 清晰但简化的独立树木、岩石与地标 |
| 近景 | 检查像素轮廓、受光、锚点、遮挡和局部地表细节 | 完整原创物件帧 |

层级切换只改变表达精度，不改变对象是否存在、对象位置或植被簇的总体形状。

## 已确认的尺度契约

| 项目 | 规格 |
| --- | --- |
| 世界总量 | 固定 `1024 × 1024` 世界格 |
| 世界视图 | 按可用视口自动适配，目标约 `0.75–1` 屏幕像素/格 |
| 区域视图 | `4` 屏幕像素/格，作为视觉设计与验收基准 |
| 近景 | `16` 屏幕像素/格，即区域基准的四倍整数放大 |

世界总量与屏幕倍率分别锁定。以后若资源构图显得拥挤，先调整物件帧、锚点间距和分布规则，不通过增加逻辑世界边长掩盖问题。

### Logical cell 与美术网格

- 一个世界格固定对应 `4×4` 原生地表像素；所有正式素材绘制在 `1px` 原生像素网格上。
- tile 与 sprite 画布宽高原则上使用 `4px` 的整数倍。
- 普通 sprite 的底部中心锚点对齐整数世界格中心；可见轮廓允许跨越多个世界格。
- 素材画布、可见轮廓、逻辑占地和排斥区是四个独立属性，不能由其中一个机械推导其他三个。
- 区域视图使用原生 `1×`，近景使用 `4×` 最近邻；世界视图使用专用聚合表达，不直接缩小近景素材。

## 地表图块

- 一个世界格对应一个 `4 × 4` 原生像素基础图块；它在区域视图以 `1×` 显示，在近景以 `4×` 最近邻放大。
- 相邻 `4 × 4` 世界格形成一个 `16 × 16` 原生像素材质组。材质组负责大片明暗、纹理方向和斑块节奏，避免每格独立随机形成棋盘噪声。
- 基础图块仍承载逐格地理边界；材质组不能把不同地理事实烘焙成一张不可拆分的大图。

### 子材质与素材预算

每种基础生境拥有三套具有环境含义的子材质，不使用纯随机换皮。子材质由湿度、遮蔽、裸露程度、地表基质等条件驱动，例如：

- 温带草原：鲜草、深色湿草、浅色裸草地；
- 沙漠：松沙、硬沙、石砾地；
- 湿地：泥地、浅水、植被浮垫；
- 极地：积雪、蓝冰、裸岩雪地。

素材数量按“基础生境 × 地表材质族”形成的材质包计算，而不是给每种基础生境套用相同数量。同一材质族进入不同基础生境后可以共享拓扑模板，但必须拥有符合该生境的像素纹理和局部细节，不能只换颜色。

| 地表材质族 | `4×4px` 基础变体 | `16×16px` 材质组模板 | 静态地表叠层 |
| --- | ---: | ---: | ---: |
| 植被土壤 | `16` | `12` | `12` |
| 裸土 | `12` | `10` | `10` |
| 沙 | `12` | `10` | `10` |
| 泥 | `12` | `10` | `10` |
| 岩地 | `16` | `12` | `12` |
| 雪 | `12` | `10` | `10` |
| 冰 | `10` | `8` | `8` |
| 幻想叠层 | `12` 个小型遮罩 | `8` 个组级遮罩 | `12` 个主题细节 |

海岸、河岸、高程边缘、基础生境交错和水面动画素材单独计算，不占用材质包数量。

### 地表材质族

地表材质族与基础生境是两个维度：材质族描述地面由什么构成，基础生境描述该区域的气候和生态。首套材质族包括：

1. 植被土壤：草地与林下草本；
2. 裸土：干土、湿土、磨损或侵蚀地表；
3. 沙：海岸沙、荒漠松沙与硬沙；
4. 泥：湿地泥与河岸泥；
5. 岩地：石砾、裸岩与山地基质；
6. 雪：松雪、积雪与风蚀雪；
7. 冰：蓝冰、薄冰与碎冰；
8. 幻想叠层：腐化等环境主题附加层，不构成新的基础生境。

基础生境从材质族中选择并定制三套子材质。例如温带林地可以组合植被土壤、裸土和湿润落叶地，极地可以组合雪、冰和裸岩。`grass`、`sand`、`snow`、`dirt` 是材质概念，不再作为 biome 的同义词。

### 地表斑块

- 材质组之上增加特征跨度为 `24–80` 世界格的大尺度地表斑块，负责组织同一基础生境内的子材质比例。
- 生境核心通常由 `60%–75%` 主体子材质、`20%–35%` 次要子材质和 `5%–12%` 裸露或特殊子材质组成。
- 三种子材质以块状区域交错，并由环境条件决定位置；不得逐格随机混合。
- 基础图块提供像素级变化，材质组提供局部节奏，地表斑块提供区域级明暗和材质走势；三层不能互相替代。

### Terrain tileset 完整组成

正式 terrain tileset 必须同时包含：

1. `4×4px` 基础填充图块；
2. `16×16px` 材质组构图模板；
3. 用于 `24–80` 格地表斑块的材质权重配置；
4. `47` 种边界拓扑及三种不规则节奏；
5. 各材质自己的边缘高光、暗部、碎屑和磨损叠层；
6. 海岸、河岸、高程等结构专用素材；
7. 水面、浪花、流纹和环境主题动画叠层。

地表斑块权重属于组合规则，不是巨幅贴图。树木、灌木、花草和岩石 sprite 属于独立物件或覆盖物资产，不计入 terrain tileset。

## 地图资源尺寸族

| 类型 | 原生帧尺寸 | 典型内容 |
| --- | --- | --- |
| 微型覆盖物 | `4×4`、`8×8` | 草簇、花、落叶、碎石 |
| 小型物件 | `8×8`、`12×12`、`12×16` | 灌木、小岩石、矿物 |
| 树木 | `16×24`、`24×24`、`24×32`、`24×40`、`32×32`、`32×40`、`32×48` | 幼树、紧凑树、普通树、高干树 |
| 中型地标 | `32×32`、`48×48` | 岩簇、洞口、小遗迹 |

- 世界视图使用专用色点和林团图形；区域与近景共享原生物件帧，分别以 `1×` 和 `4×` 最近邻显示。
- 普通物件锚定到任意一个整数世界格，轮廓允许跨格；是否放置由环境条件、局部簇结构和物件排斥半径共同决定。
- 大型环境地标拥有明确的多格占地。视觉轮廓、占地区域和排斥区域是三个不同概念，不强迫它们等大。

| 资产类 | 包含内容 | 视觉与空间特征 |
| --- | --- | --- |

### 树木视觉年龄与形态

| 视觉年龄 | 原生尺寸族 | 生成比例 | 主要作用 |
| --- | --- | ---: | --- |
| 幼树 | `16×24` | `20%–25%` | 林缘、空地和新生感 |
| 成熟树 | `24×32` | `60%–70%` | 每个树种的主体形态 |
| 老树 / 高大树 | `32×40` | `10%–15%` | 稀疏重音和林团轮廓变化 |

- 视觉年龄只选择不同素材，不引入随时间成长的生态模拟。
- 同一树种必须在冠幅宽窄、树干弯直、枝叶偏心、顶部缺口和轻微风蚀程度上变化。
- 枯树、烧焦树和腐化树属于独立资产族，不是活树的调色版本。

高度形态独立于视觉年龄：

| 高度形态 | 典型画布 | 分布比例 | 视觉特点 |
| --- | --- | ---: | --- |
| 紧凑 / 宽冠 | `24×24`、`32×32` | `30%` | 树干短、冠幅宽 |
| 标准 | `24×32`、`32×40` | `50%` | 常规树干与树冠比例 |
| 高干 / 细长 | `24×40`、`32×48` | `20%` | 树干明显加长、冠幅较窄 |

- 幼树只使用紧凑和标准形态；成熟树和老树可以使用三档高度。
- 高度形态在生成时作为视觉标签选择，不代表树木动态长高。
- 最大普通树画布扩展到 `32×48`；更大的巨树属于环境地标。

### 生境树木原型

“树木原型”是一套共享冠形与树干语言的视觉树种，不要求对应真实植物学物种。首套生境专属原型下限为：

| 基础生境 | 树木原型数 |
| --- | ---: |
| 温带草原 | `2` |
| 温带林地 | `4` |
| 热带雨林 | `4` |
| 稀树草原 | `3` |
| 沙漠 | `1` 个稀有绿洲树；仙人掌不计入树木 |
| 湿地 | `3` |
| 苔原 | `2` |
| 极地 | `0` |

同一生境中，主树种合计约占 `60%–75%`，次要树种约占 `20%–30%`，稀有树种约占 `5%–10%`。共计 `19` 套树木原型，且树木不能跨生境直接换色复用。

每套树木原型至少拥有 `15` 个真实轮廓：

| 视觉年龄 | 真实轮廓数 | 高度形态分配 |
| --- | ---: | --- |
| 幼树 | `3` | 紧凑、标准 |
| 成熟树 | `8` | 紧凑 `2`、标准 `4`、高干 `2` |
| 老树 | `4` | 紧凑 `1`、标准 `2`、高干 `1` |

三档年龄、三档高度与冠形不做完整笛卡尔积。`19` 套原型合计至少 `285` 个活树真实轮廓，每个轮廓再使用 `2–3` 个人工校准 colorway；枯树、烧焦树和腐化树不计入这 `285` 个轮廓。

## 大型环境地标

### 密度与净空

- 每个 `64×64` 世界格区域允许出现 `0–2` 个中型地标。
- 大型地标平均每 `160–256` 世界格出现一个，并按环境适宜性不规则分布，不能形成固定网格。
- 中型地标周围保留 `4–8` 世界格的降密度区；大型地标周围保留 `8–16` 世界格的降密度区。
- 降密度区不要求完全清空，但必须减少树木、普通物件和高对比装饰，使地标通过周围留白获得视觉重量。
- 遗迹只作为无法归属具体文明的环境残迹，不引入建筑类型、文化归属、国家或历史模拟。

### 缩放表达

| 观察层级 | 地标表达 |
| --- | --- |
| 世界视图 | 大型地标保留 `1–4px` 专用轮廓或色点；中型地标只保留会影响区域色块的部分 |
| 区域视图 | 显示完整原生地标、占地关系和构图净空 |
| 近景 | 使用同一原生素材，以 `4×` 最近邻显示完整轮廓 |

地标的位置、朝向、占地和周围降密度区不随缩放改变。大型地标是跨观察层级的定位点；普通中型地标不必全部进入世界视图。

## 资源美术语言

- 轮廓紧凑但不规则；不使用整圈黑描边，也不使用高频抖色堆砌表面细节。
- 顶部与左侧受光，深色侧面和落地阴影把直立物件从正俯视地表中分离。
- 每个基础生境拥有约 `6–10` 个地表主色；普通物件通常限制为 `3–5` 个主要色阶，并共享全地图的光照与阴影色族。
- palette 使用“共享色彩角色 + 生境局部色盘”，不强制所有资产使用一张固定索引色盘。
- 全地图共享最暗部、落影、通用高光和中性岩石色族；水体共享深海—外海—浅水—浪花色阶。
- 普通小素材使用约 `3–5` 个主要色阶，大型素材可按轮廓需要适度增加；单个素材最多使用 `1–2` 个高饱和强调色。
- 环境主题可以增加自己的强调色，但不得整体滤镜染色。placeholder 必须保持正式体系的明度层级和色彩角色，即使其色盘更简化。
- 各类常用装饰使用下表规定的独立轮廓预算；调色变体只能建立在独立轮廓之上，不能冒充新的资源造型。

### Variant 计数纪律

独立 variant 必须至少具备一项区域视图可辨认的变化：外轮廓、主要像素簇结构、宽窄、高矮、偏心、缺口或姿态。以下内容不计入独立 variant 数量：

- 单纯换色；
- 自动水平镜像或旋转；
- 动画的不同帧；
- shader 相位；
- 只改变少量无关噪点。

程序不得自动镜像或旋转带方向光照的树木、岩石和直立物件。需要反向姿态时必须单独绘制并计为真实轮廓 variant。

### Decoration variant 下限

以下数量按“该类别在某个基础生境中实际使用”计算，不要求每个生境包含全部类别：

| 资产类别 | 最低真实轮廓 variant |
| --- | ---: |
| 草簇 | `8` |
| 花 | `6` |
| 苔藓、地衣 | `6` |
| 蕨与低矮叶片 | `6` |
| 蘑菇 | `5` |
| 芦苇、高草 | `6` |
| 灌木 | `8` |
| 仙人掌、多肉植物 | `6` |
| 小石 | `8` |
| 独立岩石、岩簇 | `6` |
| 矿物、晶体 | `5` |
| 枯枝、树桩 | `5` |
| 枯树 | `6` |
| 贝壳、漂流物等岸缘碎屑 | `6` |

### Colorway 规则

| 素材 | 每个真实轮廓允许的人工校准 colorway |
| --- | ---: |
| 常见树木、灌木、草簇 | `2–3` |
| 花与高饱和植物 | `3–4` |
| 岩石、枯枝、枯树 | `2` |
| 稀有焦点 | `1–2` |

- colorway 不计入真实轮廓 variant 数量，且必须来自所在生境的局部 palette。
- 程序只能选择美术预先定义的 colorway，不得任意进行 HSV 染色。
- 同一林团偏向共享一个主色趋势，但不能让整片森林完全同色。
- colorway 不代表季节，本阶段不加入季节系统。

### 重复感控制

素材选择使用由世界种子与位置驱动的“确定性洗牌袋 + 局部重复冷却”，不逐个实例独立随机：

- 同一材质组优先遍历当前材质包的基础 variant 后再重复。
- 相邻材质组不得同时使用相同构图模板与相同强调叠层组合。
- 同一树木真实轮廓在 `12–20` 世界格内不重复；同一“轮廓 + colorway”组合在 `20–32` 格内不重复。
- 草簇、花等低矮覆盖物在 `4–8` 格内避免重复；灌木和独立岩石在 `8–16` 格内避免重复。
- 稀有焦点继续保持 `32–64` 格间距。
- 重新打开相同种子地图时，variant、colorway 与动画相位保持一致。
- 不通过随机旋转、镜像或任意染色伪造变化。

### 动画预算

- 必须动画：外海与浅水的稀疏高光、岸边浪花、河流局部流纹、腐化主题中的少量活性焦点。
- 允许低频动画：芦苇、高草、大型花和少量宽叶植物；同屏只有部分实例进入动画，其余保持静止。
- 保持静态：基础地表、沙、雪、泥、岩地、普通树木、灌木、岩石、枯树，以及洞口、遗迹和陨石坑等环境地标。
- 水与浪花使用 `3–5` 帧、约 `3–6 fps`；植物摆动使用 `2–3` 帧、约 `1–2 fps`；腐化焦点使用 `3–4` 帧、约 `2–4 fps`。同类实例必须错开相位。

### 美术与程序职责边界

美术必须提供所有具有审美判断的可见像素形状：

- 基础 tile、材质组、地表叠层与材质边缘；
- 高程断面、悬崖、浪花和桥接细节；
- 树木、植被、岩石、地标的真实 variant 与 animation 关键帧；
- palette、明暗关系、shadow mask 和世界视图 LOD 小型符号。

程序只负责：

- 地图语义、材质权重和适宜性；
- bitmask、拓扑遮罩和图层组合；
- variant、colorway、动画相位的确定性选择；
- 密度、间距、避让、重复冷却与 LOD 切换；
- 水体低频色阶变化。

程序不得自动生成树冠、岩石或岸缘轮廓，不得任意 HSV 染色、模糊、抗锯齿、平滑变形，也不得用噪声像素或 shader 掩盖缺失素材。

### 物件阴影

- 树冠、树干和岩石自身明暗画入 sprite；落地阴影由美术为每个真实轮廓提供独立 shadow mask。
- 程序在物件后方绘制 shadow mask，只允许使用统一阴影色与透明度，不根据轮廓自动生成模糊投影。
- 低矮覆盖物通常不提供独立阴影；大型树木、岩石与环境地标必须提供。
- shadow mask 与主体使用相同画布、锚点和 variant ID，确保 placeholder 与正式素材可整体替换。

## 树冠间隙

- 超过 `90%` 的相邻树冠在区域视图必须保留 `1–4` 原生像素的可见缝隙。
- 最多约 `10%` 的相邻树冠可以因前后层次轻微叠压，但不得让三棵以上连接成连续树冠色块。
- 阴影可以相接；主要树冠轮廓必须保持逐株可辨。
- 间隙按不透明轮廓判断，不按素材画布边界或树干锚点距离判断。

## 植被参考结构

用户指定的 WorldBox 区域视图是首套植被密度的视觉标尺。需要复现的是其空间关系，而不是复制树木素材：

- 树木遍布适生区域，但密度以大尺度场缓慢变化，不使用逐格独立随机。
- 局部树木形成边界松散的不规则林团，同时留下口袋空地和连续可见的地面通道。
- 即使最密的林地，树冠之间仍以可见地面分隔，不形成封闭冠层。
- 生境核心使用稳定的主树种组合；靠近交错带时逐渐降低密度并混入相邻生境树种。
- 林团边界不形成圆形噪声斑或规则网格，空地也不表现成尺寸一致的洞。

### 树冠覆盖率

树冠覆盖率按区域视图中树冠不透明像素占适用陆地区域的比例计算。它约束的是生境核心的目标区间，不要求每个取样窗口得到相同数值；水体、大型环境地标及其排斥区不进入分母。

| 基础生境 | 树冠覆盖率 |
| --- | ---: |
| 温带草原 | `4%–10%` |
| 温带林地 | `18%–28%` |
| 热带雨林 | `22%–34%` |
| 稀树草原 | `8%–16%` |
| 沙漠 | `0%–3%` |
| 湿地 | `6%–14%` |
| 苔原 | `0%–5%` |
| 极地 | `0%–1%` |

覆盖率上限仍服从树冠间隙规则。热带雨林的高覆盖来自更多松散林团和林下覆盖物，不得用相连树冠制造封闭冠层。

### 三层空间结构

植被不是单一尺度的噪声场，而由三个彼此嵌套的空间层共同构图：

| 空间层 | 特征跨度 | 职责 |
| --- | ---: | --- |
| 宏观密度区 | `64–192` 世界格 | 让树木密度随地形与生境缓慢升降，形成世界和区域视图可读的林区走势 |
| 局部林团 | `12–40` 世界格 | 形成边界松散、形状不规则的树木组合，并在内部保留株间地面 |
| 空地与地面通道 | `6–24` 世界格 | 从林团中保留口袋空地和连续负空间，容纳地表阅读与其他地图资源 |

- 三层形状都必须保持块状、非规则，但不能退化为圆形噪声斑、等距网格或尺寸一致的孔洞。
- 宏观密度区决定“哪里总体更密”，局部林团决定“树木如何聚集”，空地与通道决定“哪里必须留白”；三者不能由同一个阈值切割结果冒充。
- 生境交错带可以同时改变宏观密度和树种构成，但不得在边界处突然截断林团。

## 地表覆盖物与装饰系统

### 生境密度档

地表覆盖物使用稀疏、普通、丰富三个相对密度档。密度档只约束数量级；每种基础生境仍必须通过自己的素材组合、轮廓和色彩关系建立识别，不能靠无限增加覆盖物数量区分。

| 密度档 | 基础生境 |
| --- | --- |
| 丰富 | 温带草原、热带雨林、湿地 |
| 普通 | 温带林地、稀树草原 |
| 稀疏 | 沙漠、苔原、极地 |

| 密度档 | 有覆盖物的材质组比例 | 每个有效材质组的锚点数 |
| --- | ---: | ---: |
| 稀疏 | `20%–35%` | `1` |
| 普通 | `40%–55%` | `1–2` |
| 丰富 | `55%–75%` | `2–4` |

- `8×8px` 覆盖物在一个材质组中最多出现一个，其余使用 `4×4px` 尺寸族。
- “有效材质组”指本轮分布中被选中承载独立覆盖物的材质组；未被选中的组仍可使用基础图块自身的低对比纹理。

### 生境资源方向

| 基础生境 | 主要视觉资源 |
| --- | --- |
| 温带草原 | 明亮草地、野花、低灌木、少量圆冠树 |
| 温带林地 | 湿润深绿地表、阔叶树、蕨、落叶、稀有枯木 |
| 热带雨林 | 深绿斑驳地表、宽叶植物、高大异形树、藤叶与大型花 |
| 稀树草原 | 暖色草地、分散伞冠树、高草簇、风化岩 |
| 沙漠 | 沙色斑块、风纹、耐旱灌木或多肉植物、裸岩 |
| 湿地 | 泥色地表、浅水斑块、芦苇、水生叶片、枯桩 |
| 苔原 | 灰绿裸地、苔藓地衣、矮灌木、极少量弯曲小树 |
| 极地 | 蓝白雪冰、冰裂、风积雪和高对比裸岩，几乎无植物 |

这些方向定义资源主语，不代表每个区域必须出现表中的全部内容，也不能退化成八套换色树木。

### 生境装饰素材下限

| 资源层 | 每种基础生境的首套下限 |
| --- | ---: |
| 环境覆盖物 | `12` 个轮廓：6 个低对比、4 个中等识别、2 个高饱和 |
| 小型地图物件 | `6` 个轮廓 |
| 稀有焦点 | `3` 个独立轮廓 |
| 地表叠层 | `12` 个，独立于上述装饰数量 |

因此，每种基础生境除地表叠层外至少拥有 `21` 个独立装饰轮廓。灌木、小岩石、枯枝、泥块等按其实际高度和遮挡关系归入环境覆盖物或小型地图物件，不能仅按题材名称归类。

### 跨生境复用

- 树木、主要植物和高饱和焦点必须为基础生境专属。
- 普通岩石、枯枝等中性物件最多允许约 `40%` 跨生境共享。
- 共享的中性物件仍需适应所在生境的色阶与周边资源组合，不能让同一张素材无差别遍布八种生境。
- 基础生境的核心识别必须由专属资源承担，不能依赖共享中性物件。

### 装饰层级

| 层级 | 职责 | 示例 |
| --- | --- | --- |
| 结构细节 | 强化已经存在的水陆、高程和材质边界，必须服从地理结构 | 浪花、河岸泥痕、碎石坡、冰裂 |
| 环境覆盖物 | 以低矮细节丰富地表，不改变地理语义 | 草簇、花、落叶、蕨、细碎石 |
| 稀有焦点 | 在局部形成可记忆的自然或幻想视觉重音 | 枯木、特殊岩簇、晶体、巨大花株 |

大型环境地标继续作为独立资源层管理，不与普通装饰共用密度预算。

### 色彩与留白预算

- 低对比环境覆盖物可以广泛出现；鲜花、晶体等高饱和装饰只允许出现在约 `5%–12%` 的材质组中。
- 至少 `25%` 的材质组只显示地表材质，不放置独立环境覆盖物或稀有焦点。
- 留白比例是区域构图约束，不禁止基础图块自身包含低对比纹理。
- 高饱和装饰负责建立少量节奏点，不得均匀撒遍地图，也不得成为基础生境的主要识别手段。

### 覆盖物斑块

- 普通覆盖物以跨 `2–6` 个材质组、约 `8–24` 世界格的松散斑块出现。
- 高饱和装饰只形成 `1–3` 个材质组的小簇，且继续服从 `5%–12%` 的总体出现率。
- 同类稀有焦点之间至少相隔 `32–64` 世界格。
- 覆盖物斑块边界必须不规则，但不得退化为逐格随机撒点、标准圆斑或等距重复。

### 避让顺序

- 结构细节依附其对应的岸线、河道或高程边缘；环境覆盖物与稀有焦点必须让位于这些地理结构。
- 环境覆盖物与稀有焦点还必须让位于树干、岩石、地图物件占地和大型环境地标占地。
- 低矮覆盖物可以进入树冠阴影，但树干周围至少保留 `1` 世界格的构图净空。
- 装饰不能堵塞已经保留的林间空地和地面通道，也不能遮断区域视图中的地理边界。

### 结构过渡几何

海岸、河岸、高程边缘和基础生境交错共享一套边界几何角色，但各自使用符合材质和环境含义的原创像素表达：

- 直边；
- 外角；
- 内角；
- 末端；
- 狭窄通道；
- 孤立小块。

每种几何角色至少提供 `3` 种不规则边缘节奏。不同方向必须按统一左上光重新处理高光、暗部和落影，不能机械旋转素材。共享的是拓扑语法，不是跨地貌复用同一张边缘贴图。

### 装饰缩放表达

| 观察层级 | 结构细节 | 环境覆盖物与焦点装饰 |
| --- | --- | --- |
| 世界视图 | 保留简化的海岸、高程与主要水系轮廓 | 聚合为少量纹理像素或色点，不显示独立小素材 |
| 区域视图 | 显示完整的区域级边缘节奏 | 显示独立 `4×4px`、`8×8px` 覆盖物和清晰焦点装饰 |
| 近景 | 沿用区域结构并以整数倍显示细节 | 沿用区域素材，以 `4×` 最近邻显示完整轮廓 |

缩放只改变表达精度，不重新随机生成装饰位置或改变覆盖物斑块的总体范围。

## 尺度词汇

| 名称 | 负责表达 | 不负责表达 |
| --- | --- | --- |
| 世界格 | 一个位置的高度、气候、生境等地理事实 | 屏幕像素大小、完整树木轮廓 |
| 地表图块 | 一种地面材质的像素纹理 | 生境全部语义、独立地图物件 |
| 物件帧 | 树木、岩石等地图物件的一种像素轮廓 | 世界的地理采样精度 |

这三个尺度必须分别决定。扩大世界格总量、增加每格原生像素和缩小物件帧会产生完全不同的视觉结果，不能统称为“把地图做大”。

## P0 实现基线，不是最终规格

- 世界地图：`1024 × 1024` 世界格。
- 地表：每个世界格当前表现为 `4 × 4` 原生像素，因此区域基准下的完整地表为 `4096 × 4096` 原生像素。
- 当前相机最大倍率为区域基准的 `4` 倍，因此最大近景下整张地图的理论屏幕跨度约为 `16384 × 16384` 像素；玩家只观察其中一小块。
- P0 visual bundle 已按 terrain、transition、water、vegetation、ground decoration、landmark、effects 与 world LOD 分成八张 PNG contract atlas，并由 manifest 语义解析。
- 当前区域与近景会执行完整可见视口的 `64×64` chunk，并绘制地表、水岸、材质组、树木、覆盖物、装饰、shadow、foreground 和受限水面效果。
- 详细 LOD 只在全部可见 chunk 就绪后原子显示；构建或跨入未缓存区域时继续显示完整世界概览，禁止世界概览与部分详细 chunk 拼贴成矩形切片。
- 世界视图树木以 `16×16` 世界格采样桶聚合，每桶最多一个低对比像素标记；区域与近景仍使用同一批树木事实的独立 sprite。
- 基础 `47` 拓扑遮罩、三种边缘节奏和 biome/terrain/chunk/autotile 调试视图已可在浏览器检查；完整正式岸浪美术尚未实现。
- Worker 只输出地貌、生境、材质、环境主题、水系和稀疏物件等语义事实，不直接加载图片；projection 才把事实解析为 visual handle。
- 当前占位纹理只负责暴露尺寸、palette、过渡和 LOD 边界，不代表正式材质密度、轮廓或重复控制质量。

旧四张 SVG atlas、枚举行序、物理帧布局和旧材质美术已经在阶段 3 浏览器闭环通过后删除：没有迁移、兼容或保留为回退。新的 P0 placeholder tileset 已按本规范和视觉 manifest 从头建立，只保留“地图生成输出语义事实、不直接加载图片”这一正确边界。

- P2-2 的 `4×4px` base 保持安静，形状节奏由低频世界坐标色调场和稀疏 `16×16px` 材质组承担；草原/沙漠材质组候选节奏约为 `10%/6%`，语义 overlay 约为 `1%`。这避免沙地变成逐格砂纸，也不靠堆满装饰识别生境。
- P2-2 浏览器 ground-only 门禁测得草原 `1.56%`、沙漠 `1.63%` 高频边缘率；两组镜头、近景快速拖动、WebGL2、DPR、确定性、控制台和资源请求均通过自动检查。atlas 构建还会检查上述 8 个装饰 family 各自至少存在 3 个不同的裁切 alpha mask。当前状态是“地表已检查、装饰精修等待用户验收”，不是正式美术完成。
- `P2-3` 已实现苔原与极地：固定 `continent + seed 8`，chunk `36` 为苔原雪岸，chunk `24` 为极地冰岸，chunk `38` 为寒冷山脊。雪/冰各有 `4` 个 base、`4` 个 group、`3` 个 overlay；寒冷岩地按生境各有 `3/3/2` 个候选。两类苔原树沿用 `16×24px`、底部中心锚点、年龄与高度契约；寒草、地衣、灌木、石块、岩簇、晶体、树桩、枯树与冰岸残片均通过原语义族解析。
- P2-3 的 `4×4px` 寒带基底保持纯净，雪尘、风蚀纹和冰裂只进入低频 overlay 与稀疏 `16×16px` 材质组。首轮浏览器截图触发了 `5%` 高频边缘门禁；根因是旧通配候选仍参与寒带解析，现已通过 biome 作用域隔离，而不是降低测试阈值。
- 寒冷高程必须是生成事实。生成器版本 5 在代表大陆北部加入确定性不规则山脊，温度仍由纬度和高程共同决定；renderer 只使用 `cold_highland` / `cold_mountain` palette 和寒冷岩地资源表现它，不凭空制造雪山。
- `P2-4` 专门完成世界视图。它使用美术提供的 `lod-world` palette、林团图形和 `1–4px` 地标符号，由程序聚合八生境密度、海岸、水系和高程；不得把区域/近景 sprite 直接缩小。
- P2-4 的世界总览必须消除当前纯色块草图感，同时禁止逐格噪点：远景读取大陆轮廓、分层海岸、生境大块、林团走势、高程结构和少量地标重音，保持静态并在八种模板上验收。

## WorldBox 尺度核查

详细证据见 [`research/WORLDBOX_MAP_SCALE.md`](./research/WORLDBOX_MAP_SCALE.md)。当前能安全采用的结论是：

- WorldBox 官方没有公开各地图档位的精确逻辑格数、每格屏幕像素或最大相机倍率。
- 官方只确认 Titanic 大于 Gigantic，PC 的 Iceberg 又大于 Titanic，并确认普通世界与 mini map 存在不同的表现路径。
- 社区技术资料长期一致地把 Titanic 测为约 `512 × 512` 逻辑格、Iceberg 测为约 `576 × 576` 逻辑格；这只能作为工程假设，不是官方规格。
- `4096 × 4096` 更可能是 `512` 格地图在每格约 `8` 屏幕像素时的显示跨度，不代表 WorldBox 拥有 `4096 × 4096` 个逻辑格。
- 用户提供的区域与近景截图具有相同输出分辨率，其中重复素材在近景约放大四倍；截图能证明层级差异，不能反推出 WorldBox 的精确最大倍率。

因此，当前没有证据支持扩大 Eon Vale 的逻辑地图。现有 `1024 × 1024` 世界格已经高于 WorldBox 社区测量的原生档位；资源是否“放得下”应先由区域视图每格屏幕像素、物件帧比例、锚点间距和分层表达共同验证。

## 视觉验收板

地图视觉系统使用四组隐藏名称与界面的固定截图验收：

| 验收图 | 规格 | 必须检查 |
| --- | --- | --- |
| 世界总览 | 完整 `1024×1024` 世界 | 大陆轮廓、生境色块、分层海岸、水系和宏观植被走势 |
| 生境区域图 | 每种基础生境一个 `64×64` 世界格裁切 | 地表斑块、树冠覆盖率、林团、覆盖物、装饰和留白 |
| 生境近景图 | 每种基础生境一个 `16×16` 世界格裁切 | 像素轮廓、左上受光、阴影、锚点、遮挡和装饰避让 |
| 过渡图集 | 海岸、河岸、生境交错和高程边缘 | 直边、内外角、末端、狭窄通道、孤立小块和不规则节奏 |

- 八种基础生境不能只靠色相区分；区域图中地表颜色与材质应独立贡献约 `60%–70%` 的识别。
- 世界总览不能出现由近景覆盖物直接缩小形成的噪声；近景不能暴露机械重复、错误受光或被装饰堵塞的构图净空。
- 只有四组验收图同时满足本规范，地图视觉系统才可进入素材完成或实现验收阶段。

## 规格状态

地图视觉语言、世界格与像素尺度、基础生境、海岸、水系、地形过渡、植被密度、地表覆盖物、装饰、环境地标、腐化主题、tileset、autotile、动画、atlas、命名、palette、去重复策略、美术与程序职责边界以及跨层级验收方式均已确认。本轮地图视觉与最终美术资产体系的决策前沿已经清空。

正式美术资产由谁制作保持未决；该问题不改变地图系统和资产契约。开发阶段允许先使用符合相同尺寸族、锚点、语义标识、层级和动画状态约束的 placeholder / prototype assets，之后整体替换正式 tileset，而不重写地图生成算法。

### Placeholder 替换边界

地图生成只产生地貌、基础生境、子材质、边界拓扑、物件类别和确定性变体种子，不引用 PNG 文件名、atlas 行列或帧矩形坐标。

替换美术时必须稳定：

- 语义资产 ID；
- 原生尺寸族；
- 锚点；
- 逻辑占地与排斥区；
- 渲染层级；
- 动画状态名称与帧节奏类别。

允许替换：

- 文件格式与具体文件；
- atlas 数量、打包位置和帧矩形坐标；
- 具体轮廓、配色与正式美术作者。

视觉 manifest 负责把语义资产 ID 映射到当前 tileset 的帧、锚点、LOD 表达和动画信息。placeholder 与正式素材可以使用不同的 atlas 打包结果，地图生成算法不因此改变。

当正式素材扩充同一语义族的 variant 池时，地貌、生境、物件位置和确定性变体种子保持不变；具体命中的轮廓可以随新 manifest 的权重和池容量变化。这属于美术替换，不是重新生成地图。

### Atlas 顶层分类

运行时 atlas 按视觉职责分类，不再让枚举数值绑定物理行列：

- `terrain-ground`：基础图块、子材质和材质组；
- `terrain-transition`：边界拓扑与高程、岸缘结构；
- `water`：水体 tile、浪花和水面动画帧；
- `vegetation`：树木、灌木和直立植物；
- `ground-decoration`：草、花、落叶和碎石等低矮覆盖物；
- `landmark`：中大型环境地标；
- `effects`：腐化和稀有环境效果；
- `lod-world`：世界视图专用小型符号和林团图形。

源素材保持独立，运行时打包为无损 PNG atlas 与 manifest。atlas 可以分页和重新排列，语义资产 ID 不变。

区域视图直接使用 `vegetation`、`ground-decoration`、`landmark` 等正式 sprite 的原生 `1×` 表达；近景使用同一 sprite 的 `4×` 最近邻表达。不存在独立 `lod-region` 美术 atlas。世界视图由程序聚合语义密度，但使用美术提供的 `lod-world` 符号和 palette。

### 语义 ID 与文件命名

- 语义 ID 使用点号分层，每个分段内部使用小写 `snake_case`。
- variant 使用两位编号 `v01`；动画帧使用 `f01`，但帧数不计入 variant 数量。
- 文件路径以资产类别、语义族和尺寸/形态层级组织，不包含 atlas 坐标、打包页、作者名或临时状态。
- 材质与同名 sprite 必须明确区分，例如 `grass_material` / `grass_tuft`、`rock_material` / `rock_sprite`。

示例：

```text
vegetation.tree.temperate_oak.mature.wide.v01
ground_cover.flower.temperate_meadow.small.v03
terrain.sand.desert.hard.base.v07
water.shallow.ripple.calm.v02

assets/source/vegetation/tree/temperate_oak/mature/wide_v01.png
assets/source/ground_cover/flower/temperate_meadow/small_v03.png
```

### 源素材与运行时打包

- 单个交换源素材使用透明背景的无损 PNG；未来美术制作者可以自行选择工作文件格式。
- 所有源画布遵守尺寸族和 `4px` 倍数。
- 运行时使用无损 PNG atlas 与 manifest，每张 atlas 页最大 `2048×2048px`。
- sprite 之间保留 `2px` 透明 padding；tile 保持完整画布，不裁切。
- sprite 允许运行时裁切透明边，但 manifest 必须保留原始画布、锚点和偏移。
- 禁止缩放打包、颜色压缩、抗锯齿和 mipmap。
- 动画帧不要求物理相邻，由 manifest 定义帧序列。

### Placeholder 分级

placeholder 只验证资产契约和地图视觉系统，不作为正式美术质量基线：

| 等级 | 覆盖范围 | 验证目标 |
| --- | --- | --- |
| P0 契约占位 | 覆盖全部资产类别、尺寸族、锚点、层级、shadow mask 和动画状态；每类只需少量简单轮廓 | 验证 manifest、atlas、渲染顺序、动画状态和整包替换链路 |
| P1 视觉切片 | 完成温带草原、温带林地、完整海洋与海岸、高程过渡和腐化主题；素材数量接近正式预算 | 验证密度、重复控制、跨层级表达和统一视觉语言 |
| P2 全生境占位 | 八种基础生境全部可生成，每类只制作正式 variant 下限的约 `25%–40%` | 验证完整世界、性能和所有语义路径 |

正式 tileset 接入后，生成算法、世界事实、物件位置和确定性种子不得改变；只允许 manifest、atlas、具体轮廓和 palette 内容整体替换。

### Visual manifest 必填元数据

每个可渲染资产条目必须声明：

- `asset_id`、资产类别和语义标签；
- 生境、材质族、树木原型、视觉年龄与高度形态等适用标签；
- atlas 页与帧矩形；
- 源画布尺寸、裁切偏移和底部中心锚点；
- 逻辑占地、物件排斥区与构图净空；
- 渲染层级、排序基线和最大视觉溢出；
- palette ID、colorway 与 variant 权重；
- shadow mask 引用；
- 动画状态、帧序列、帧率与相位类别；
- `lod-world` 引用和 manifest schema 版本。

地图生成只消费语义标签和确定性变体种子；atlas 页、帧矩形、裁切偏移等打包字段只由渲染与资产管线消费。

### Palette library

palette 是由 manifest 引用的命名资产，不采用单一全局索引色盘：

- 全局结构色约 `12–16` 色：最暗色、阴影、高光、中性岩石和木材等共享角色；
- 水体约 `12` 色：深海、外海、浅水和浪花的受控色阶；
- 每个基础生境提供 `6–10` 个地表色和 `4–8` 个物件/强调色；
- 每个环境主题提供 `6–8` 个主题强调色；
- 普通 sprite 通常只使用 `3–5` 个主要色阶；新颜色必须先登记到相应命名 palette，再进入素材；
- placeholder 必须保持正式 palette 的明度角色和对比关系，但允许减少实际使用色数。

### 资产导入与验收门槛

自动检查必须覆盖：

- `asset_id` 唯一，所有 manifest 引用完整；
- 画布、尺寸族、锚点、占地和溢出数据符合资产契约；
- atlas 页不超过 `2048×2048px`，padding 正确；
- tile 未裁切，sprite 裁切元数据完整；
- shadow mask 与主体 variant 使用相同源画布和锚点；
- 动画状态、帧序列和必要引用完整；
- palette 已登记；普通 sprite 的 alpha 仅允许 `0/255`，shadow/effect mask 例外；
- 不存在缩放、抗锯齿、mipmap 或有损压缩。

视觉检查必须覆盖：

- 每类素材的原生 `1×` 与最近邻 `4×` contact sheet；
- `64×64` 世界格区域的密度与重复测试；
- 树冠间隙、遮挡、落影、构图净空和局部重复冷却；
- 完整 `47×3` 地貌过渡图集；
- 世界 LOD 与区域视图的一致性；
- 世界总览、生境区域图、生境近景图和地理过渡图集四组视觉验收板。

### 有意保持未决的内容

- 最终正式美术由谁制作；
- `19` 套树木原型的具体物种名称，以及各 variant 的最终像素轮廓；
- 各命名 palette 的最终 RGB 数值；
- 美术制作者使用的源工作文件格式、绘制工具和生产排期；
- manifest、打包器、渲染器、水体效果和 LOD 聚合的具体实现方案。

这些内容不会改变已确认的视觉语言和资产契约。前四项属于正式内容生产，最后一项属于下一阶段的地图架构设计。
