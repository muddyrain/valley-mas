# Eon Vale 核心模拟重构决策

- 状态：设计树已闭合，待 owner 授权实施
- 接受日期：2026-08-15
- 规则真源：[`GAME_RULES.md`](./GAME_RULES.md)
- 交付状态：[`PLAN.md`](./PLAN.md)

## 背景

现有实现已经具备地图、种子、渲染、交互、存档和多类玩法，但完整世界观察证明“功能存在”和“世界可玩”不是一回事：LOD 会隐藏大部分实体，视觉层会绘制不存在的装备，动物缺少物种速度，文明不会响应领土内野生威胁，食物职业不能可靠响应饥荒，空聚落缺少衰败行为，任务诊断还会把正常需求中断标成受阻。

这些问题来自领域模型缺少统一的感知、决策、行动、结果和观察契约，继续在现有 `worldSimulation.ts` 中追加条件只会制造新的耦合补丁。因此第五批与 5.5 的产品验收撤回，第六批暂停。

## 已接受方向

以 WorldBox 当前公开可观察的玩法行为为基线，重新设计 Eon Vale 的核心玩法架构。对齐的是行为语义和玩家预期，不复制 WorldBox 源码、资产、UI 文案、商标或未公开数据。

首轮范围只覆盖稳定版 0.51.x 所代表的核心神明沙盒循环；文化、宗教、语言、家族深化、基因、书籍、复杂物种和未稳定发布的直接文明控制后置。验收以公开行为契约与因果结果为准，不追求逐项复制数值表。

迁移采用[**原地替换**](./adr/0001-replace-gameplay-core-in-place.md)，不建立长期并行的 `simulation-v2`。旧玩法核心不再维护兼容层，也不作为运行时后备；完成依赖边界清单和保留资产验证后，直接删除被新模型取代的需求、任务、职业、经济、生态、聚落、王国和战争实现，再按新的领域契约逐段恢复可玩能力。

### 原则上保留

- 确定性地图生成与世界种子复现。
- 地形、生物群系、资源节点和地图编辑能力。
- 正交像素相机、阶梯缩放、平移与地图拾取。
- 人物选择、跟随、悬停、检查器和目标定位等观察交互。
- 已验证可复用且不绑死旧领域模型的 PixiJS 渲染、Worker 通信、TypedArray、Chunk、A* 和 Flow Field 基础设施。

“保留”不等于原样冻结。任何基础设施如果迫使视觉编造事实、隐藏数量、泄漏旧状态模型或阻碍行为正确性，都必须改造或替换。

原地替换不授权无边界清空目录。实施前必须先形成机器可检查的保留清单和删除清单：地图与种子结果、地形资源格式、相机输入、拾取/选择协议和必要渲染资产属于保护对象；旧玩法状态、执行器、规则、存档字段和只服务旧领域的 UI 属于删除候选。删除后通过编译错误和契约测试逐项恢复，不允许为保持旧测试绿色而保留错误语义。

[V13 旧世界明确废弃](./adr/0002-discard-pre-release-saves.md)。新内核不提供只读旧世界、一次性迁移、旧 JSON 导入或旧 Schema 兼容分支；切换时使用新的存储命名空间并忽略或清理旧开发期档案。新存档只保存新领域模型确认的权威事实，版本和字段在第一条可玩垂直切片稳定后定义，不能先把旧任务、装备、聚落或王国字段搬过去。

[文明保持自治](./adr/0003-keep-civilizations-autonomous.md)。玩家不设置建设优先级、规划区、居民工作或军队命令；旧间接经营入口和状态属于删除候选。

[每棵树保持独立事实](./adr/0004-model-trees-as-individual-facts.md)，同一地图格最多一棵。中远景可以聚合显示，近景只对可见 Chunk 做纵深和焦点揭示，不能对全地图可视对象逐帧排序。

[居民决策与聚落需求分离](./adr/0005-split-resident-and-settlement-decisions.md)。聚落拥有缺口和有限任务机会，居民拥有需求、意图和任务；中央调度器不能直接把居民切换为工作状态，王国也不控制居民日常行为。

[居民按分层优先级低频拉取任务机会](./adr/0006-residents-pull-ranked-work-opportunities.md)。可行意图先按致命危险、紧急生存、家庭与安全职责、聚落任务、自主生活分层，再只在最高层内评分；工作角色随聚落缺口变化，技能与经验持续保留。接受机会会建立带版本任务和有期限预留，过期路径结果不得提交。

任务按危险等级在不同检查点中断：致命危险立即中断，紧急生存在安全检查点暂停，普通变化等待阶段或承诺窗口；失败按目标消失、不可达、资源不足和系统异常分别释放、退避、重选或进入诊断。没有紧急需求和合格机会时允许有期限的自主生活，而不是把空闲视为错误。

首轮自主生活到此封口：居民可以回家休息、短途散步、交谈、发笑、歌唱和玩耍，但不建立娱乐建筑或经济。社交必须有真实可达对象，失败立即回退单人活动；生活满意度只影响行为选择与诊断。检查器展示具体活动，地图使用短暂表达，聚落统一汇总为自主生活。

[聚落根据净缺口生成工作](./adr/0007-generate-work-from-net-deficits.md)。需求扣除库存、携带、预留和在途产出，任务机会再受目标、工位、存储、运输与资格容量反压；聚落不维持固定职业比例。

[居民身体只保留分阶段的核心生存事实](./adr/0008-model-core-physical-needs-as-staged-facts.md)。健康、营养和精力连续变化并通过带迟滞的阶段触发决策；危险来自感知，住所、家庭与满意度是上下文。食物遵守生产、入库、预留、领取、携带和进食的事实转移，休息优先使用真实住宅床位并允许低效安全回退。

[聚落由居民自主建立并通过真实物流施工](./adr/0009-found-settlements-and-build-through-logistics.md)。新世界默认没有文明居民，玩家按个体投放；合格成年人可以在具有空间、食物、树木、安全与距离条件的土地建立营地，单人建村不绕过人类伴侣繁衍。新村没有资源礼包，只有零材料但仍需劳动的营火、帐篷与基础储存点。聚落按净缺口选择有限项目，工地、材料运输、劳动进度和建筑启用组成单一事实链。

[资源必须真实运输，装备表现只读所有权与动作](./adr/0010-transport-resources-and-render-owned-equipment.md)。首条切片使用食物、木材、石料与普通金属；聚落维护单一库存，建筑提供端点与容量。送达前的产物是携带或现场资源；职业工具由任务阶段派生。武器与护甲必须制作、入库、领取并装备，基础居民模型不自带武器。

[食物真实生长，建筑只保留最小因果集合](./adr/0011-grow-food-and-keep-only-causal-buildings.md)。开荒依赖野外食物，农田是稳定主粮，成年动物提供肉食；捕鱼后置。首条切片只保留六类必要建筑，只有帐篷与基础储存点存在功能明确且外观可见的升级。生产工作站必须有在场工人、真实输入、持续时间与输出运输。

[动物按物种档案、本地种群和局部威胁事件运行](./adr/0012-model-species-and-local-wildlife-threats.md)。首条切片启用鸡、羊、牛、鹿、狼和熊，鱼暂不激活；不同物种独立定义移动、饮食、感知、繁衍、捕食、逃跑、危险与栖息边界。普通活动围绕适生环境，种群容量按连续栖息地结算；`384×384` 默认自然数量约 `400–700`，新内核必须实测 `1,000` 名人类与 `1,000` 只活跃陆生动物并存。人类狩猎由食物净缺口生成有限机会并完成真实猎物、尸体、屠宰、运输和入库链。危险动物进入聚落领土或居民感知范围就形成可观察入侵，即使当前目标是其他动物；路过引发避让与拦截，接近文明目标或攻击时分级升级，威胁消失后解除且不能无限追击。

[个体战斗只提交事实伤害，死亡保留可回收尸体](./adr/0013-resolve-combat-and-preserve-remains.md)。基础攻击由身体或物种、真实武器和技能构成，攻击速率控制频率，护甲按比例减伤，确定性暴击提供有限变化；首轮没有普通未命中。真实武装守卫可以响应威胁，猎人只攻击有效猎物，平民逃跑并仅在被困、受击或近亲直接遇险时自卫。重伤、低精力或孤立允许脱离，首轮不做个人投降与俘虏。死亡停止活体任务并生成保留身份、死因、装备和携带物的尸体；回收和搜取是显式行动。近景使用克制像素命中反馈、按情境血条和限流声音，并启用徒手、单手挥击、长柄突刺、动物攻击、硬直、击退、撤退与倒地。动物尸体在屠宰窗口后腐烂；人类尸体只允许有容量的遗物回收，随后自然腐化并把耐久物品留在原地，死者事实进入历史。

[聚落状况由权威事实派生，零人口立即废弃](./adr/0014-derive-settlement-lifecycle-from-facts.md)。人口、生存供给、安全、住房、库存、承诺产出和建筑健康决定正常、承压、饥荒、濒危、废弃、衰败、被接管与毁灭，阶段标签不能被任意写入。仍有一名居民就不是废弃；最后一名居民死亡或离开后立即废弃，当前原子结果完成后取消任务与预留并停止所有文明运行。建筑、库存和领土分别按真实材料、损伤、端点与控制强度衰败。相容居民必须进入、确认安全、建立归属并修复文明锚点才能接管；零居民、零领土且锚点均不可恢复后毁灭，建筑转为可交互遗迹。居民层连续表达停产、破损、现场资源和回长；聚落层使用色调、轮廓和活动密度；世界层只保留战略标记。接管的勘察、清障、运输、修复、名称、灯火、功能和领土严格随事实检查点恢复。

### Web 容量合同

- 首轮目标平台为桌面 Chrome 与 Edge。
- 硬基线为 `384×384` 地图、`1,000` 名人类与 `1,000` 只活跃陆生动物并存、固定 `20 Hz` 模拟和 `60 FPS` 渲染目标。
- `1×/2×/4×/8×` 只改变执行步数；相同种子与 Tick 数必须得到相同结果。
- 移动端与更大世界属于后续扩容，不阻断首轮行为正确性。

### 运行时代码准入门槛

一段规则、状态或配置只有同时满足以下条件才能进入新内核：

1. 能指出唯一的权威事实归属，或明确声明为可从权威事实确定性派生的观察投影。
2. 能说明它改变了哪个玩家可观察结果，而不是只让代码“以后可能用到”。
3. 至少有一条短场景行为契约证明它何时生效、何时不生效以及失败时如何解释。
4. 已被当前交付范围实际调用，不依赖未实现的未来系统才能成立。

不满足门槛的枚举、字段、阈值、法则开关、占位处理器、兼容分支、UI 入口和测试直接删除。未来批次的构想只记录在玩法文档，不提前进入运行时；产品批次和交付状态也不得伪装成世界模拟法则。

### 原则上重建

- 人物需求、感知、记忆、意图、任务与行动状态机。
- 村庄库存、食物来源、职业分配、生产、运输和装备所有权。
- 动物物种档案、饮食、速度、视野、捕食、逃跑和目标关系。
- 聚落安全、威胁事件、平民避让、守卫响应和防御建筑协作。
- 家庭、繁衍、迁居、聚落形成、承压、废弃、衰败、接管和毁灭。
- 王国公民、领土、外交、军队、战争、流亡与灭亡。
- 任务、装备、伤害、动画、检查器、历史和 LOD 之间的单一事实源。
- 以短场景行为契约为首要证据的测试与验收体系。

## 目标领域流水线

每个生命和文明领域都遵守同一条因果链，但不建设一个万能规则引擎：

1. **事实**：位置、身体、库存、装备、关系、领土和环境。
2. **感知**：只从事实派生当前可感知的食物、危险、同伴、目标和事件。
3. **决策**：按需求、职责、风险和可行性选择意图，并记录选择原因。
4. **行动**：通过导航、预留、工作、战斗或交互推进可中断状态机。
5. **结果**：只在行动实际完成时修改库存、身体、建筑、关系和历史。
6. **观察**：动画、LOD、检查器和事件只投影上述事实，不自行推测或补画。

## 第一条可玩垂直切片

首条切片只实现单聚落闭环：`12–40` 名人类建立聚落，自主取得基础资源并建设，完成进食、休息、繁衍、装备、野兽威胁响应和失败衰败。该切片同时验证意图到观察的因果链、独立树木、三层事实连续和 `1×/8×` 确定性；王国、军队和战争在它通过后进入下一条切片。

王国基础采用[聚落组成、层级归属与真实供应](./adr/0015-compose-kingdoms-from-settlements.md)：独立聚落各自建国，王国殖民者建立的新聚落继承原王国，同种族聚落不会自动合并。居民先属于聚落，王国归属由聚落派生；建国聚落是稳定首都，建国者成为首任国王，国王与聚落领袖分离，继任者来自合格聚落领袖。资源归聚落库存，王国内供应必须由富余聚落真实运输到缺口聚落，不存在共享王国仓库。跨国贸易、外交援助、战争赔款与复杂继承只进入后期候选清单，不提前污染运行时。上述规则尚未实现。

王国扩张与关系采用[基于事实并经过准备的政治计划](./adr/0016-drive-expansion-and-diplomacy-with-plans.md)：殖民由持续发展压力、真实余粮、合格成年人、有效统治者与合法可达候选地共同成立，饥荒、战争、严重威胁、人口过低或弱小聚落待援时暂停；选址综合可建空间、生存资源、距离、危险和领土冲突，殖民者必须真实抵达。忠诚由治理容量、首都可达性、支援、近期征服/换王和战争疲劳等事实派生，持续低忠诚的非首都聚落具备领袖与自保能力后才能筹备叛乱。王国关系只有和平、联盟、战争和休战，好感只解释变化机会，状态必须由政治计划、战争结果或神力提交并遵守稳定窗口。上述规则尚未实现。

殖民与政治结果采用[真实队伍与原子政治提交](./adr/0017-commit-colonies-rebellions-and-alliances-from-facts.md)：殖民队由母聚落真实居民构成，目标约 `6` 名合格成年人并尽量保持家庭完整；口粮与已有装备真实领取，任务态职业工具不升格为物品。抵达后先形成临时殖民营，营火和基础储存锚点可用时才原子创建聚落、成员归属、领土种子和实际卸载库存。叛乱由发起聚落和直接相邻的合格低忠诚聚落组成新王国，原资产不复制不重置，并立即形成叛乱战争。联盟是两个以上王国的真实共同体，默认承担共同防御，进攻与叛乱参战逐国判断。上述规则尚未实现。

军队采用[聚落所有、真实集结与本土守备](./adr/0018-organize-armies-by-settlement.md)：每个合格聚落最多组织一支本村居民军队，由队长带领；王国只形成战略目标，聚落领袖决定本军参与和目标。士兵必须是完成真实训练并持有真实武器的健康成年人，容量受人口、食物、训练、装备、生产和家庭延续约束。主动出征要求队长、路线、武器和口粮有效并真实集结到计划兵力约 `80%`，本土紧急防御不受该门槛。每个聚落动态保留本土守备，外出期间的新兵留守，殖民护卫按母城与新村守备事实返航或转属。三级观察必须保持不同聚落军队、成员、路线与补给事实连续。上述规则尚未实现。

战争采用[有限征服目标并保持居民生存规则](./adr/0019-limit-war-objectives-and-preserve-resident-needs.md)：自主征服必须由持续低好感、真实边界/扩张冲突、缺少安全发展空间、稳定统治与军队补给和陆路可达目标共同成立；防御、叛乱、联盟防御与神力战争由对应事实产生。军队主动攻击敌军、队长和仍阻挡目标的防御设施，不追杀普通平民或自动破坏民用建筑。指挥、兵力、伤势、疲劳、口粮、队形、目标和路线恶化会触发撤退或无免费补给的战地营地；士兵继续遵守普通居民生存与装备规则。王国检查器和关系层必须显示同一双边好感、趋势、原因、关系、计划与冷却事实。上述规则尚未实现。

战役采用[稳定目标、事实占领与可解释停战](./adr/0020-coordinate-campaigns-and-resolve-wars.md)：征服目标只从陆路可达敌方聚落中按邻接、补给、防御与战略价值选择，并在完成、失效或安全撤退前保持稳定。每支聚落军队同一时间只承担一个目标，多军通过承诺兵力、集结点、路线和增援事实协同。占领只在真实聚落领土内由军事控制推进，组织化守军与有效防御会阻断完成；完成时原子转移聚落归属但不重置居民、建筑、库存、损伤或历史。战争根据目标、占领、军力、伤亡、疲劳、食物、首都风险和无进展形成议和/投降，结束后撤军并进入休战。王国领土是成员聚落领土并集，地图使用可切换颜色、边界、村庄分界和关系纹理投影同一事实。上述规则尚未实现。

征服结果采用[保留被征服聚落的真实对象与因果](./adr/0021-preserve-conquered-settlement-facts.md)：占领提交时解散目标聚落原军队并取消敌对命令，幸存本地士兵保留居民、家庭、伤势、经历和个人装备事实，但不立即加入征服方；外部旧国军队保持原归属并真实撤退。近期征服同时形成忠诚压力和有限稳定保护，恢复取决于安全、食物、住房、供应、治理与时间。居民、建筑、库存、现场资源、损伤、生产和历史不重置，普通任务重新验证，旧军事/政治任务取消，不自动掠夺或传送资源。盟军战役在出征前按主战、真实接壤、补给与治理可达性确定唯一主张方，不由最后一击决定。上述规则尚未实现。

征服后的政治延续采用[让驻防、归属、继任与历史保持真实](./adr/0022-keep-post-conquest-politics-physical.md)：首轮没有独立占领军，现有参战军队只在战争或局部威胁持续时临时驻防，消耗真实补给并占用母城远征容量，结束后真实返航；当地军队按普通规则重建。居民当前王国随聚落改变，家庭、住宅、关系和物品不重置，旧国与旧职位只进入政治履历。国王和领袖必须真实逃离，首都失守后按人员与存续聚落事实迁都、继任或流亡。占领扩散、换旗、驻防、撤军与恢复进入三级表现，每次征服形成可跨人物、聚落、王国和战争定位的结构化历史。上述规则尚未实现。

战后生活采用[让平民和聚落从真实缺口中恢复](./adr/0023-recover-conquered-settlements-from-real-needs.md)：普通平民只在当前聚落内执行局部避险并优先靠近家庭，不新增战争专属跨村难民链；被占聚落从当前真实成年人中重新评估领袖，原领袖只有满足新归属与资格才可再次当选。跨国亲属关系保留但不产生双重国籍或瞬移，是否开放受限跨国团聚仍待决定。恢复按持续危险、食物/休息、住房/储存、关键生产/防御、本地守备、有效旧建设和新扩张的事实缺口推进。历史永久保留，居民、聚落和王国层面的战争影响按不同时间尺度衰减并进入同源 UI。上述规则尚未实现。

战后归属收口采用[让重新武装和流亡继续遵守聚落事实](./adr/0024-rearm-and-rehome-after-conquest.md)：跨国团聚继续与完整跨国迁居一起后置。新征服聚落在安全、领袖、生存、生产、训练、装备、人口与近期征服稳定条件满足后，先重建本土守备再恢复远征军。恢复完成由危险解除、生存/住房/储存底线、核心生产、治理与最低防御事实派生，不要求全建筑修复，也不删除历史记忆。原村被占但仍在外的旧国军队转为没有聚落库存、住房、补员和生产能力的失所军队，真实撤往旧国存续聚落并在抵达后接纳重组，或在无聚落时维持流亡并按真实定居规则求生。上述规则尚未实现。

神力采用[自由施放但按明确目标提交](./adr/0025-cast-free-powers-through-explicit-targets.md)：现有十六个主题全部重新验证，“和平/战争”拆成两个目标化工具，形成 `17` 项首版范围；旧效果、数值和全局外交切换不迁移。神力没有法力、资源、通用冷却或解锁成本，连续输入按世界距离确定性采样并通过有界预算顺序提交，不因帧率丢失结果。地形/生态、点灾害、单位/区域状态与双王国外交使用各自目标契约，预览不是事实，模拟、历史、音效和视觉只从权威施放结果产生。战争只强制选中双方进入战争而不绕过物理战役规则，和平只结束选中的战争；外交与战争法则关闭时禁止战争神力但仍允许和平。上述规则尚未实现。

非外交神力采用[按因果边界区分自然、生命状态与灾害](./adr/0026-separate-power-effects-by-causality.md)：降雨、生长与繁盛分别改变环境、植物生命周期和合格生命的自然繁衍机会；祝福、治愈与净化分别负责有期限强化、活体健康恢复和异常状态清除。狂暴是非政治性的临时无差别攻击，诅咒是不可传染的长期衰弱，瘟疫由真实感染者跨群体传播。雷击是瞬时命中，火焰是传播格子危险，龙卷风是移动灾害实体，陨石是预警后撞击并留下陨坑，冰霜是可解冻低温区域，地震是短时多次震动且不统一降低大陆高度。所有命中、伤害、传播、尸体、地形、历史和三级视觉来自同一权威事实。上述规则尚未实现。

神力交互采用[离散范围、有限叠加和暂停冻结演化](./adr/0027-bound-power-inputs-and-freeze-time.md)：连续环境与区域生命工具使用小、中、大、特大四档圆形世界范围，点灾害使用固定物理范围；具体格数由行为与性能门禁校准。祝福、繁盛、狂暴和诅咒重复命中只刷新时长，祝福与诅咒互相替代；治愈可重复恢复到上限，瘟疫不重复感染，环境事实有上限，多个灾害保持独立事件。火焰、冰霜和龙卷风由环境反制或寿命结束，不增加万能清除且不回滚后果。暂停允许提交即时结果，但所有依赖世界时间的移动、传播、周期伤害、倒计时、成长和环境衰减冻结。旧统一冷却、固定半径和前端预演成功路径不迁移。上述规则尚未实现。

神力结果采用[统一世界时间、显式抗性与聚合事件](./adr/0028-time-resist-and-report-power-effects.md)：所有状态、环境和灾害持续时间以剩余模拟 Tick 为权威，暂停冻结、倍率只改变现实等待，存档必须连续恢复。疾病免疫、强心智、防火和抗寒是显式能力，只影响登记状态或伤害；身份、职业、家庭和收藏不提供抗性。雷击、火焰/冰霜、龙卷风、陨石和地震分别采用重伤中心、暴露累积、路径多次伤害、中心通常致命和建筑优先的基础轮廓，精确数值由确定性场景校准。一次成功施放建立一个持续汇总命中、抗性、损坏、死亡和结束原因的神力事件，局部反馈、三级地图、通知、检查器和历史共享同一摘要。上述规则尚未实现。

神力收口采用[逐项登记冲突并只保存已提交事实](./adr/0029-register-power-law-conflicts-and-save-committed-facts.md)：世界法则只阻止明确登记的自主过程或目标类别，玩家灾害、直接创造生命、部分繁盛和和平分别遵守各自例外，不建设全局优先级。保存停在确定性模拟边界，先结算此前已接受的命令，再持久化状态、感染、环境、灾害和事件摘要，不保存输入积压与视听瞬态。祝福与诅咒只修改移动、物理攻击、物理抗伤和诅咒期自然繁衍资格；瘟疫经历潜伏、传染和重症且只因净化或死亡结束。十七项神力按自然、生命、灾害和外交组织，工具选择保持、范围逐项记忆，快捷槽属于浏览器偏好。上述规则尚未实现；神力产品合同已形成首轮闭环。

世界塑造采用[让森林由树木派生并让塑造后果保持真实](./adr/0030-derive-forests-and-keep-world-edits-causal.md)：旧森林格收敛为林地土壤，森林由独立树木和生态密度派生，画笔不逐格生成成熟树。地形覆盖已有世界时，生命进入真实逃生与环境风险，建筑、道路、资源、任务、预留和路径按损坏或失效事实处理，只增量更新受影响 Chunk。生命点击只创建一个成年早期个体，连续投放按世界距离和 `Shift` 确定性采样；资源投放创建树苗、野生食物、石料和普通金属节点且不直接入库。万能擦除拆成无尸体/战利品的生命抹除、因果结构拆除和资源移除；五个顶层工具模式全局互斥并统一鼠标、键盘和触控边界。上述规则尚未实现。

新世界采用[生成可复现世界并把暂停与倍率解耦](./adr/0031-generate-replayable-worlds-and-decouple-pause.md)：基础配置固定为种子、`128/256/384` 尺寸、群岛/大陆/空白海洋预设和植被/资源/动物开关，任何预设都不创建文明居民。地图权威事实把海拔与地表生境正交存储，通行、建造、生态和视觉从两者派生。非空白预设按尺寸保证至少 `2/4/6` 个可定居区域，失败时在同一种子下确定性最小修复。新世界默认暂停、全世界相机、观察模式和无覆盖，但保留浏览器当前时间倍率；暂停只冻结世界时间。首轮没有局部撤销，高风险手势在确定性边界生成独立完整安全快照，快照失败就拒绝提交。上述规则尚未实现。

观察层采用[按语义投影世界并揭示被遮挡生命](./adr/0032-project-observation-semantically-and-reveal-life.md)：居民层绘制视口内全部真实对象，聚落层形成带精确数量的生命群、森林密度与活动热点，世界层只保留战略事实；任何层都不再按对象标识随机抽样。脚点纵深、分离树冠、遮挡轮廓和焦点揭示共同保证未选与已选生命可读。全世界投影替代常驻小地图，`M` 与观察返回栈保持相机上下文。居民、聚落、王国、军队、战争和灾害共用同一右侧检查器，三级视觉反馈只读取权威事实并在超出屏幕预算时确定性聚类。上述规则尚未实现。

观察交互采用[优先显示重要观察并分离通知与历史](./adr/0033-prioritize-observation-and-separate-event-records.md)：标签按选中、收藏、危险、政治军事和普通对象稳定避让；生命跟随使用可临时脱离的软相机，死亡时停在原地并由玩家选择后续对象。普通动作只做即时反馈，近期异常聚合成可清理通知，重要世界结果写入结构化历史。地图只允许一个连续填色层并组合稀疏标记，每个本地世界旁路保存相机与覆盖元数据，新世界仍以无覆盖全世界视图开始。键鼠和触控分别具有无歧义的观察/工具合同，所有名称、热点、通知和历史都通过“压入相机位置 → 定位 → 打开统一检查器”展开。上述规则尚未实现。

新内核执行采用[以单一运行时垂直替换并发布可恢复观察](./adr/0034-replace-one-runtime-and-publish-recoverable-observation.md)：先建立新状态、命令、`20 Hz` 固定阶段 Tick 和场景骨架，再按生命生存、资源物流与建设、动物威胁与战斗、聚落生命周期、观察层逐段接管；每段接管即删除对应旧链，不运行并行 V2。Tick 依次处理命令、环境与身体、感知、低频规划、意图与预留、行动与战斗、结果提交、清理与历史、观察发布，领域写权限明确。Worker 为 Pixi 发布动态帧/脏区/关键帧，为 React 发布低频摘要；IndexedDB 原子清单分开手动、自动、安全与观察数据。第一条单聚落切片必须同时通过行为、可读性、确定性与 Web 性能门禁。上述规则尚未实现。

## 待决问题

当前设计树没有阻挡实施计划的未决产品或架构问题。Q1–Q165 已形成共享理解，下一步只生成并评审实施计划；收到独立实施授权前不修改运行时代码。实施中若发现会改变玩法语义、权威事实归属、存档边界或退出门禁的新问题，必须重新加入本节并恢复“接受一项、立即同步一项”的决策流程。

本文件、`GAME_RULES.md`、`PLAN.md`、`CONTEXT.md` 与 ADR-0001 至 ADR-0034 共同构成本轮设计基线；实施计划不得把“已接受、待实施”误报为“已交付”。
