# Eon Vale 产品与交付状态

更新时间：2026-08-14。玩法语义、默认值、阈值、例外和待决问题以 [GAME_RULES.md](./GAME_RULES.md) 为唯一真源。

## 产品定位

Eon Vale（纪元谷）是一个浏览器单机 2D 像素神明沙盒。核心体验不是随机移动单位演示，而是可持续演化、可被玩家干预且可存取的活世界：居民出生、成长、工作、建设、获得装备与身份；聚落发展经济并建立王国；王国可能结盟、开战或灭亡；动物参与觅食、逃跑、捕食和繁殖；神力会改变真实模拟状态。

## 已交付状态

- **阶段 0 性能骨架**：Web Worker 固定 20 Hz 模拟，主线程快照插值，实体状态使用 Packed TypedArray；个体寻路使用带预算 A*，战争群体移动使用 Flow Field，局部避让使用空间哈希。
- **PixiJS 8 真 2D 渲染**：不再使用 Three.js、透视相机或斜视角。地图固定正北，只允许有边界的平移与 `0.5/0.75/1/1.5/2/3/4` 阶梯缩放，缩放锚定指针，不支持旋转和倾斜。
- **三级地图 LOD**：世界层使用每格 1 像素的宏观纹理，只保留连续海岸、大片生物群系、聚落名称和资源叠层；聚落层使用 4 像素区划纹理并显示抽样居民、抽样资源、道路与建筑；居民层显示完整居民、建筑与资源节点。地形 Chunk 原位更新，地图只同步脏单元，资源只同步脏节点，不在周期快照中传输或重建整张地图，避免整屏闪烁。
- **有限世界**：支持 128、256、384 三种地图，默认 256；支持确定性群岛、主大陆和空白海洋，边界始终为深海，同一种子可重放。空白海洋不预置居民或动物，需玩家先创造陆地和生命；自然回归只作用于该世界曾经存在过的物种，不会把从未引入的生命凭空加入空白世界。
- **地图编辑**：升高、降低、陆地、水域、森林、食物、石料与清理；森林、石料和清理直接创建或移除独立节点，编辑仅使受影响导航 Chunk 失效，并同步脏单元与脏节点。
- **个体人口系统**：所有居民都是持续存在的真实个体，拥有年龄、性别、家庭、伴侣、父母、健康、饥饿、精力、职业、等级、经验、贡献、身份、装备、特质、携带资源、资源目标和个人经历。初始人口采用平衡年龄结构；出生来自同村伴侣并继承家庭关系，新生代性别会优先补齐本王国未成年人口中较少的一侧，不再受历史槽位奇偶影响；居民会老去，并按寿终、饥荒、疾病、袭击或灾害记录死亡原因。实体数组达到 1,200 个历史槽位后，会安全复用未被存活家庭、王国领袖或先遣队引用的死亡槽位，避免长局永久停止出生和投放。
- **动态承载力与迁徙**：村庄承载力由住房、农田产能、储粮趋势和安全共同决定，空置遗址不再虚增当前人口承载目标。人口压力按“抑制出生 → 扩建真实住房 → 家庭迁居 → 消耗储备 → 长期饥荒”响应；满载聚落的年轻伴侣会带未成年子女沿真实路径迁入同王国可达的低占用聚落，低人口聚落的未婚成年人也可迁往存在适龄配偶的村庄，均不使用瞬移或生成替身。
- **像素居民与王国识别**：居民由肤色、头发、衣服、王国色、职业工具、身份和装备分层生成；无王国居民使用中性色。建筑、居民和旗帜共享王国色，同一套像素实体在世界、聚落和居民层连续缩放，不替换为战略圆点。
- **动物生态与野生食物闭环**：鸡、羊、牛、鹿、狼、熊、鱼具有饥饿、年龄、寿命、栖息容量、繁衍、捕食和可诊断死因。动物死亡留下会腐烂的可见尸体；缺粮聚落安排猎人追猎成年食草动物，持续屠宰后携肉入库。采集者只能站在陆地岸边消耗真实鱼群，渔获送达前不进入库存；鱼群通过水域取食、繁衍和自然回归恢复。生态面板显示活体、尸体、屠宰、捕获和腐烂统计。
- **世界法则目录**：建立类型安全 `WorldLawCatalog`，统一法则 ID、分类、默认值、决策状态和交付状态。当前 UI 已开放饥饿、自然老死、人类繁衍、动物繁衍、动物捕食、动物自然回归和默认关闭的“文明重启”；扩张、外交战争与灾害仍保持计划中，关闭行为未完整接通前不显示为可用开关。
- **可信通行与独立资源节点**：人类和陆生动物统一遵守深水、山脉、动态地形和成熟树干碰撞，路径压缩保留道路与森林密度代价，旧路径会随导航版本失效；森林 `75%`、缓坡 `85%`、陡坡 `60%`、道路 `140%`，携重继续减速。树木、露天石料和金属矿脉使用可扩容 TypedArray 和 `8×8` 分块索引，384 地图稳定生成约 2.95 万个节点；成熟树格进入高代价通行档案，施工与道路会先清理真实节点，不把整片森林变成不可达墙。
- **语义任务、生活与需求驱动经济**：居民任务持久保存类型、原因、目标、阶段、进度、租约、抢占和失败结果；检查器展示原因、目的地、预期结果、携带物、住宅与工位。普通饥饿会先到仓储取餐再回家进食，极端饥饿在仓储就地进食；睡眠回到家庭住宅，无房居民露宿且恢复减半。伐木、采矿、播种、收割、制作、施工和搬运都包含前往、持续工作、可见携带与入库，入库前不增加聚落库存。
- **功能建筑与分类仓储**：村庄中心负责调度，住宅提供家庭住房，仓库为七类资源分别提供容量，农田、伐木营地、矿场和工坊提供真实工位与生产端点；损毁建筑停止提供能力。聚落仍使用汇总账本，但超出分类容量的资源进入可见露天积存并可能腐坏或被火烧毁。建设规划由人口、食物、住房、仓储和生产缺口驱动，玩家可选择自动、住房、储粮、食物、生产或防御优先级，生存危机会解释性覆盖优先级。
- **施工物流**：建筑选址会先锁定一次成本，清理工地与道路上的真实资源节点并回收材料，再由搬运者到仓储装载预留材料并分批送达工地；全部材料到位后建筑工按 Tick 推进施工。清障、运输、施工、受损和摧毁状态均可被地图反馈与建筑检查器观察。
- **王国战争**：村庄形成王国并维护和平、联盟和战争关系。守卫沿共享 Flow Field 集结，接敌后优先攻击敌方守卫；防守力量崩溃后才累计聚落占领进度，不主动追杀平民。占领会转移聚落、居民和王国归属，保留至少 65% 聚落与建筑健康，使经济可以继续运行。战争记录初始军力、进展、得分与疲劳；持续 5 年后会因军力低于开战时 40%、失地或长期无进展而议和，20 年强制结束，并进入 15 年休战。
- **战斗表现**：守卫沿用可见武器、护甲等级与队长旗帜，并增加两帧突刺、受击红闪、仅战斗中显示的细血条和死亡烟尘；装备等级继续影响像素外观和实际伤害/减伤。
- **十六种神力**：降雨、雷击、火焰、龙卷风、陨石、瘟疫、祝福、治愈、狂暴、和平/战争、诅咒、生长、冰霜、地震、净化、繁盛；均作用于真实环境、资源节点、实体、建筑或外交状态。生长会创建或催熟树木，火焰会烧毁树木，陨石与地震会移除命中节点。
- **动作图集与观察操作**：人类使用四朝向以及待机、步行、搬运、砍树、采矿、建造、进食、睡眠动作，动物使用待机、步行、进食、攻击动作；受控调色板帧由源码生成到单一共享 PixiJS 图集 source，斜向移动复用最近方向。全屏地图、紧凑顶部状态、底部工具、时间控制和检查器继续保留；建筑可直接拾取并解释能力、工人、工位、输入输出、状态与停工原因，选中居民会显示目标连线和携带物。
- **V12 存档**：Zod 严格校验的版本化 JSON；按开发期约定明确拒绝 V11，不建立迁移链。V12 延续 V11 的地图、居民、任务、经济、战争、领土、规划、首都和历史事实，并新增动物尸体、下一尸体 ID 及狩猎、屠宰、捕鱼任务状态；A* 路径、动画帧、派生边界、派生邻接和脏格队列不持久化，载入后重建技术缓存与观察数据。三个手动档、三个滚动自动档和导入导出均沿用原子替换策略。
- **第三批 3A · 真实逐格领土**：聚落根据等级、人口、建筑和可达地形逐格扩张，相邻聚落使用同一所有权数组竞争分界，废弃聚落按控制强度逐步衰退；野外食物与独立资源节点优先使用本村领土、其次使用无主土地，不能跨入其他村庄领土采集。征服必须进入真实目标领土，完成后由村庄王国归属即时派生王国领土。领土通过 Worker 只同步脏格，覆盖层不再按聚落半径画圆。
- **第三批 3B · 四级聚落与空间规划**：营地、村落、城镇和城邦按人口与具体可运行建筑逐级发展，升级成本来自这些建筑的真实资源、运输和施工；建筑外观按聚落阶段使用帐篷木构、木屋、石木混合和城邦石材层次。玩家可在本聚落可通行领土内绘制住宅、生产和防御区，自主选址优先匹配规划区但不会绕过地形、占用和矿脉门槛；规划区通过领土脏格同步并进入 V9 存档。聚落检查器显示下一阶段条件、规划格数和工作热点人数，地图提供规划区与工作热点覆盖层。
- **第三批 3C · 王国观察层**：王国外边界、同王国内村庄分界、首都标识、邻接关系与战争前线全部从真实逐格领土派生；选择王国会强化本国、弱化其他王国并连接真实邻国。创立聚落是稳定首都，失守后按聚落等级、人口、可运行建筑与建立时间自动迁都；真实首都现由 V11 存档延续。王国检查器显示首都、邻国外交与下属聚落，并可定位首都。
- **第三批 3D · 聚落纪事与历史定位**：历史档案按王国、村庄、人口、生态、灾难和收藏人物筛选，结构化事件保存人物生命 ID、村庄、王国、战争和地点引用并可回到地图；人物履历、聚落纪事和王国纪事只读取真实模拟事实。普通工作不写档，普通出生不进入全局档案。完整档案通过 Worker 按需查询，高频快照只带重要通知和修订号。
- **第三批 3E · 公共防御能力与总验收**：兵营提供守卫工位、在场训练与成长，议事厅增强领土可达预算和控制强度，城墙在被逐座攻破前阻止占领进度，瞭望塔扩大领土并定期射击范围内敌方守卫；所有能力只来自建成且健康的建筑，损毁后立即失效。聚落和建筑检查器可观察能力状态，防御优先级会补齐三类防御建筑且不会无限重复兵营。能力从 V11 已保存的建筑事实派生，无需提高存档版本。
- **第四批 · 完整野生生态与食物闭环（已完成）**：动物生命法则、尸体腐烂、成年猎物狩猎、屠宰搬运、真实岸边捕鱼、鱼群恢复、观察统计和 V12 已落地；采集者在没有可达野外食物和岸边鱼时会回退到可运行农田。默认静态/单元/构建、常规 Chrome、3 个 250 年种子、10 个 2,000 年分层种子与 30 分钟 8× 浸泡均已通过。
- **音频**：Web Audio 程序化环境底噪和创建、神力、危险、选择提示音，可静音，不依赖外部素材。

## 第三批浏览器总验收

3E 使用稳定生产预览重跑 384×384 主大陆、1,000 初始居民、约 3 万资源节点的 30 分钟 8× Chrome 浸泡。30 个逐分钟采样中 Tick 从 `9,588` 推进到 `254,118`，FPS 始终为 `60`，最差 P95 `22.6 ms`，最高 Draw Calls `10`、最高三角形 `1,014`、最终累计平均 Tick `1.12 ms`。Worker 现上报真实路径队列：首分钟峰值 `323`，随后收敛到 `0`，全程低于 `2,000` 门槛；累计完成路径 `748,773`。常规 Chrome 套件覆盖聚落检查器中的兵营、议事厅、城墙和瞭望塔能力。

## 第四批总验收

常规生产预览 Chrome 套件为 `7` 项通过、`1` 项长浸泡按配置跳过。100/500/1,000 居民近景均为 `60 FPS`，P95 分别为 `17.2/17.7/17.5 ms`，平均 Tick 分别为 `0.41/0.97/1.76 ms`；384×384 / 1,000 居民完整世界为 `60 FPS`、P95 `17.7 ms`、平均 Tick `0.80 ms`、路径队列 `207`。无 DOM 的成熟 384 世界 60,000 Tick 六段样本为每 10,000 Tick `6.47–8.76s`，约 `0.65–0.88 ms/Tick`。

250 年用例已改用可配置的 `900s` 死循环兜底，每 25 年输出平均 Tick 及人口、动物、尸体、聚落、建筑、实体槽位和寻路队列；固定负载 Chrome 门禁继续承担硬性能判定。最终 3 个种子全部通过，分别保有 `412/144/275` 人，并维持儿童、适龄人口与长者三段代际结构。门禁过程发现采集者在没有野外食物和岸边鱼时空转，导致其中一个种子约 150 年饥荒灭绝；修复为回退到可运行农田后，同一种子恢复到 `144` 人。

2,000 年分层长局 `10/10` 存活，最终人口依次为 `243/376/518/653/242/552/128/417/245/367`。最终 384×384 / 1,000 初始居民 / 约 3 万资源节点的 30 分钟 8× Chrome 浸泡中，30 个逐分钟采样均为 `60 FPS`，最差 P95 `21.9 ms`，最高 Draw Calls `13`、最高三角形 `1,068`，最终累计平均 Tick `0.65 ms`；Tick 推进到 `275,260`，寻路队列从首分钟 `202` 收敛到 `0`。第四批退出门禁全部通过。

## 架构边界

- `src/simulation` 是无 DOM 的确定性模拟核心；地图和实体使用 TypedArray，村庄、王国、建筑和事件使用结构化对象。
- `src/worker` 负责时间倍率、世界法则命令、可转移实体与尸体快照、地图脏单元、资源与领土/规划脏格、语义任务、人口与生态诊断、王国观察、历史按需查询和 V12 序列化；高频模拟状态不进入 React。
- `src/simulation/rules` 提供类型安全世界法则目录和人口、生态、劳动、领土、运行时领域规则接口；具体行为仍由各领域模块实现，不建设万能规则引擎。
- `src/render` 负责 PixiJS 8 WebGL 2D 场景、24×24 渲染 Chunk、三级地形 LOD、像素纹理、插值、分层拾取、覆盖层和即时反馈。地图和资源变化只立即重绘当前可见 LOD，其他 LOD 记录脏标记并在玩家切换层级时补绘。
- `src/App.tsx` 只协调低频 UI、设置、选择、IndexedDB 档案和音频。
