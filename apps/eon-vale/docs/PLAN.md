# Eon Vale 地图优先重构计划

> 状态：P0 阶段 4、P1-1、P1-2 与 P2 全阶段均已通过用户复验并关闭。P3-1 新世界入口已根据首轮反馈重做，正等待用户 Web 视觉复验；P3-2 尚未开始，最终正式美术仍未完成。

## 已确认范围

- 用新的世界数据和渲染链路取代旧居民/文明世界；不迁移旧存档或旧地图。
- 先完成 `1024 × 1024` 的可复现随机像素地图和多层缩放体验。
- 当前不加入居民、动物、房屋或其他建筑。
- 区域视图作为视觉主场，世界与近景分别约束宏观轮廓和局部素材；地图采用原创的方格像素、块状生境、分层海岸与间隙型植被簇。
- 每格自然视觉拆成地貌带、基础生境与环境主题三层；幻想内容只叠加，不替换水陆、高程或自然生态事实。
- 首套自然目录包含深海、外海、浅水、岸缘、低地、高地和山地七级地貌带，包含海洋/湖泊/河流水系和八种基础生境；自然系统完成后只用“腐化”验证一次环境主题叠加。
- 海岸采用 `2–4` 格岸缘、`4–8` 格浅水、四种环境岸型和经过整理的像素阶梯；只让少量高地或山地海岸形成悬崖例外。
- 水面采用远景静态、区域/近景低频动态；湖岸缩窄，基础生境使用块状交错带，高程使用破碎抬升带和岩脊而非渐变或连续围墙。
- 河流按支流、普通河道、主河道和入海口分级；树冠以可见间隙为硬约束，只允许少量前后叠压，不形成连续冠层。
- 植被分布以用户指定的 WorldBox 区域视图为密度标尺：适生区域持续有树，但由不规则林团、空地口袋和地面通道组织，最密处也不封闭地表。
- 八种基础生境已经分别锁定树冠覆盖率区间；植被以 `64–192` 格宏观密度区、`12–40` 格局部林团和 `6–24` 格空地/地面通道组成三层空间结构。
- 地表覆盖物已经按生境分为丰富、普通、稀疏三档；装饰拆成结构细节、环境覆盖物和稀有焦点，并锁定高饱和出现率、材质组留白和主要资源避让规则。
- 三档覆盖物已经锁定材质组出现率与锚点预算；覆盖物以 `2–6` 个材质组为普通斑块尺度，高饱和装饰以 `1–3` 组为小簇，同类稀有焦点至少间隔 `32–64` 格。
- 八种基础生境已确认各自的自然资源主语。每种生境使用三套有环境含义的子材质，素材量按“生境 × 材质族”材质包计算；植被土壤和岩地获得最高变体预算，`24–80` 格地表斑块负责组织主体、次要和特殊子材质。
- 每种基础生境的普通装饰下限为 `12` 个环境覆盖物、`6` 个小型物件和 `3` 个稀有焦点；核心植物与高饱和焦点保持专属，中性物件最多约 `40%` 跨生境共享。
- 地理过渡共享六种几何角色和每种至少三种不规则节奏，但保留各自材质与方向光照；普通装饰在世界视图聚合、区域视图独立显示、近景整数放大，位置不随缩放重算。
- 地貌边界使用八邻域 `47` 拓扑和对角约束；最终像素素材遵守 `1px` 美术网格、`4px` 画布倍数、底部中心锚点和共享色彩角色。
- `47×3=141` 个二值拓扑遮罩与各材质边缘叠层组合，避免按生境对制作全彩图块；terrain tileset 的基础填充、材质组、斑块权重、边界、结构素材和动画叠层职责已经锁定。
- 深海、外海、浅水和四种岸型分别锁定静态与动画素材预算；外海、浅水、岸缘通常形成 `12–32`、`4–8`、`2–4` 格的层级。
- 基础生境过渡采用子材质权重、中性桥接材质和资源替换三步完成，不制作两两专属混合 tileset。
- 地图素材已经分为九类；树木采用幼树、成熟树和老树/高大树三档视觉年龄与多维形态变化，但不加入生长模拟，枯死树木保持独立资产族。
- 八种生境共固定至少 `19` 套专属树木原型；variant 只按真实轮廓和结构差异计数，换色、自动镜像、动画帧和无关噪点不计数。
- 树木除三档视觉年龄外，再使用紧凑、标准和高干三档高度形态，最大普通树画布扩展到 `32×48`；常用装饰类别的真实轮廓下限和人工校准 colorway 数量已锁定。
- 每套树木原型至少 `15` 个轮廓，合计至少 `285` 个活树轮廓；确定性洗牌袋与分类重复冷却负责降低局部重复。
- 美术与程序的职责边界、独立 shadow mask 规则已经锁定；独立 `lod-region` atlas 已取消，区域与近景共享正式 sprite，只有世界视图使用专用 LOD 美术。
- 语义 ID、源文件命名、PNG 交换格式、`2048×2048px` atlas 页、padding、裁切元数据和禁用缩放/抗锯齿/mipmap 等打包规则已经锁定。
- placeholder 与正式 tileset 通过语义资产 ID 和视觉 manifest 解耦：稳定尺寸族、锚点、占地、层级与动画状态，允许更换文件和重新打包 atlas，不改地图生成算法。
- 地表材质族与基础生境正式分离；水体采用静态 tile、美术动画叠层和受限像素级程序效果，普通树木与地标保持静态，仅水面、岸浪、流纹和少量植物/腐化焦点动画。
- 运行时 atlas 按地表、过渡、水体、植被、地面装饰、地标、效果和世界 LOD 分类，并全部由 manifest 映射。
- placeholder 已分为 P0 契约占位、P1 温带与完整水岸/高程/腐化视觉切片、P2 八生境全覆盖三档；正式美术接入时保持地图事实、物件位置和确定性种子不变。
- visual manifest 的语义、画布、锚点、占地、净空、层级、溢出、palette、shadow、动画、LOD 和 schema version 必填元数据已经锁定。
- palette library 的全局结构色、水体色、生境地表/物件色和环境主题强调色预算已经锁定；新颜色必须先登记到命名 palette。
- 新资产必须同时通过自动契约检查与 `1×/4×` contact sheet、密度重复、完整过渡、跨 LOD 和四组视觉验收板检查。
- 地图运行时已经收敛为“模板 + 种子 → 内存中的完整只读 snapshot”：不提供地图编辑、保存或加载，选择新模板会重新生成并替换当前世界。
- 生成任务只在 Worker 中产生地图事实，loading 展示真实阶段进度，成功后一次性提交世界；视觉派生在主线程分帧并按 snapshot、视觉目录、`64×64` chunk 和 LOD 缓存。
- 首轮桌面性能门槛已锁定为 `1.5s` 可信反馈、`5s` 世界可用、`150ms` 可见细化、稳定 `60 FPS`/P95 `≤25ms` 和地图自有内存 `≤256MiB`。
- 项目正式发布前不承担旧地图、旧生成器或旧 visual bundle 兼容；上线后的存档与兼容政策以后单独决策。
- 首版世界入口锁定八种原创宏观模板和已有世界时的替换确认；模板不固定 biome 组合。普通玩家默认 UI 不展示 seed，选择模板时由系统生成新的随机 seed；seed 仍保留在权威 snapshot、失败重试和开发调试入口中，以维持确定性、复现与诊断能力。
- loading 使用独立全屏真实进度状态并允许取消，不显示旧世界或半成品；其正式像素美术与过渡仍需单独设计。
- visual bundle 采用完整校验后的原子替换，失败时保留上一有效目录或回退内置 P0；LOD 使用迟滞和短交叉淡化，详细 chunk 采用受内存预算约束的距离/方向/最近使用混合淘汰。
- 源码 visual bundle 已按职责命名为 `MapVisualContractBundle`、`TemperateMapVisualBundle`、`WetHotMapVisualBundle`、`DryMapVisualBundle` 与 `ColdMapVisualBundle`；阶段代号不再承担运行时语义。既有生成 atlas 的存储路径暂不迁移，不影响资产契约或整体替换 seam。
- snapshot 的最小权威字段、按 chunk 排序的稀疏物件、水系逐格事实和生成期噪声丢弃规则已经锁定；斑块、植被簇和水体不建立长期对象。
- `WorldRulesCatalog` 与 `VisualCatalog` 已形成独立 seam，资产导入负责交叉验证语义族、尺寸、锚点与占地，生成器不读取 atlas。
- `RenderChunkPlan` 的八层紧凑批次、Pixi 纯执行职责、统一视觉时钟与失败重试语义已经锁定。
- Worker 使用 transferable 单向交出 snapshot，`MapSession` 保持 React 低频状态，地图生成与视觉目录并行通过就绪门；过期任务不进入会话。
- 静态地表采用 chunk texture，直立物件采用可见 sprite batch，世界视图采用独立 `1024×1024` texture；区域与近景共享视觉缓存。
- `MapCache` 统一执行 `256MiB` 预算、距离/方向/LRU 淘汰和 GPU 释放；projection 与上传在交互/静止时分别服从约 `4ms/8ms` 分帧预算。
- 八模板目录作为内部类型化规则数据，不建立 JSON、用户模板或 mod seam。
- 世界内 visual bundle 使用完整预备后的原子交叉替换；固定 seed/checksum/结构不变量、projection golden/属性测试和 renderer 资源/浏览器视觉验证组合已经锁定。
- 性能降级只影响预取、动画频率和不可见缓存，任何可见事实与像素清晰度都不可降级；P0/P1/P2 性能失败直接阻断推进。
- 新 P0 垂直链路切换应用入口后立即删除旧 SVG、loaders 和旧 renderer，不保留双运行时；后续依次完成地图层、P1 切片和 P2 八生境。
- `MapSession` 状态机、WebGL2/DPR 像素基线、Pixi 相机所有权、地图命中摘要、公开错误类别和 `src/map` 唯一公共入口已经锁定；长期 seam 记录于 [`ADR 0002`](./adr/0002-separate-map-facts-from-visual-projection.md)。
- 中型与大型环境地标已经锁定密度、降密度区和跨层级表达；遗迹仅作为无文明归属的环境残迹。
- 腐化以受限地表叠层和部分资源替换验证环境主题，不得遮蔽基础生境；最终视觉使用世界总览、生境区域图、生境近景图和过渡图集四组截图验收。
- 视觉尺度固定为世界视图自动适配约 `0.75–1px/格`、区域视图 `4px/格`、近景 `16px/格`；逻辑世界继续使用 `1024 × 1024` 世界格。

## 已完成

### P1-2 地图结构视觉切片——已验收完成（2026-08-23）

- 固定 `continent + 0x1a2b3c4d`，分别锁定 chunk `180/118/166` 作为草原/林地交错、高地/山地抬升和温带侵染前沿验收镜头；运行时目录升级为 `p1-structure-1`。
- `RenderChunkPlan` 新增 biome bridge、高程带、环境主题带与权威 elevation/theme 投影列；所有派生只影响视觉，仍保留原始 biome、landform 和水系事实。
- 草原/林地边界使用两侧各 `2–6` 格、总宽约 `4–12` 格的量化交错带和 `4×4` 材质组舌形穿插；交错区停用单线过渡描边，不创建混合 biome。
- 代表模板加入受控山核，固定世界实际包含低地、高地和山地；岩地使用独立基础、碎石叠层和 `16×16px` 岩面组，高地/山地物件密度降为低地的受控比例，避免山体继续铺满树林。
- 腐化由连续噪声扭曲的不规则陆地焦点生成，不再使用 `32×32` 方块；侵染限制在海岸以上陆地，并以底色混合、稀疏裂纹和可替换 effect asset 表达，不改下层地理。
- 浏览器 smoke 覆盖世界、区域、近景、三个固定结构镜头和 structure debug；可见 9 chunk 原子细化继续满足 `≤150ms`、P95 `≤25ms`，无控制台错误、资源失败、黑屏或 chunk 接缝。
- 快速拖动或切换到未缓存视口时，不再先撤下整套详细层。renderer 保留上一套完整详细 chunk，并同时保护旧/新集合免于 LRU 淘汰；目标视口完整后再原子交换。浏览器逐帧回归门禁要求后台仍有 chunk 构建时，已提交的详细覆盖数量不得归零。

### P1-1 温带海岸首批视觉资产——已验收完成（2026-08-23）

- 固定 `continent + 0x1a2b3c4d + chunk(640,256)` 作为生成器版本 7 的 P1 温带海岸验收场景；测试锁定浅水、岸缘、草原、林地和对象数量，不再依赖动态“代表性 chunk”。
- 新建完整可校验的 `p1-temperate-coast-4` visual bundle。它保持全部语义 ID 和 atlas 契约，但使用独立 `map/p1/` PNG 页与新的温带/水岸 palette。
- 首批原创运行时素材包含 `40` 个植被土壤 tile/group/overlay 插槽、深海/外海/浅水/岸缘四类水岸素材、草原 `2` 套与林地 `4` 套树木原型的 `48` 个年龄/高度组合，以及常见温带覆盖物、岩石和枯木轮廓。
- 树木从 P0 竖条替换为带树干、分枝、体块树冠、左上高光和年龄/高度差的底部锚定 sprite；最密区域仍保留可见株间地面。
- 水面和沙岸的逐格横向条纹已从程序根因修正：水效改为确定性稀疏短纹，地表基础纹理降低逐格噪声。
- 内部原创方向板、精确 `4×` contact sheet 和浏览器世界/区域/近景验收图统一记录在 [`visual/p1/`](./visual/p1/) 与 `output/p1-acceptance/`。
- 该阶段只完成第一批温带资产。其他六种生境、大型地标、腐化和完整高程视觉仍使用 P0 合同占位或尚未开始，不能表述为 P1 全部完成。
- 用户首次复验确认树木轮廓与间隙方向通过，但指出冷启动世界→区域 LOD 明显掉帧，温带地表平、硬且边界描线过强。整改后 `VisualCatalog` 改为按规范化视觉查询缓存候选集，详细 chunk 改为像素缓冲合成后单次上传，并把预取移出可见细化门禁；当前降噪材质版浏览器冷启动实测可见细化约 `59.3ms`、P95 帧时约 `15.8ms`，满足 `≤150ms` 与 `≤25ms` 门槛。
- 用户再次指出 v2 只有底色和微噪点，不能称为完成的草原/林地材质；该判断已接受，原完成表述撤回。v3 加入跨 chunk 连续的 `19/46` 格量化色调场、透明不规则 `16×16px` 材质斑块、低频草叶/落叶/枯草/裸土叠层，以及湿沙、主体沙、内侧沙丘三带。新建“地表”验收模式隐藏全部物件，防止树木遮蔽地表缺陷。
- v3 首轮又暴露砂纸噪点与棕斑过量，已在同轮浏览器迭代中压低叠层频率、降低枯土 variant 权重并改为橄榄色环境斑块。材质组轮廓进一步改为由多个椭圆融合形成的圆润像素团块，以阶梯边缘、少量缺口和大片留白保持自然感，禁止抗锯齿模糊与规则圆斑。v4 进一步将固定无树地表的高频边缘占比从 `12.06%` 降至 `3.01%`，低于 `5%` 门禁；用户已于最终页面复验后确认 P1-1 可以结束。

### 新地图 P0 阶段 4（2026-08-23）

- 将阶段 3 的固定代表性 chunk 替换为真实视口调度：区域与近景会计算全部可见 `64×64` chunk，并按中心优先逐帧构建一圈预取；未完成时继续显示世界概览，不出现空白。
- 新增受保护的 LRU chunk 缓存。当前可见 chunk 不可淘汰，renderer chunk 子预算为 `192MiB`，为世界 texture、共享 atlas 和运行开销预留其余地图预算；淘汰时同步销毁独占 GPU texture/source。
- `RenderChunkPlan` 已包含基础地表、`16×16px` 材质组、47-mask 生境/材质/地貌过渡、低矮覆盖物、shadow、直立物件、foreground 与稳定排序键；Pixi 只执行 visual handle，不重新读取生态规则。
- 世界视图加入确定性树木像素聚合；区域与近景共享同一批静态 chunk texture 和物件 sprite，近景只做最近邻整数感放大，不再切换到空层。
- 水体保持 tile 基底，并叠加只作用于可见 chunk 的低频相位效果；统一视觉时钟不修改地图事实。
- 完整可见 chunk 均支持 autotile debug，原有 biome、terrain 与 chunk boundary debug 保留。
- renderer 内部手势产生的 world/region/close LOD 会回报 `MapSession`，页面状态与实际 Pixi 层不再分叉。
- 物件投影首次覆盖全视口后暴露并从生成根因修正三类事实错误：禁止“幼树 + 高干”无素材组合；带地貌限制的资源只能生成在允许地貌；普通/少见/稀有装饰按权重抽取，稀有自然地标保持 `32–64` 格间距。
