# Eon Vale 地图沙盒

Eon Vale 是一个让玩家生成、观察和编辑原创像素世界地图的桌面浏览器沙盒。首版只建立清晰、可缩放且可复现的地理世界，不包含生命或文明模拟。

## 地图

**世界地图**：由固定网格表示、以种子可复现生成的地理世界。
_避免_：无限世界、静态背景图、旧世界

**世界模板**：在生成前选择、用于约束大陆数量、海陆比例、连通性和海岸结构等宏观地理的世界类型；它不固定具体地图或生境组合。
_避免_：预制地图、当前 seed 预览、biome 配方

**种子地图**：由一个世界模板与 seed 确定性生成、只存在于当前浏览器会话中的完整只读地图。
_避免_：存档地图、可编辑地图、随机视觉背景

**世界格**：世界地图中承载一份地理事实的最小空间单位；它描述位置与环境，不规定玩家最终看到多少像素。
_避免_：地表图块、贴图像素、物件帧

**地表图块**：用于表现一种地表材质的可重复像素单元；它把世界格翻译为视觉纹理，但不承载树木、岩石等独立物件。
_避免_：世界格、完整生境、地图物件

**材质组**：由相邻地表图块共同形成、用于控制局部色块与纹理节奏的较大地表单元。
_避免_：独立大图、随机图块集合、地图物件簇

**子材质**：同一基础生境内由湿度、遮蔽、裸露程度或地表基质区分的地面材质状态；它有环境含义，但不构成新的基础生境。
_避免_：随机换皮、独立生境、纯调色变体

**地表材质族**：按地面构成区分、可被多个基础生境采用并定制的材质类别，例如植被土壤、裸土、沙、泥、岩地、雪或冰。
_避免_：基础生境、纯颜色标签、环境主题

**材质包**：一个基础生境对某个地表材质族的完整美术实现，包含基础变体、材质组模板和静态地表叠层。
_避免_：通用调色板、完整 biome、terrain atlas 页面

**地表斑块**：跨越多个材质组、用于组织同一基础生境中主体、次要和特殊子材质比例的区域级地表结构。
_避免_：逐格噪声、基础生境、覆盖物斑块

**地表叠层素材**：叠加在基础图块之上的低矮像素形状，用于表达局部磨损、湿痕、风纹等地表状态，不作为独立地图物件。
_避免_：地表覆盖物、结构细节、可选物件

**低矮覆盖物**：具有独立语义资产 ID、但没有显著直立高度的地面 sprite，例如草簇、花、苔藓、蕨或碎石。
_避免_：地表材质、地表叠层、灌木

**小型直立植被**：使用底部锚点并具有可读直立轮廓的小型植物 sprite，例如灌木、芦苇、仙人掌或宽叶植物。
_避免_：低矮覆盖物、树木、地表材质

**树木原型**：共享冠形和树干造型语言、并具有幼树、成熟树、老树等视觉年龄素材的一套生境专属树木资产。
_避免_：单张树木 sprite、植物学物种、生长模拟状态

**高度形态**：独立于视觉年龄、描述树干长度与树冠纵向比例的树木造型标签，包括紧凑、标准和高干；它不表示动态成长。
_避免_：视觉年龄、树种、生长阶段模拟

**物件帧**：地图物件的一种独立像素轮廓，采用底部锚点放置在世界地图上。
_避免_：世界格、地表图块、地图物件实例

**视觉 variant**：在区域视图具有可辨认轮廓、主要像素簇、比例或姿态差异的独立素材造型；换色、动画帧和自动变换不增加其数量。
_避免_：colorway、动画帧、shader 相位

**Colorway**：由美术预先校准、在同一真实轮廓上使用生境局部 palette 形成的颜色版本；它用于降低重复感，但不算新的视觉 variant。
_避免_：随机 HSV 染色、季节状态、独立轮廓

**重复冷却**：在确定范围内暂时排除最近使用的相同视觉 variant 或 colorway 组合、同时保持种子可复现的素材选择约束。
_避免_：非确定性随机、自动镜像、永久禁用素材

**Shadow mask**：与主体 variant 共用原始画布和锚点、由美术绘制的独立落地阴影形状；程序只负责在主体后方着色显示。
_避免_：主体自阴影、模糊投影、程序轮廓生成

**资产契约**：地图语义标识与视觉资产之间保持稳定的尺寸族、锚点、占地、层级和动画状态约定，使占位素材和正式素材可以重新打包并整体替换，而不改变地图生成规则。
_避免_：具体图集文件、生成算法、美术制作者

**语义资产 ID**：由地图事实和视觉角色确定、与文件名及 atlas 坐标无关的稳定资源标识；视觉 manifest 将它解析到当前 tileset。
_避免_：枚举行号、atlas 槽位、PNG 文件路径

**地貌带**：由水陆关系与高程决定的基础地理区域，例如深海、外海、浅水、岸缘、低地或高地。
_避免_：基础生境、环境主题、地图物件

**水域层级**：海洋与大型湖泊按视觉深度组织的深海、外海和浅水三个水体地貌带；岸缘属于陆地过渡，不属于水体层。
_避免_：颜色变体、浪线、河流等级

**水系**：由海洋、湖泊与河流组成的连续水体网络；水系决定水体连通关系，地貌带决定具体位置表现为深海、外海、浅水或岸缘。
_避免_：蓝色装饰线、单一海洋背景、地表覆盖物

**岸缘**：水体与陆地相接的过渡地貌带，其表面可以是沙、石、湿地或冰，而不固定等同于沙滩。
_避免_：统一沙圈、浅水、基础生境

**岸型**：岸缘依据相邻基础生境与局部高程采用的材质类别；首套岸型为沙岸、石岸、湿地岸和冰岸。
_避免_：独立生境、纯调色变体、每种生境一套海岸

**悬崖岸**：高地或山地直接临水形成的少量岸缘例外；它可以缩窄或中断普通岸缘，但仍保留浅水和浪线。
_避免_：所有石岸、高地生境、无过渡的陆水切口

**基础生境**：由气候与生态条件决定、可与不同地貌带组合的自然环境事实；它影响地表色族和植被适宜性，但不等同于树木集合。
_避免_：地貌带、地表生境、森林贴图、装饰色块

**环境主题**：叠加在自然地理之上的幻想环境表达，例如腐化或魔法侵染；它改变视觉与分布规则，但不抹掉下层地形事实。
_避免_：基础生境、独立世界、纯调色滤镜

**侵染前缘**：环境主题从未受影响区域进入受影响区域时形成的不规则过渡带；它改变部分地表与资源，但保留下层地理连续性。
_避免_：基础生境交错带、硬直边界、全屏滤镜

**地图物件**：由一个世界格锚定、但视觉轮廓可以跨越多个世界格的独立环境对象，例如树木、灌木、岩石或矿簇。
_避免_：单格贴花、随机杂物、居民、基础生境

**环境地标**：占据明确区域、用于塑造局部构图焦点的大型自然或幻想对象，例如遗迹、巨树、洞口或陨石坑。
_避免_：城市、普通地图物件、远景装饰色块

**地表覆盖物**：与地图物件并存、不可选择的低矮地表细节，例如草簇、野花、蕨、落叶、沙丘草和海岸碎石。它服从生境与地理条件，不能作为“树木数量”的替代品。
_避免_：可选单位、树木变体、全地图随机撒点

**覆盖物斑块**：跨越若干相邻材质组、由同一生境条件组织起来的地表覆盖物组合。
_避免_：逐格随机撒点、标准圆形噪声斑、独立生境

**结构细节**：依附岸线、河道、高程边缘等既有地理结构，用来加强其形状和材质关系的装饰表达。
_避免_：随机撒点、独立地貌、环境覆盖物

**结构过渡几何**：海岸、河岸、高程边缘和生境交错共同使用的边界拓扑角色，包括直边、内外角、末端、狭窄通道和孤立小块；它不规定具体材质。
_避免_：通用边缘贴图、机械旋转、基础生境材质

**边界拓扑**：由一个位置与八邻域的连接关系确定、并要求对角连接受相邻正交方向约束的边界几何事实。
_避免_：生境材质、atlas 坐标、随机边缘造型

**拓扑遮罩**：只描述两种材质在一个边界位置如何覆盖的二值像素形状；它可与不同材质边缘叠层组合，不携带具体生境颜色。
_避免_：全彩过渡图块、高程断面、浪花素材

**稀有焦点**：以低出现率为局部区域提供视觉重音的自然或幻想装饰，规模小于环境地标。
_避免_：普通覆盖物、大型环境地标、遍地重复资源

**构图净空**：为保持地理边界、物件轮廓和地面通道清晰而禁止或限制次要装饰进入的区域。
_避免_：碰撞体、空白地图、固定方形边框

**视觉验收板**：由世界总览、生境区域图、生境近景图和地理过渡图集组成的固定截图集合，用于跨素材与缩放层级判断地图是否符合视觉规范。
_避免_：单张宣传图、带界面截图、只检查近景素材

**植被簇**：共享局部分布趋势、但每株仍保留可见间隙的植被组合。
_避免_：连续树冠、均匀铺满、彼此碰撞的树墙

**树冠覆盖率**：区域视图中树冠不透明像素占适用陆地区域的比例；它用于约束生境核心的植被密度区间，不代表树木锚点占格率。
_避免_：树木数量、锚点密度、连续冠层比例

**植被空间层**：共同塑造植被分布的三种尺度，包括宏观密度区、局部林团，以及从林团中保留的空地与地面通道。
_避免_：单层噪声阈值、固定圆斑、规则种植网格

**生境交错带**：两个基础生境在边界附近以明确归属的块状图块与资源互相穿插形成的过渡区域。
_避免_：颜色渐变、硬直分界、归属不明的混合生境

**桥接材质**：在生境交错带中被相邻双方共享或作为中性地表出现、用于建立连续视觉关系的材质族。
_避免_：混合 biome、新地貌带、单格渐变边线

**抬升带**：低地、高地或山地之间由破碎边缘、岩脊、碎石坡和局部阴影共同表达的高程过渡区域。
_避免_：单纯换色、连续围墙、平滑高度渐变

**观察层级**：同一世界事实随缩放改变表达精度的规则；世界视图使用像素点和区域色块，区域视图显示简化的独立物件，近景显示完整物件轮廓。
_避免_：不同地图、随机删物、压缩同一张素材、仅相机倍率

**旧世界**：本次重构前含居民、动物、建筑、聚落、文明与其模拟链路的产品和数据，不属于新产品的兼容范围。
_避免_：迁移源、保留功能、当前世界

**旧原型资产体系**：当前以枚举行序绑定四张 SVG atlas 的地图素材与加载约定；其帧布局、美术、数量和映射均不进入正式资产体系，也不要求兼容。
_避免_：placeholder tileset、正式 tileset、资产契约

**Placeholder tileset**：完整遵守语义 ID、尺寸族、锚点、占地、层级、动画和 manifest 契约、但不承担最终美术质量的临时地图素材包。
_避免_：旧原型资产、正式质量基线、随意占位图

**Visual manifest**：把稳定的语义资产 ID 与当前 atlas 帧、画布、锚点、占地、palette、shadow、动画和 LOD 元数据连接起来的版本化资产清单。
_避免_：地图生成规则、枚举行号、固定 atlas 布局

**Palette library**：以命名色盘维护全局结构色、水体色、生境局部色和环境主题强调色的视觉资产集合。
_避免_：单一全局索引色盘、程序任意 HSV 染色、未登记临时颜色

**Contact sheet**：将同类素材以固定网格同时展示原生 `1×` 与最近邻 `4×` 的验收图，用于比较轮廓、比例、受光、色阶和重复感。
_避免_：游戏截图、宣传拼图、缩放后模糊预览

**资产导入门槛**：新 placeholder 或正式素材进入运行时 atlas 前必须共同通过的机器契约检查与视觉验收。
_避免_：主观单图确认、仅检查文件能否加载、事后修补 manifest
