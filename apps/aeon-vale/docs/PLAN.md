### 具体画面与流程目标

| 对象 | 调整目标 | 验收关注 |
| --- | --- | --- |
| 草原 | 清楚的草绿底色与连贯的深浅草甸；少量成簇短草、野花和疏树，留出可读空地 | 缩远仍能看见草甸而非花点；去掉植被后土地自身有层次 |
| 桦木林 | 明亮的黄绿草底、局部苔草与淡落叶痕；白桦树干和树冠成为主体，树下细节降低对比 | 与深色温带林相接时边界自然，白桦轮廓清楚，底纹不抢树木 |
| 热带草原 | 暖黄草地、局部干土与成片偏绿湿润草带；疏落金合欢及低矮草簇 | 避免均匀黄点或重复斜线铺满，干湿区域和树间空隙一眼可辨 |
| 其他生态、岸带与山地 | 协调其余生态的颜色和细节密度，保持浅岸、海水与山地的层级；幻想生态的高亮集中在特色区域 | 同图远中近景统一，不把裸岩山地变成可播种土地，不重生成旧地图 |
| 晴天浮云 | 少量、不规则像素轮廓和几层浅蓝白云块，地面可透见；独立错位云影，平滑缓慢经过，近景逐渐变淡 | 浮云不触发雨或催熟；移动不使地表缓存失效；世界时间与存读档连贯 |
| 建图 | 左侧选中模板的固定缩略图、名称、植被与河流；右侧模板/尺寸或细调页；底部固定创建与返回 | 模板图即点即换，参数不触发地图生成；无“正在描绘”和换图案按钮；返回细调前后值保留 |

建图缩略图随游戏附带，运行时读取，不在启动或选图时重新生成完整世界。示意图不承诺具体海岸一致；点击创建时取得新的随机图案，配置值全部应用到真实生成。加载过程显示实际进度并防止重复创建；取消或失败时不能丢失原世界。

新绘法直接用于旧图。植被换代只处理真实死亡或不适生对象，不为统一美术而删除健康植被；新生成与后续补生使用协调后的植被疏密。浮云沿用自然天气的控制语义：关闭后停止自动生成，已存在天气按其剩余寿命结束；浮云状态需随世界保存，没有浮云记录的旧档从无活动浮云开始。雨云既有降雨节奏与灭火规则保持。

改前已用隔离场景复现旧枯树阻挡树肥和自然树苗被草花挡住；实现后新增检查覆盖这两类根因。旧档升级 v9 时保留地图、植物生命及枯木消解进度，首次覆盖保留原版本备份，缺少浮云记录的旧档从无活动浮云开始。1x 改后 15 秒样本最大 27.054 ms，超过 33.333 ms 为 0；普通移动缩放 2,700 帧有一帧超过 33 ms，5x 云层与集中施肥压力样本最大 56.357 ms，未宣称消除了全部长帧。

### 改前事实与复现

GitNexus 索引仍为 2026-09-02，未覆盖本游戏，按当前源码审计。隔离诊断脚本为 `test-output/audit09-fertilizer.gd`，Godot 无头运行退出码 0，没有操作玩家存档。

- 草原存在树种；`world_data.gd` 主动树肥却沿用自然萌发的双偶数坐标及固定哈希落点。32×32 全空适生草原、种子 98417：1,024 格中 768 格因网格排除，另有 180 格因固定疏密筛选排除，只有 76 格可催生。一个适生空格重复 20 次施肥仍为空。
- 低矮草花占用单一植物位置，树肥不会替换；在本可长树的位置先放草再施肥，草仍存在且该点被判无效。截图 3 的具体位置缺少存档对应，不能宣称已精确复现该截图，但上述两类无反应可稳定复现。
- 蘑菇林目录全部不属于当前树类，树肥整区结果为 0 株。原 `feedback.gd` 只检验已经出生的植物类型，没有断言每类适生空地至少产出一株，因此漏检；本轮必须补充非空产出验证。
- `collect_cast` 对适生土地上因占位或固定密度被拒绝的位置直接跳过，缺少可见反馈。预览使用同一筛选，导致名义作用区大部分变暗、呈碎格。
- 当前雨只对已有火焰的地块有效，无火地面不会生成雨事件。现有雨线是短暂命中效果，没有自然天气、云影和保存中的雨云状态。
- 山地是独立噪声高度的插值和分档颜色，雪由阈值铺成斑块；没有明确峰顶和岩壁方向，且表面噪声与生成山脉用的高度场不同，造成柔软色环状团块。
- Esc 当前在无神力时会退分类或请求主菜单，不会直接进入设置，确实与新要求不符。
- 组合压力测试进一步发现：镜头移动时，连续施肥逐格重复盖完整笔刷，叠加预览逐格邻域判断，出现 444.806 ms 长帧。改为固定现实时间节奏、保留转折的连续路径合并、按距离重叠盖印、整片占位遮罩与预计算排序后，同类组合样本最大降至 72.796 ms；详细方法和限制见本轮验证记录。

### 第五轮源码审计事实

### 实施前的 0.2 核对与原因

- [全图贴合与距离分档](../scripts/world_view.gd) 按绝对缩放值分档，远景只换成低分辨率植物纹理，仍使用相同世界矩形。需要以实际观察覆盖范围形成概览表达，并检查三档地图尺寸；不能让小地图点击俯瞰后仍保留中景树形。
- [工具选择与速度](../scripts/game.gd) 当前只有原按钮金边，未实现独立选中面板；速度入口是播放图标，只有 1→2→5 循环。已有生态时间倍率可复用，缺口在沙漏交互、3x/4x 和选中状态关系。
- [悬浮绘制](../scripts/world_view.gd) 当前只有空心圆与中心短线，缺少图标、填充与有效性区分。预览应复用实际作用规则，避免看似有效却不生效。
- [当前地表](../scripts/world_data.gd) 每格为 4×4 的程序纹理；[当前植物](../scripts/pixel_flora.gd) 由程序逐像素绘制，已替换首版生成图片。十八种植物虽然都有三个变体位置，但部分形态没有实际轮廓差异。画面不足不能只归因于生成图片尺寸，应同时解决地表结构、邻接、植物轮廓与细节密度。
- 已有七类生态及专门的海水、沙滩和山峰适生规则，需要丰富物种组合并保持自然生长一致。扩充物种要同步图集、工具目录、自然更新和存档合法编号；不通过改名或换色把同一种植物计成多个物种。

### 已确认的交付方案

1. **缩略远景**：同一世界缩到概览时，植被收为细密色点和林地斑块，弱化单棵树干与小草；岛屿、近海、沙岸、山脉和生态分布成为主要信息。地图四周保留海洋空间，中近景逐步展开真实树形和地表细节，位置与生态状态不因缩放变化。
2. **选中与预览**：工具栏上方偏左常驻当前神力面板，图标与原工具按钮同步；× 取消后回到观察。地图鼠标附近显示神力图标与半透明作用区域，有效范围和实际施法一致，无效格灰暗。切换工具替换当前神力；仅浏览分类保留当前神力，进入界面区域隐藏地图预览。
3. **时间选择**：沙漏展开五个整数档位 1x–5x，当前档位高亮，选择后收起；不替换施法工具。关闭时间面板保留速度，暂停时调档仍保持暂停，恢复后使用该档位。
4. **地表美术**：海水做水深色层与有节制的水纹；沙岸做湿沙、干沙和零散细节；草地做连续自然斑块与局部草花；丘陵表现坡面、岩石与植被关系；山峰表现山脊、背光面和积雪。采用统一光向与像素尺度，避免均匀噪点、重复方块和仅在植被遮挡时好看；包含隐藏植被的单独地表验收。
5. **植物丰富度**：目标至少 48 种可区分植物，其中至少 24 种树木，其余为灌木、草花、蕨类、菌菇等；分布到现有七类生态并遵守沙滩、丘陵和山峰的适生条件。每种至少三种实际轮廓变化，生长阶段另算；成熟、幼苗、衰老和枯死继续可辨。具体物种及造型由开发方设定，植物工具按生态和用途分组浏览。

先制作能在游戏里观察的地表与植物样区，再接入全地图和自然生长，以实际远中近景画面修正素材；素材图集预览不代替游戏验收。现有生命周期、改地转枯、肥料用途、存读档和撤销保持一致。王国、生物和灾害仍为后续阶段。

### 改造前事实

- 当前底部默认进入世界塑造，另有自然和世界管理页签，不具备主工具栏与分类工具栏的两级结构；切分类已保留神力，可复用这个行为。
- 顶栏包含名称、保存状态、悬停地块信息、距离提示及镜头和帮助按钮；右侧混合面板包含笔刷、撤销/重做、植物显隐与时间/植物统计。撤销/重做还存在快捷键和帮助引用，不能只隐藏两个按钮。
- 地图滚轮缩放、右/中键拖动以及观察状态左键拖动独立于顶栏按钮，可继续使用。移除顶栏需同时释放世界视图的顶部空间。
- 目前没有设置页、全屏控制、界面大小控制或偏好保存；“操作”只是帮助。新增设置必须产生实际效果，不能把旧帮助入口改名充当设置。
- 存读档已有三个本地槽位和必要的覆盖/未保存确认；本轮重组入口与视觉，不重新设计存档容量或扩展世界规则。
- 现有 `dawn.png` 是像素谷地插画，工具图标主要为小尺寸程序像素绘制，植物工具直接取地图图集。现有资源没有可直接套用的二次元界面；仅替换主题颜色不足以达到新目标。

### 已确认的交付方案

以下为 Q1–Q4 已确认决定的设计展开。具体控制归位为：笔刷大小放在当前神力面板内，未选神力时随面板隐藏；名称、保存状态、年份和植物统计移入主工具栏信息区；主工具栏的观察入口展开俯瞰/中景/近景及植物显隐；设置提供全屏、界面大小与操作帮助。顶部状态栏和原右侧混合面板移除，撤销/重做按钮、快捷键与帮助说明一起移除。返回主工具栏保留神力，× 取消；沙漏继续独立控制 1x–5x，保留神力与暂停状态。

1. **主工具栏与分类工具栏**：主工具栏集中世界管理与信息；分类页签位于底栏上沿，进入分类后用分组双排神力填充内容区，左侧提供返回。暂停与沙漏的位置跨状态保持稳定，当前神力独立于工具栏导航。世界管理从分类内容归入主工具栏；本阶段只呈现已实现的世界塑造与植物自然工具，不用空按钮代替后续文明或灾难。
2. **森系幻想绘本**：以象牙白的纸页/瓷质表面、鼠尾草绿、深森林色文字和香槟金细节形成层次；叶片、种子、星芒与魔法纹样用于少量关键位置。面板、页签和按钮重新设计轮廓、边饰、留白和明暗，避免沿用现有深绿矩形框只换颜色。
3. **统一图标与反馈**：工具使用统一的插画式图标与清晰轮廓，维持地形、物种及肥料的识别；不同用途通过图案区分。正常、悬停、按下、选中与不可用状态均有明确表现，选中同时使用边框/徽记，不能只靠色差；动效短促，不遮挡地图。当前神力、沙漏选项、观察浮层和提示也使用同一套表面与边饰。
4. **启动与加载**：使用原创幻想山谷插画，保留纪元谷与 Aeon Vale 的品牌识别；标题、按钮和加载组件使用相同字体与装饰语言。加载以种子/叶片的生长作为视觉意象，显示真实准备与生成进度，并保持窗口响应。
5. **新建世界与其余弹窗**：新建世界统一插画、地图模板卡、选择态、参数控件与确认按钮；保存/加载、设置、帮助和确认弹窗一起重做，保留已有地图参数和有效存读档行为。界面尺寸变化时，控件、文本与分组仍可读、可点，不遮住关闭或返回入口。

具体尺寸、字形搭配、纹样、图标造型与动画节奏由开发方在已选方向内设定，不继续拆分用户已授权的美术细节。验收需要主工具栏、两类分类工具栏、当前神力/沙漏、标题、加载、新建世界、存档及设置的实际运行截图与输入验证；现有地图和植物生态规则继续回归，不能以概念图代替运行结果。
