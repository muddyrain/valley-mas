# ADR 0005：雨云使用世界时钟，主动落雨独立反馈

状态：已采纳。日期：2026-09-06。依据：第九轮 Q1、Q2、Q5 已确认。

玩家要求自然降雨与雨神力都有局部天气效果，并保留暂停时主动施法立即有结果的规则。如果整片雨云按现实时间运行，暂停后仍会移动和灭火；如果所有效果只跟随世界时间，暂停施法又缺少即时反馈。

因此初次施法立即按笔刷区域灭火，播放短暂的现实时间雨线；同时创建持续雨云。持续雨云的位置、寿命和灭火由每世界秒更新推进，暂停时冻结，倍速同步加速。自然天气每隔 60–180 世界秒产生局部雨云，每片持续 10–20 世界秒，雨不改变植物成长速度。设置关闭自然天气只停止新增自动雨云，不移除已有雨云，也不禁止雨神力。

存档升级到 v7，保存天气开关、下一次降雨倒计时、随机序列计数和活动雨云。继续接收 v1–v6，旧档使用默认开启的自然天气、120 世界秒的初始倒计时及空雨云列表，不补算旧年份。首次覆盖旧文件前保留原始字节备份。JSON 写出保留浮点精度，使云的位置和速度在读写后保持连续；加载时校验字段类型、数值范围、笔刷和最多 12 片云。

云影只使用缓存纹理；活动云最多 12 片，单帧雨丝预算最多 420 条，视野外跳过，避免云数量带来无上限绘制。即时反馈无需存档，因为世界结果已完成。持续雨云必须存档，读档后从原位置继续。测试分别覆盖即时灭火、暂停、移动中的灭火、自然生成、开关、到期、无生长加成及保存后的确定性推进。
