# 生态扩散遵守局部环境，并作为世界规则保存

2026-09-06 用户在第七轮 Q3–Q6 确认，18 类生态可以改变相邻土地，包括玩家播种的生态，但竞争应受当地环境约束并缓慢推进，以获得会演化的世界，同时避免单一固定强势生态快速抹去多样性。扩散开关属于世界状态，新世界默认开启、旧存档首次加载默认关闭，关闭仅冻结生态边界，以保留既有创作和植物生命过程；开关随世界保存，旧地图、年份与生命阶段不能因加入扩散而重生成。

0.7 用持久保存的冷暖、湿度与高度场评估当地适生度，只考虑四邻相接的土壤和丘陵。每个边界位置约十二世界秒参与一次竞争，单次变化先计算再统一应用；不让遍历顺序在同一步形成整片连锁推进。随机判断由种子、位置与生态时钟决定，读档后续演化可复现。关闭期间不累计待扩散次数。v6 保存环境和开关，v1–v5 根据现有生态补足环境，保持关闭且不改原地图。

视觉更新在后台读取独立快照，按受影响地块和缩略图小片区绘制，再由主线程发布图像；发布后的图像不再由工作线程修改。缩小片区时保留相邻像素，避免每次交融都重新缩小全图。该缓存只影响绘制，存档与生态判断仍以完整世界数据为准。

0.8 在第八轮镜头卡顿反馈后，将边界竞争分散到十二个世界秒中：每个位置仍每十二秒参与一次，但由位置和世界种子决定相位，避免同一帧处理所有边界。同一相位的变化先计算后同时提交，不让遍历顺序造成连锁推进。相位由已有生态时钟恢复，存档格式不变；不要求新版继续逐像素复现 0.7 的未来演化，保存后在同一版本继续模拟仍可复现。植被变化分帧刷新，地表只向 GPU 上传受影响的 32×32 地块纹理。
